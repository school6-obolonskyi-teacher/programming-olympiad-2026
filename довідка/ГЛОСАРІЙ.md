# Глосарій

Терміни олімпіадного програмування українською. У дужках подано англійський відповідник, який трапляється в міжнародних джерелах (CSES, Codeforces, cp-algorithms). Посилання ведуть на сторінки тем, де термін пояснено докладніше.

## Олімпіада і перевірка

**Задача (problem)** — завдання олімпіади: умова, формат вхідних і вихідних даних, обмеження, приклади.

**Тест (test)** — один набір вхідних даних і правильна відповідь до нього. Розв'язок перевіряють на багатьох тестах, яких учасник не бачить.

**Підзадача (subtask)** — група тестів з додатковими обмеженнями (наприклад, `n ≤ 1000`), за яку нараховують окремі бали. Зазвичай бали за підзадачу дають, лише якщо пройдено всі її тести. Буває й потестове оцінювання: бали за кожен тест (так було на I і II етапах 2025/2026). Див. [учням/ПОРАДИ.md](../учням/ПОРАДИ.md).

**Частковий розв'язок** — розв'язок, що проходить лише частину підзадач, зазвичай простіший і повільніший за повний.

**Обмеження часу (time limit)** — найбільший час роботи програми на одному тесті, найчастіше 1 секунда.

**Обмеження пам'яті (memory limit)** — найбільший обсяг пам'яті, який може використати програма, найчастіше 256 МБ.

**Вердикт** — результат перевірки на тесті: правильна відповідь (OK, AC), неправильна відповідь (WA), перевищено час (TL), перевищено пам'ять (ML), помилка виконання (RE), помилка компіляції (CE).

**Відправлення (submission)** — надсилання розв'язку на перевірку в системі (Eolymp, CMS тощо).

**Дорозв'язування (upsolving)** — розв'язання задач після завершення змагання, коли вже доступні розбори.

**Розбір (editorial, tutorial)** — пояснення розв'язків задач від авторів.

**Формат IOI** — олімпіада з частковими балами за підзадачі, як на Міжнародній олімпіаді з інформатики. Протилежність — формат ICPC, де задача зараховується лише повністю.

**Стрес-тестування** — порівняння швидкого розв'язку з повільним, але очевидно правильним на багатьох випадкових тестах. Див. [довідка/СЕРЕДОВИЩЕ.md](СЕРЕДОВИЩЕ.md#4-як-перевірити-розвязок-самостійно-стрес-тестування).

**Граничний випадок (edge case)** — тест з крайніми значеннями: найменшими, найбільшими, однаковими, нульовими. На них найчастіше помиляються.

## Введення-виведення

**Стандартне введення (stdin)** і **стандартне виведення (stdout)** — потоки, з яких програма читає дані (`cin`, `input()`) і в які пише відповідь (`cout`, `print()`). На олімпіадах зазвичай використовуються саме вони.

**Стандартний потік помилок (stderr)** — окремий потік (`cerr`), який система не перевіряє. Зручний для налагоджувального виведення.

**Перенаправлення** — подання файлу на вхід програми: `prog < 01.in`.

**Швидке введення** — прийоми, що прискорюють читання великих даних: `ios::sync_with_stdio(false); cin.tie(nullptr);` у C++, `sys.stdin.buffer.read()` у Python. Див. [тему 06](../учням/теми/06-складність.md).

## Мова і типи даних

**Змінна** — іменована комірка пам'яті для значення.

**Тип даних** — вид значення і діапазон, що його можна зберегти: `int` (32 біти, приблизно від −2,1·10⁹ до 2,1·10⁹), `long long` (64 біти, приблизно до 9,2·10¹⁸), `double` (дійсні числа з обмеженою точністю), `char`, `string`, `bool`.

**Переповнення (overflow)** — результат обчислення не вміщується в тип. У C++ для знакових цілих це помилка, і програма видає неправильне (часто від'ємне) число. У Python цілі числа не переповнюються. Див. [тему 06](../учням/теми/06-складність.md).

**Цілочисельне ділення** — ділення з відкиданням дробової частини: `7 / 2 = 3` у C++ для цілих, `7 // 2 = 3` у Python. Для від'ємних чисел C++ округлює до нуля, а Python — вниз: `-7 / 2 = -3` у C++, `-7 // 2 = -4` у Python.

**Остача від ділення (`%`)** — `10 % 3 = 1`, бо `10 = 3·3 + 1`. У C++ знак остачі збігається зі знаком діленого (`-3 % 2 = -1`), у Python — зі знаком дільника (`-3 % 2 = 1`).

**Ділення з округленням угору** — `⌈a/b⌉` для додатних цілих обчислюється як `(a + b − 1) / b` без дійсних чисел. Див. [тему 01](../учням/теми/01-перші-програми.md).

**Масив (array)** — послідовність елементів одного типу з доступом за індексом. Індексація в C++ і Python починається з 0. У C++ зазвичай використовують `vector`, у Python — список (`list`).

**Рядок (string)** — послідовність символів. Див. [тему 05](../учням/теми/05-рядки.md).

**Функція** — іменований фрагмент коду, що приймає параметри й може повертати значення.

**Рекурсія** — функція, що викликає сама себе. Потрібна **база** (випадок без рекурсивного виклику), інакше виклики не закінчаться. Див. [тему 13](../учням/теми/13-рекурсія-та-перебір.md).

**Компіляція** — перетворення програми на C++ у виконуваний файл. Python-програма не компілюється заздалегідь, а виконується інтерпретатором.

## Складність алгоритмів

**Алгоритм** — точна послідовність дій, що розв'язує задачу для будь-яких допустимих вхідних даних.

**Часова складність** — як зростає кількість операцій зі зростанням розміру входу `n`. Записують у нотації «O-велике»: O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ).

**Просторова складність** — як зростає обсяг потрібної пам'яті.

**Орієнтир** — близько 10⁸ простих операцій за секунду на C++. Python повільніший у десятки разів (на простих циклах — до 100 разів). Таблиця «обмеження → допустима складність» — у [темі 06](../учням/теми/06-складність.md).

**Наївний розв'язок (повний перебір)** — найпростіший розв'язок, що перебирає всі варіанти. Часто правильний, але повільний.

## Алгоритми

**Лінійний пошук** — перегляд елементів по одному, O(n).

**Двійковий пошук (binary search)** — пошук у відсортованому масиві поділом діапазону навпіл, O(log n). Див. [тему 09](../учням/теми/09-двійковий-пошук.md).

**Сортування** — упорядкування елементів. Бульбашкове сортування і сортування вставками працюють за O(n²). Вбудовані `sort` (C++) і `sorted` (Python) — за O(n log n). Сортування підрахунком — за O(n + k) для чисел від 0 до k. Див. [тему 08](../учням/теми/08-сортування.md).

**Префіксні (часткові) суми** — масив `pref[i] = a₁ + … + aᵢ`. Дозволяє знаходити суму на відрізку за O(1). Див. [тему 07](../учням/теми/07-префіксні-суми.md).

**Метод двох вказівників** — два індекси, що рухаються масивом лише вперед. Часто перетворює O(n²) на O(n). Див. [тему 12](../учням/теми/12-два-вказівники-та-жадібні.md).

**Жадібний алгоритм (greedy)** — на кожному кроці робить вибір, який зараз здається найкращим. Правильний не завжди, тому потребує доведення.

**Перебір (brute force)** — розгляд усіх варіантів: підмножин (2ⁿ), перестановок (n!).

**Бітова маска** — подання підмножини числом, у якому i-й біт показує, чи входить i-й елемент.

**Динамічне програмування (ДП)** — розв'язання задачі через відповіді до менших підзадач, які зберігаються в таблиці, щоб не обчислювати їх повторно. Див. [тему 14](../учням/теми/14-динамічне-програмування.md).

**Решето Ератосфена** — знаходження всіх простих чисел до `n` викреслюванням кратних, O(n log log n). Див. [тему 11](../учням/теми/11-теорія-чисел.md).

**Алгоритм Евкліда** — знаходження НСД: `НСД(a, b) = НСД(b, a mod b)`, `НСД(a, 0) = a`.

**Пошук у ширину (BFS)** — обхід графа «шарами» від стартової вершини. Знаходить найкоротші шляхи в графі без ваг. Див. [тему 15](../учням/теми/15-графи.md).

**Пошук у глибину (DFS)** — обхід графа, що заходить якомога глибше, а потім повертається.

## Математика

**Дільник** — `d` є дільником `n`, якщо `n % d == 0`.

**Просте число** — натуральне число більше за 1, що має рівно два дільники: 1 і саме себе. Число 1 не є простим.

**НСД** — найбільший спільний дільник: `НСД(12, 18) = 6`.

**НСК** — найменше спільне кратне: `НСК(4, 6) = 12`. Обчислюється як `a / НСД(a, b) · b`. Порядок дій важливий: так менше ризику переповнення.

**Парне число** — ціле число, що ділиться на 2 без остачі (зокрема 0 і від'ємні −2, −4…).

**Паліндром** — рядок або число, що однаково читається зліва направо і справа наліво: `level`, `12321`.

**Анаграма** — слово, утворене перестановкою літер іншого слова: `listen` і `silent`.

**Послідовність Фібоначчі** — `F(0) = 0`, `F(1) = 1`, `F(n) = F(n−1) + F(n−2)`: 0, 1, 1, 2, 3, 5, 8, 13, … Числа зростають приблизно в 1,618 раза на крок: `F(47)` уже не вміщується в `int`, а `F(93)` — у `long long`.

## Структури даних

Див. [тему 10](../учням/теми/10-структури-даних.md).

**Стек (stack)** — «останнім прийшов — першим вийшов» (LIFO): `stack` у C++, список з `append`/`pop` у Python.

**Черга (queue)** — «першим прийшов — першим вийшов» (FIFO): `queue` у C++, `collections.deque` у Python.

**Дек (deque)** — двостороння черга: додавання й видалення з обох кінців за O(1).

**Множина (set)** — набір без повторів зі швидкою перевіркою наявності елемента: `set` (упорядкована, O(log n)) і `unordered_set` у C++, `set` у Python.

**Асоціативний масив, словник (map, dict)** — пари «ключ → значення»: `map`/`unordered_map` у C++, `dict` у Python.

**Купа, черга з пріоритетом (heap, priority queue)** — швидко повертає найбільший (або найменший) елемент: `priority_queue` у C++, `heapq` у Python.

**Граф** — вершини, з'єднані ребрами. Граф буває орієнтованим або неорієнтованим, з вагами на ребрах або без них. Зберігають його найчастіше списками суміжності.

**Дерево** — зв'язний граф без циклів: `n` вершин і `n − 1` ребро.
