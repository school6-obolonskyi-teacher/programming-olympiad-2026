# Перевірені ресурси для підготовки

Кожне посилання відкрито й перевірено **09.10.2026**. До переліку потрапили лише ресурси, що реально корисні для олімпіадної підготовки учнів 6–9 класів. Архіви задач олімпіад — в окремому файлі [АРХІВ-ЗАДАЧ.md](АРХІВ-ЗАДАЧ.md).

## 1. З чого почати (українською)

| [Eolymp](https://eolymp.com/uk) | Великий каталог задач з автоматичною перевіркою, інтерфейс українською. Основні можливості безкоштовні, є платні плани. За умовами використання — з 14 років або з дозволу батьків | Усі |

| [Документація Python українською](https://docs.python.org/uk/3/) | Офіційна документація, перекладена частково (підручник — здебільшого) | Ті, хто пише на Python |
