# Два тижні до I етапу: план на 12–25 жовтня 2026

I (міський) етап з інформатики в Дніпрі — **у неділю, 25.10.2026, о 10:00**. Його оголошено для 8–11 класів, тож семикласники, найімовірніше, виступають за 8 клас (так було у 2024/2025; за який клас ви зареєстровані, уточніть у вчителя, див. [7-КЛАС.md](7-КЛАС.md)). План розраховано на учнів 7–9 класів: 45–90 хвилин на день, крім двох пробних турів. ## Як узяти бали, коли повного розв'язку не видно

Бали дають за кожен пройдений тест, а серед тестів завжди є малі. Тому, якщо швидкого розв'язку не видно, напишіть **перебір** — найпростіший розв'язок, який перевіряє всі варіанти підряд. Він повільний, але на малих тестах встигає.

Приклад. Задача: «Дано `n` чисел і число `k`. Скільки є пар чисел (з різних місць масиву), сума яких дорівнює `k`? `n ≤ 2·10⁵`». Швидкий розв'язок потребує словника, але перебір усіх пар пишеться за 3 хвилини:

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    long long cnt = 0;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)      // кожну пару (i, j) перевіряємо один раз
            if (a[i] + a[j] == k) cnt++;
    cout << cnt << '\n';
}
```

Python:

```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
cnt = 0
for i in range(n):
    for j in range(i + 1, n):    # кожну пару (i, j) перевіряємо один раз
        if a[i] + a[j] == k:
            cnt += 1
print(cnt)
```

Скільки разів виконується перевірка: приблизно `n²/2`. При `n = 1000` це 500 тисяч — мить навіть на Python. При `n = 2·10⁵` — 2·10¹⁰, і програма не встигне. Але тести з малими `n` вона пройде, і ці бали ваші.

Порядок дій на олімпіаді:

1. Подивіться в умові, які є обмеження і що сказано про оцінювання. Фраза на кшталт «не менше 10 балів, якщо розв'язок правильно працює для `n = 1`» — прямий натяк, що прості розв'язки теж оцінять.
2. Напишіть перебір, перевірте на прикладах і **відправте**.
3. Лише потім думайте над швидким розв'язком. Перебір збережіть: ним зручно перевіряти швидкий (див. [стрес-тестування](../довідка/СЕРЕДОВИЩЕ.md#4-як-перевірити-розвязок-самостійно-стрес-тестування)).
4. Якщо повного розв'язку так і немає, а ідея є, хоч і недоведена, — об'єднайте: `if (n <= МЕЖА) перебір(); else ідея();`. На задачі 19 репозиторію така комбінація набрала 83 бали потестово, а сам перебір — 65 ([докладно](ПОРАДИ.md#потестове-оцінювання-не-залишайте-тестів-порожніми)).

Документи й форму проведення визначає [наказ департаменту гуманітарної політики ДМР № 275](../довідка/ОЛІМПІАДИ.md#i-міський-етап-20262027-у-дніпрі).

### Під час туру — коротко

1. Перші 10–15 хвилин: прочитайте **всі** задачі, випишіть обмеження і правила оцінювання. Якщо можна мати папір — заповніть [картку туру](КАРТКА-ТУРУ.md), як на пробних турах.
2. Почніть з A і B: ви їх уже бачили в наборах. До 10 хвилин на кожну.
3. Далі — C, D, E. Перш ніж відправити, перевірте найменші й найбільші значення з умови.
4. На складних задачах спершу відправте перебір для малих тестів (див. [вище](#як-узяти-бали-коли-повного-розвязку-не-видно)).
5. 25–30 хвилин без прогресу — переходьте до іншої задачі.
6. Перед кожним відправленням перевірте вибрану мову.
7. Останні 15 хвилин не переписуйте робочі розв'язки.

Якщо тур, як у 2025–2026, триває 5 годин, орієнтовний розподіл часу: A і B — до 20 хвилин разом, C–E — до години, F — 30–40 хвилин, решта — G і H. Пийте воду й перекушуйте, якщо дозволено: 5 годин — це довго.

- Етап проходить в укритті закладу освіти, тому дитині варто взяти теплий одяг і воду.
- Найкраща допомога в останні дні — спокій і нормальний сон. Нові теми за день до олімпіади не допомагають.
