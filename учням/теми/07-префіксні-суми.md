## Що треба зрозуміти

Після цієї теми ви зможете:

1. Будувати масив префіксних сум `pref` за O(n), де `pref[0] = 0`.
2. Обчислювати суму на будь-якому відрізку `[l, r]` за O(1) як `pref[r] − pref[l−1]`.
3. Рахувати префіксними сумами не лише суми, а й кількості (скільки елементів із властивістю на відрізку).
4. Будувати префіксні мінімуми й максимуми і застосовувати їх.
5. Додавати число на відрізку за O(1) за допомогою різницевого масиву.

## Теорія

### Ідея

Нехай треба багато разів відповідати на запитання «яка сума елементів з `l`-го по `r`-й». Якщо щоразу сумувати циклом, то q запитань коштуватимуть до n · q операцій. Для n = q = 2·10⁵ це 4·10¹⁰ — не встигне.

Порахуємо заздалегідь суми всіх префіксів (початкових частин) масиву. Нумеруємо елементи з 1:

```
pref[0] = 0
pref[i] = a[1] + a[2] + … + a[i] = pref[i − 1] + a[i]
```

Тоді сума на відрізку — це різниця двох префіксів:

```
a[l] + … + a[r] = pref[r] − pref[l − 1]
```

| i | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| a[i] | — | 4 | 0 | 7 | 1 | 3 |
| pref[i] | 0 | 4 | 4 | 11 | 12 | 15 |

Сума з 2-го по 4-й: `pref[4] − pref[1] = 12 − 4 = 8` (справді, 0 + 7 + 1 = 8).

Нульовий елемент `pref[0] = 0` потрібен для того, щоб формула працювала й при `l = 1` без окремого випадку.

### Кількість елементів із властивістю на відрізку

Префіксні суми можна будувати не з самих чисел, а з «прапорців» 1 або 0. Скільки парних чисел серед `a[l..r]`?

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> cnt(n + 1, 0);           // cnt[i] — скільки парних серед a[1..i]
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        cnt[i] = cnt[i - 1] + (x % 2 == 0 ? 1 : 0);
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << cnt[r] - cnt[l - 1] << '\n';
    }
}
```

Python:

```python
import sys

data = sys.stdin.buffer.read().split()
n, q = int(data[0]), int(data[1])
cnt = [0] * (n + 1)                  # cnt[i] — скільки парних серед a[1..i]
for i in range(1, n + 1):
    x = int(data[1 + i])
    cnt[i] = cnt[i - 1] + (1 if x % 2 == 0 else 0)
out = []
pos = 2 + n
for _ in range(q):
    l, r = int(data[pos]), int(data[pos + 1])
    pos += 2
    out.append(str(cnt[r] - cnt[l - 1]))
print("\n".join(out))
```

Для входу

```
6 3
4 7 2 9 6 1
1 3
2 5
4 4
```

відповіді: `2`, `2`, `0`.

Якщо замість прапорців додавати самі значення, вийдуть звичайні префіксні суми. Тоді пам'ятайте про тип: 2·10⁵ чисел по 10⁹ дають суму до 2·10¹⁴, тобто потрібен `long long`.

### Префіксні мінімуми

`pmin[i] = min(a[1], …, a[i]) = min(pmin[i − 1], a[i])` — теж будується одним проходом.

Приклад: відомі ціни акції по днях. Купити можна в день i, продати в день j > i. Який найбільший прибуток? Для кожного дня продажу j найвигідніше було купити за найменшою ціною серед попередніх днів — це і є префіксний мінімум.

C++:

```cpp
vector<long long> p = {7, 1, 5, 3, 6, 4};
long long best = 0, mn = p[0];       // mn — найменша ціна серед уже переглянутих днів
for (int j = 1; j < (int)p.size(); j++) {
    best = max(best, p[j] - mn);
    mn = min(mn, p[j]);
}
cout << best << '\n';                // 5: купити за 1, продати за 6
```

Python:

```python
p = [7, 1, 5, 3, 6, 4]
best, mn = 0, p[0]                   # mn — найменша ціна серед уже переглянутих днів
for j in range(1, len(p)):
    best = max(best, p[j] - mn)
    mn = min(mn, p[j])
print(best)                          # 5
```

Так само будуються суфіксні мінімуми (справа наліво). Поєднання «найкраще зліва від позиції + найкраще справа від позиції» трапляється часто, зокрема в задачі H «Виставка» I етапу 2025–2026.

### Різницевий масив: додати x на відрізку

Нехай треба багато разів «додати x до всіх елементів з l по r», а результат потрібен лише наприкінці. Заведемо масив `d` (з нулів) і для кожної операції зробимо дві дії:

```
d[l] += x
d[r + 1] -= x
```

Наприкінці префіксні суми масиву `d` дадуть, скільки додано до кожного елемента. Кожна операція — O(1), відновлення — O(n).

У коді C++ нижче `add` — це **лямбда-функція**: невелика функція, оголошена прямо всередині іншої функції. Запис `[&]` дозволяє їй змінювати масив `d`.

C++:

```cpp
int n = 5;
vector<long long> d(n + 2, 0);       // n + 2, бо звертаємося до d[r + 1] при r = n
auto add = [&](int l, int r, long long x) { d[l] += x; d[r + 1] -= x; };
add(1, 3, 2);
add(2, 5, 1);
add(4, 4, 5);
long long cur = 0;
for (int i = 1; i <= n; i++) {
    cur += d[i];
    cout << cur << ' ';              // 2 3 3 6 1
}
cout << '\n';
```

Python:

```python
n = 5
d = [0] * (n + 2)                    # n + 2, бо звертаємося до d[r + 1] при r = n
for l, r, x in [(1, 3, 2), (2, 5, 1), (4, 4, 5)]:
    d[l] += x
    d[r + 1] -= x
cur = 0
res = []
for i in range(1, n + 1):
    cur += d[i]
    res.append(cur)
print(*res)                          # 2 3 3 6 1
```

### Двовимірні префіксні суми

Для таблиці `P[i][j]` — сума прямокутника від `(1, 1)` до `(i, j)`:

```
P[i][j] = a[i][j] + P[i−1][j] + P[i][j−1] − P[i−1][j−1]
```

Сума прямокутника з кутами `(r1, c1)` і `(r2, c2)`:

```
P[r2][c2] − P[r1−1][c2] − P[r2][c1−1] + P[r1−1][c1−1]
```

Віднімаємо дві смуги, а кут, який відняли двічі, додаємо назад. Намалюйте це на папері в клітинку.

## Типові задачі

- Багато запитань «сума (кількість, середнє) на відрізку від l до r».
- «Скільки елементів із властивістю між позиціями l і r» — префіксні суми з прапорців.
- «Найкращий відрізок» або «найкраща пара позицій i < j» — префіксні мінімуми, максимуми, суми.
- Багато операцій «додати x на відрізку», а відповідь потрібна лише наприкінці — різницевий масив.
- Суми в прямокутниках таблиці — двовимірні префіксні суми.
- Скільки відрізків мають суму x (рівну, кратну k) — префіксні суми плюс підрахунок у `map`/`dict` ([тема 10](10-структури-даних.md)).

## Типові помилки

1. **`pref[r] − pref[l]` замість `pref[r] − pref[l − 1]`** — губиться елемент `a[l]`. Як виявити: запитання з `l = r`.
2. **Індексація з 0 без зсуву** — вихід за межі або зсув відповіді на один елемент. Як виявити: запитання з `l = 1`.
3. **`int` для сум.** Як виявити: тест з усіма значеннями, рівними максимуму.
4. **Масив перебудовують для кожного запитання** або сумують зрізом (`sum(a[l-1:r])` у Python) — це знову O(n · q).
5. **Різницевий масив розміру n + 1** при зверненні до `d[r + 1]` з `r = n`.
6. **Повільне введення й виведення** при q до 2·10⁵ (див. [тему 06](06-складність.md#швидке-введення-й-виведення)).
