## Що треба зрозуміти

Після цієї теми ви зможете:

1. Читати слово, рядок із пробілами й кілька рядків, не потрапляючи в пастки з переведенням рядка.
2. Працювати з рядком як із масивом символів: довжина, `s[i]`, прохід циклом.
3. Перетворювати символи на числа й назад: номер літери `c - 'a'`, цифра `c - '0'` (`ord`, `chr` у Python).
4. Виконувати основні операції: підрядок, пошук, перевертання, порівняння, перетворення числа на рядок і навпаки.
5. Рахувати частоти літер масивом із 26 лічильників.

## Теорія

### Читання рядків

C++:

```cpp
string w;
cin >> w;              // одне слово: читає до пробілу або кінця рядка
string line;
getline(cin, line);    // увесь рядок разом із пробілами
```

Пастка: після `cin >> n` символ переведення рядка залишається у вхідному потоці, і наступний `getline` прочитає порожній рядок.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    string line;
    getline(cin, line);              // ПОМИЛКА: дочитає залишок рядка з n, тобто ""
    cout << "[" << line << "]\n";
    getline(cin >> ws, line);        // ws спершу пропускає пробіли й переведення рядка
    cout << "[" << line << "]\n";
}
```

На вході `3` / `hello world` програма виведе `[]`, а потім `[hello world]`.

Python:

```python
s = input()            # увесь рядок, без символу переведення рядка
words = s.split()      # список слів
```

Якщо рядок читається через `sys.stdin.readline()`, символ `'\n'` залишається в кінці. Видаляйте його через `.strip()` (заразом зникнуть пробіли й символ `'\r'`, який буває у файлах, створених у Windows).

### Символи — це числа

Кожен символ має код: `'a'`…`'z'` — це 97…122, `'A'`…`'Z'` — 65…90, `'0'`…`'9'` — 48…57. Пам'ятати коди не треба, досить знати, що літери й цифри йдуть підряд.

C++:

```cpp
char c = 'c';
cout << c - 'a' << '\n';           // 2 — номер літери в абетці, з нуля
cout << char('a' + 25) << '\n';    // z
cout << '7' - '0' << '\n';         // 7 — цифра-символ стала числом
```

Python:

```python
c = 'c'
print(ord(c) - ord('a'))           # 2
print(chr(ord('a') + 25))          # z
print(int('7'))                    # 7
```

### Частоти літер

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;                            // лише малі латинські літери
    vector<int> cnt(26, 0);
    for (char c : s) cnt[c - 'a']++;
    for (int i = 0; i < 26; i++)
        if (cnt[i] > 0) cout << char('a' + i) << ' ' << cnt[i] << '\n';
}
```

Python:

```python
s = input()
cnt = [0] * 26
for c in s:
    cnt[ord(c) - ord('a')] += 1
for i in range(26):
    if cnt[i] > 0:
        print(chr(ord('a') + i), cnt[i])
```

Для `banana` виведеться `a 3`, `b 1`, `n 2`. У Python те саме робить `collections.Counter(s)`. Подумайте, як масив частот допоможе в задачі 11 «Анаграми».

### Основні операції

| Дія | C++ (`string s`) | Python (`str s`) |
|---|---|---|
| довжина | `s.size()` | `len(s)` |
| символ з індексом i | `s[i]` | `s[i]` |
| k символів, починаючи з i | `s.substr(i, k)` | `s[i:i + k]` |
| перевернути | `reverse(s.begin(), s.end())` — змінює `s` | `s[::-1]` — новий рядок |
| знайти t | `s.find(t)` — позиція або `string::npos` | `s.find(t)` — позиція або `-1`; `t in s` |
| чи починається з t | `s.rfind(t, 0) == 0` | `s.startswith(t)` |
| число ↔ рядок | `to_string(x)`, `stoll(s)` | `str(x)`, `int(s)` |
| регістр | `char(toupper(c))`, `char(tolower(c))` (без `char(...)` `cout` виведе код символу) | `s.upper()`, `s.lower()` |

C++:

```cpp
string s = "olympiad";
cout << s.substr(1, 3) << '\n';        // lym
cout << s.find("pi") << '\n';          // 4
string t = s;
reverse(t.begin(), t.end());
cout << t << '\n';                     // daipmylo
```

Python:

```python
s = "olympiad"
print(s[1:4])                          # lym
print(s.find("pi"))                    # 4
print(s[::-1])                         # daipmylo
```

Рядки в Python незмінні: `s[0] = 'x'` дає помилку `TypeError`. Щоб змінювати окремі символи, перетворіть рядок на список: `t = list(s)`, а потім зберіть назад: `''.join(t)`.

### Рядки й числа

- Рядки порівнюються **посимвольно** (лексикографічно), як слова в словнику. Тому `"10" < "9"` — істина: символ `'1'` менший за `'9'`. Числа, записані рядками, порівнюйте як числа або спершу за довжиною.
- Число на 100 цифр не поміститься в `long long`, але його можна обробляти як рядок. У Python `int` впорається і так.
- Число b є префіксом числа c, якщо запис c починається із запису b: `to_string(c).rfind(to_string(b), 0) == 0` у C++ і `str(c).startswith(str(b))` у Python. Наприклад, 123 — префікс 12345, а 13 — ні.

### Пошук підрядка

Найпростіший спосіб — перевірити кожну позицію. Порахуємо, скільки разів t трапляється в s (входження можуть перекриватися).

C++:

```cpp
int cnt = 0;
for (int i = 0; i + (int)t.size() <= (int)s.size(); i++)
    if (s.compare(i, t.size(), t) == 0) cnt++;
```

Python:

```python
cnt = 0
for i in range(len(s) - len(t) + 1):
    if s[i:i + len(t)] == t:
        cnt += 1
```

Для `s = "abababa"` і `t = "aba"` відповідь 3. А вбудований `s.count("aba")` у Python поверне 2, бо рахує лише входження, що не перекриваються.

Такий пошук робить близько n · m порівнянь символів (n і m — довжини рядків). Для рядків до кількох тисяч символів цього достатньо. Для 10⁶ символів потрібні спеціальні алгоритми (префікс-функція, Z-функція), але це вже теми II етапу.

### Як збирати рядок

- C++: `res += c;` додає символ швидко. А `res = res + c;` щоразу копіює весь рядок, тож на довгому рядку час зростає квадратично.
- Python: складайте частини в список, а наприкінці об'єднайте: `''.join(parts)`.

## Типові задачі

- Паліндроми: рядок читається однаково в обидва боки.
- Анаграми, «чи можна переставити літери…» — масив частот.
- Підрахунок символів певного виду (голосних, цифр, великих літер).
- Пошук і підрахунок підрядків, заміна одних символів іншими.
- Шифр зсуву: кожна літера зсувається на k позицій в абетці — `(c - 'a' + k) % 26`.
- Дуже довгі числа, які зручніше обробляти як рядки.

## Типові помилки

1. **`getline` після `cin >>`** читає порожній рядок. Виправлення — `getline(cin >> ws, line)`.
2. **Зайві символи в кінці рядка** (`'\r'`, пробіли). Симптом: порівняння рядків «чомусь» хибне. Виправлення — `.strip()` у Python.
3. **Порівняння чисел як рядків:** `"10" < "9"`.
4. **`if (s.find(t))` у C++.** Якщо t стоїть на початку s, `find` повертає 0, і умова хибна; а «не знайдено» (`npos`) — навпаки, істина. Правильно: `if (s.find(t) != string::npos)`.
5. **`s.size() - 1` для порожнього рядка.** `size()` повертає беззнакове число, і `0 - 1` перетворюється на 18446744073709551615. Цикл `for (int i = 0; i < s.size() - 1; i++)` на порожньому рядку піде далеко за межі. Пишіть `(int)s.size() - 1`.
6. **`s.count(t)` у Python не рахує входжень, що перекриваються.**
7. **Великі й малі літери:** `'A'` і `'a'` — різні символи. Уважно читайте, чи розрізняє їх умова.
