## Що треба зрозуміти

Після цієї теми ви зможете:

1. Написати програму, яка читає числа зі стандартного введення й виводить **лише** відповідь, без запрошень на кшталт «Введіть n».
2. Обчислювати цілочисельну частку й остачу (`/` і `%` у C++, `//` і `%` у Python) і знати, чим мови відрізняються для від'ємних чисел.
3. Ділити з округленням угору без дійсних чисел: `(a + b - 1) / b`.
4. Виділяти цифри числа й переводити одиниці: копійки в гривні, секунди в хвилини, сантиметри в метри.
5. Обирати в C++ тип `int` або `long long` залежно від найбільшого можливого значення.

## Теорія

### Каркас програми

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;          // числа можуть бути в одному рядку або в різних
    cout << a + b << '\n';
    return 0;
}
```

Python:

```python
a, b = map(int, input().split())   # обидва числа мають бути в ОДНОМУ рядку
print(a + b)
```

`cin >>` у C++ пропускає і пробіли, і переведення рядка, тому йому байдуже, як розташовані числа. А `input()` у Python читає **один рядок**. Якщо кожне число стоїть в окремому рядку (як у задачі «Борги»), пишіть `int(input())` для кожного числа або прочитайте весь вхід одразу:

```python
import sys

data = sys.stdin.read().split()    # усі числа з усього входу, хоч як розташовані
a, b, c = int(data[0]), int(data[1]), int(data[2])
print(a * b * c)
```

Виводьте відповідь точно у форматі з умови. Перевіряльна програма порівнює ваше виведення з правильним, тож зайве слово («Відповідь: 5») — це вже неправильна відповідь.

### Типи даних

| Тип | Діапазон значень | Коли вживати |
|---|---|---|
| `int` (C++) | від −2 147 483 648 до 2 147 483 647, тобто приблизно ±2,1·10⁹ | значення й результати не перевищують 2·10⁹ |
| `long long` (C++) | приблизно ±9,2·10¹⁸ | суми, добутки, відповіді, які можуть перевищити 2·10⁹ |
| `int` (Python) | без обмежень | завжди |

Поки що правило просте: якщо сумніваєтеся, беріть `long long`. Детально про переповнення — у [темі 06](06-складність.md).

### Ділення та остача

C++:

```cpp
cout << 17 / 5 << ' ' << 17 % 5 << '\n';   // 3 2
cout << -7 / 2 << ' ' << -7 % 2 << '\n';   // -3 -1
```

Python:

```python
print(17 // 5, 17 % 5)    # 3 2
print(-7 // 2, -7 % 2)    # -4 1
print(17 / 5, 10 / 2)     # 3.4 5.0 — це дійсні числа!
```

- У C++ ділення двох цілих чисел дає цілу частку (дробова частина відкидається), а `%` — остачу.
- У Python для цього є `//` і `%`. Оператор `/` у Python **завжди** дає дійсне число: навіть `10 / 2` виведеться як `5.0`.
- Для невід'ємних чисел обидві мови дають однакові результати. Для від'ємних — різні: C++ відкидає дробову частину (округлює до нуля), а Python округлює вниз. В олімпіадних задачах числа зазвичай невід'ємні, але якщо ні — будьте уважні.

Що дають `/` і `%` на практиці:

| Вираз | Значення | Приклад для `n = 4729` |
|---|---|---|
| `n % 10` | остання цифра | 9 |
| `n / 10` (`n // 10`) | число без останньої цифри | 472 |
| `n / 10 % 10` | цифра десятків | 2 |
| `n % 2` | 0 — парне, 1 — непарне (для n ≥ 0) | 1 |
| `t / 60`, `t % 60` | повні хвилини й решта секунд у `t` секундах | — |

Приклад: сума в копійках, вивести її як гривні з копійками у форматі `12.05`.

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long k;                                   // сума в копійках, наприклад 1205
    cin >> k;
    printf("%lld.%02lld\n", k / 100, k % 100);     // 12.05
}
```

Python:

```python
k = int(input())                       # сума в копійках, наприклад 1205
print(f"{k // 100}.{k % 100:02d}")     # 12.05
```

Запис `%02lld` у C++ і `:02d` у Python означає «щонайменше дві цифри, доповнити нулем зліва». Без нього вийшло б `12.5`.

### Ділення з округленням угору

Скільки автобусів по 40 місць потрібно, щоб перевезти 95 учнів? Ціла частка `95 / 40 = 2`, але двох автобусів замало. Потрібно округлити частку вгору: ⌈95 / 40⌉ = 3.

Для `a ≥ 0` і `b > 0`:

```
⌈a / b⌉ = (a + b − 1) / b      (ділення цілочисельне)
```

Чому це працює: якщо `a` ділиться на `b` націло, то додані `b − 1` не дотягують до наступного кратного; якщо не ділиться, то остача разом з `b − 1` дає щонайменше `b`, і частка зростає на 1. Наприклад, для `b = 40`: `(95 + 39) / 40 = 134 / 40 = 3`, а `(80 + 39) / 40 = 119 / 40 = 2`.

C++:

```cpp
long long a = 95, b = 40;
cout << (a + b - 1) / b << '\n';   // 3
```

Python:

```python
a, b = 95, 40
print((a + b - 1) // b)    # 3
print(-(-a // b))          # 3 — ще один спосіб, працює лише в Python
```

Чому не `ceil`? Тому що легко помилитися:

```cpp
cout << ceil(7 / 2) << '\n';                     // 3, а не 4: вираз 7 / 2 уже дорівнює 3
long long a = 100000000000000001LL, b = 2;       // a = 10^17 + 1
cout << (long long)ceil((double)a / b) << '\n';  // 50000000000000000 — неправильно
cout << (a + b - 1) / b << '\n';                 // 50000000000000001 — правильно
```

Тип `double` зберігає лише близько 15–16 значущих цифр, тому для великих чисел він втрачає точність. Те саме в Python: `math.ceil((10**17 + 1) / 2)` дає `50000000000000000`. **Якщо відповідь ціла, рахуйте в цілих числах.**

### Виведення дійсних чисел

Якщо відповідь дробова, умова пояснює, як її вивести: «з двома знаками після коми» або «з абсолютною чи відносною похибкою не більше 10⁻⁶». Без налаштувань `cout` виводить лише 6 значущих цифр, а великі числа — у вигляді `1.42857e+08`.

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double x = 2.0 / 3, y = 1e9 / 7;
    cout << x << ' ' << y << '\n';                     // 0.666667 1.42857e+08
    cout << fixed << setprecision(2) << x << ' ' << y << '\n';  // 0.67 142857142.86
    printf("%.2f\n", x);                               // 0.67
    printf("%.2f %.0f %.0f\n", 2.675, 0.5, 2.5);       // 2.67 0 2
}
```

Python:

```python
x, y = 2 / 3, 10**9 / 7
print(x, y)                        # 0.6666666666666666 142857142.85714287
print(f"{x:.2f} {y:.2f}")          # 0.67 142857142.86
print(round(x, 2), round(1.5, 2))  # 0.67 1.5 — round не дописує нулі
print(f"{1.5:.2f}")                # 1.50
print(f"{2.675:.2f}", round(2.5))  # 2.67 2
```

- `fixed << setprecision(k)` діє на всі наступні числа в `cout`, а `printf("%.2f", …)` і `f"{x:.2f}"` — лише на одне число.
- `round(x, 2)` у Python повертає число, а не текст, тому `round(1.5, 2)` виводиться як `1.5`. Якщо умова вимагає рівно два знаки після коми, форматуйте: `f"{x:.2f}"`.
- «Половинки» округлюються не так, як у школі. Число 2,675 у пам'яті — це 2,67499999…, тому виходить `2.67`. А рівно 2,5 і `round` у Python, і `printf("%.0f")` у C++ округлюють до парного: `2`.
- Якщо відповідь перевіряють з похибкою (наприклад, 10⁻⁶), виводьте знаків із запасом: `setprecision(9)` чи `f"{x:.9f}"`. Зайві знаки не шкодять, а замало знаків — це неправильна відповідь.

Якщо задачу можна розв'язати в цілих числах, розв'язуйте в цілих. `double` зберігає лише 15–16 значущих цифр, тож дробові результати майже завжди трохи неточні, а порівняння «на рівність» підводить. Гроші рахуйте в копійках, як у прикладі вище, а дроби порівнюйте без ділення: для додатних `b` і `d` нерівність `a / b > c / d` рівносильна `a · d > c · b`.

### Від умови до формули

1. Розв'яжіть приклади з умови вручну, на папері.
2. Запишіть обчислення буквами замість чисел. Це і є формула.
3. Перевірте формулу на **всіх** прикладах з умови.
4. Перевірте граничні випадки: найменші значення (0, 1) і найбільші (чи не переповниться `int`?).

## Типові задачі

- «Скільки потрібно автобусів (коробок, парт), якщо в кожен вміщується k?» — ділення з округленням угору.
- «Скільки повних … і скільки залишиться?» — `/` і `%`.
- «Переведіть секунди в години та хвилини», «копійки в гривні», «сантиметри в метри» — `/` і `%` на 60, 100, 3600…
- «Остання цифра», «число без останньої цифри», «цифра десятків» — `% 10` і `/ 10`.
- Площі, периметри, кількість клітинок у прямокутнику — формула з малюнка.
- Двоє гравців ходять по черзі однаковими ходами — зручно рахувати пари ходів «перший + другий».

## Типові помилки

1. **Зайвий текст у виведенні** («Введіть n», «Відповідь:»). Як виявити: порівняйте своє виведення з прикладом з умови символ у символ.
2. **`/` у Python замість `//`.** `print(10 / 2)` виводить `5.0`. Як виявити: у виведенні з'явилася крапка.
3. **`ceil` і `double` для цілої відповіді.** Як виявити: тест з `a`, кратним `b`, і тест з дуже великими числами (≈10¹⁷).
4. **Переповнення `int`.** Добуток двох чисел до 10⁵ — це вже до 10¹⁰. Як виявити: підставте найбільші значення з умови й оцініть відповідь.
5. **У Python числа з різних рядків читаються через `input().split()`.** Програма падає з `ValueError: not enough values to unpack (expected 2, got 1)`. Як виявити: запустіть програму на прикладі, скопійованому з умови без змін.
6. **Від'ємні числа й остача.** У C++ `-7 % 2` дорівнює `-1`, тому перевірка непарності `n % 2 == 1` для від'ємних `n` не спрацює. Пишіть `n % 2 != 0`.
7. **Не перевірені межі.** Формула, правильна для «звичайних» чисел, може ламатися при `n = 0` або `n = 1`.
