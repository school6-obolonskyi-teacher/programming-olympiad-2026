## Що треба зрозуміти

Після цієї теми ви зможете:

1. Користуватися стеком («останнім прийшов — першим вийшов»), чергою («першим прийшов — першим вийшов») і деком (двосторонньою чергою); усі їхні основні операції працюють за O(1).
2. Користуватися впорядкованими множиною й асоціативним масивом у C++ (`set`, `map`, `multiset`, операції за O(log n)) і хеш-структурами (`unordered_set`, `unordered_map`, `set` і `dict` у Python, у середньому O(1)).
3. Обирати структуру за тим, які операції потрібні й скільки разів.
4. Уникати пасток: `map[key]` створює елемент, `multiset::erase(x)` видаляє всі копії, `list.pop(0)` у Python повільний, хеш-структури не впорядковані.

## Теорія

### Яку структуру обрати

| Потрібно | C++ | Python | Складність |
|---|---|---|---|
| додавати й забирати з кінця (стек) | `vector` (`push_back`, `pop_back`, `back`) або `stack` | `list` (`append`, `pop`, `[-1]`) | O(1) |
| додавати в кінець, забирати з початку (черга) | `queue` (`push`, `pop`, `front`) | `collections.deque` (`append`, `popleft`) | O(1) |
| працювати з обома кінцями | `deque` | `collections.deque` | O(1) |
| множина без повторів, перевірка «чи є x» | `set` / `unordered_set` | `set` | O(log n) / O(1) у середньому |
| множина з повторами, найменший і найбільший елемент | `multiset` | немає вбудованої (див. нижче) | O(log n) |
| відповідність «ключ → значення» (лічильники для великих чисел, рядків) | `map` / `unordered_map` | `dict`, `collections.Counter`, `collections.defaultdict` | O(log n) / O(1) у середньому |
| найближчий елемент `>= x` у множині, що змінюється | `set::lower_bound(x)` | немає вбудованої | O(log n) |

### Стек

Стек — як стос тарілок: кладемо зверху й беремо зверху. Він природно описує вкладеність: що відкрилося останнім, те має закритися першим. Тому стек використовують для дужок, скасування дій, обходу в глибину ([тема 15](15-графи.md)).

C++:

```cpp
vector<int> st;
st.push_back(1);
st.push_back(2);
st.push_back(3);
cout << st.back() << '\n';   // 3 — верхній елемент
st.pop_back();               // знімаємо 3
cout << st.back() << '\n';   // 2
```

Python:

```python
st = []
st.append(1)
st.append(2)
st.append(3)
print(st[-1])                # 3 — верхній елемент
st.pop()                     # знімаємо 3
print(st[-1])                # 2
```

Перш ніж брати верхній елемент, перевіряйте, що стек не порожній: `back()` порожнього `vector` у C++ — невизначена поведінка, `st[-1]` порожнього списку в Python — `IndexError`.

### Черга і дек

Черга — як черга в їдальні: стаємо в кінець, обслуговують з початку. Вона потрібна для моделювання обслуговування і для обходу в ширину ([тема 15](15-графи.md)).

C++:

```cpp
queue<int> q;
q.push(10);
q.push(20);
q.push(30);
cout << q.front() << '\n';   // 10 — перший у черзі
q.pop();
cout << q.front() << '\n';   // 20
```

Python:

```python
from collections import deque

q = deque()
q.append(10)
q.append(20)
q.append(30)
print(q[0])                  # 10 — перший у черзі
q.popleft()
print(q[0])                  # 20
```

**Не робіть чергу зі списку Python через `pop(0)`:** після видалення першого елемента всі інші зсуваються, тож це O(n), а не O(1). Про це прямо сказано в документації Python (розділ «Using Lists as Queues»).

### Множина й асоціативний масив

`set` у C++ зберігає різні елементи **у порядку зростання**; `map` зберігає пари «ключ → значення», впорядковані за ключем. Обидва — збалансовані дерева, операції O(log n).

Порахуємо, скільки разів трапляється кожне число, якщо числа до 10⁹ (масив частот тут не підходить).

C++:

```cpp
vector<long long> a = {1000000000, 5, 1000000000, 7, 5, 1000000000};
map<long long, int> cnt;
for (long long x : a) cnt[x]++;                 // відсутній ключ створюється зі значенням 0
for (auto& [value, c] : cnt) cout << value << ' ' << c << '\n';   // за зростанням ключа
```

Python:

```python
from collections import Counter

a = [1000000000, 5, 1000000000, 7, 5, 1000000000]
cnt = Counter(a)                                # dict, де значення — кількості
for value in sorted(cnt):                       # dict не впорядкований за ключами — сортуємо
    print(value, cnt[value])
```

Обидві програми виведуть `5 2`, `7 1`, `1000000000 3`.

У `set` і `map` є власний метод `lower_bound`, що працює за O(log n):

```cpp
set<int> s = {1, 3, 5, 7};
auto it = s.lower_bound(4);                     // перший елемент >= 4
if (it != s.end()) cout << *it << '\n';         // 5
```

Загальна функція `lower_bound(s.begin(), s.end(), 4)` теж дасть 5, але для `set` вона працює за O(n), бо не може «стрибати» в середину. Для множин завжди пишіть `s.lower_bound(x)`.

### Пастки `map` і `multiset`

Звернення `m[x]` до відсутнього ключа **створює** його зі значенням 0:

```cpp
map<int, int> m;
if (m[5] > 0) cout << "yes\n";
cout << m.size() << '\n';                        // 1 — ключ 5 з'явився, хоча ми лише перевіряли
cout << m.count(7) << ' ' << m.size() << '\n';   // 0 1 — count нічого не створює
```

Для перевірки наявності використовуйте `m.count(x)` або `m.find(x) != m.end()`. У Python `d[x]` для відсутнього ключа дає `KeyError`; використовуйте `x in d` або `d.get(x, 0)`.

`multiset::erase(x)` видаляє **всі** копії x. Щоб видалити одну, передайте ітератор:

```cpp
multiset<int> ms = {1, 2, 2, 2, 3};
ms.erase(ms.find(2));                   // видалили ОДНУ двійку
cout << ms.size() << '\n';              // 4
ms.erase(2);                            // видалили всі двійки, що залишились
cout << ms.size() << '\n';              // 2
```

У стандартній бібліотеці Python немає впорядкованої множини з пошуком «найближчий елемент `>= x`». Якщо множина не змінюється, відсортуйте список і шукайте `bisect` ([тема 09](09-двійковий-пошук.md)). Для найменшого елемента множини, що змінюється, є купа `heapq`. У складніших випадках задачу простіше розв'язати на C++.

### Хеш-структури: `unordered_set`, `unordered_map`, `set` і `dict` Python

Вони в середньому працюють за O(1), але:

- елементи не впорядковані: перебір іде в непередбачуваному порядку;
- у найгіршому випадку операція може коштувати O(n). На змаганнях, де учасники можуть складати тести проти чужих розв'язків, спеціально підбирають числа, що «ламають» стандартний хеш `unordered_map`. На Всеукраїнській олімпіаді тести готують заздалегідь, тож такі тести малоймовірні, але гарантії немає;
- якщо порядок потрібен або є сумнів, `map` і `set` з O(log n) майже завжди достатньо швидкі.

## Типові задачі

- Правильність дужкової послідовності, вкладеність, «скасувати останню дію» — стек.
- «Найближчий менший (більший) елемент ліворуч» — стек.
- Моделювання черги, обслуговування в порядку надходження, обхід у ширину — черга.
- «Скільки різних», «чи траплялося раніше», «скільки разів трапляється» при великих значеннях або рядках — `set`/`map` (`set`/`dict`).
- «Знайдіть найменший елемент, не менший за x», коли елементи додаються й видаляються — `set`/`multiset` у C++.
- Пара чисел із заданою сумою: для кожного числа перевіряємо, чи траплялося вже «доповнення» — `map`/`dict`.

## Типові помилки

1. **`m[x]` для перевірки наявності** — створює зайві ключі й змінює `size()`.
2. **`ms.erase(x)` замість `ms.erase(ms.find(x))`** у `multiset`.
3. **`back()`, `top()`, `front()` або `pop()` на порожній структурі.** Як виявити: тест, де стек спорожніє (наприклад, рядок `")("` для дужок).
4. **`list.pop(0)` або `list.insert(0, x)` у Python** — O(n) на кожну операцію.
5. **`lower_bound(s.begin(), s.end(), x)` для `set`** замість `s.lower_bound(x)` — O(n) замість O(log n).
6. **Розраховують на порядок елементів в `unordered_map` або в Python `set`.**
7. **`x in list` у Python для багатьох запитань** — O(n) кожне; перетворіть список на `set`.
