## Що треба зрозуміти

Після цієї теми ви зможете:

1. Писати рекурсивну функцію з базою (коли зупинитися) і кроком (як звести задачу до меншої).
2. Перебирати всі підмножини n елементів (2ⁿ варіантів) рекурсією і бітовими масками.
3. Перебирати всі перестановки (n! варіантів) через `next_permutation` / `itertools.permutations` або рекурсію.
4. За обмеженнями оцінювати, чи встигне перебір: n ≤ 20 — підмножини, n ≤ 10 — перестановки.
5. Відсікати безперспективні гілки перебору.
6. Враховувати обмеження глибини рекурсії в Python і C++ і обходити їх, коли глибини замало.

## Теорія

### Рекурсія

Рекурсивна функція викликає сама себе для меншої задачі. Обов'язково потрібна **база** — випадок, який розв'язується без рекурсії.

C++:

```cpp
long long fact(int n) {
    if (n == 0) return 1;            // база
    return n * fact(n - 1);          // крок: n! = n · (n − 1)!
}
```

Python:

```python
def fact(n):
    if n == 0:                       # база
        return 1
    return n * fact(n - 1)           # крок: n! = n · (n − 1)!
```

`fact(5)` поверне 120. Кожен виклик чекає, доки завершиться вкладений, і всі вони зберігаються в **стеку викликів**. Глибина рекурсії тут дорівнює n.

### Перебір підмножин рекурсією

Для кожного елемента вирішуємо: брати чи не брати. Виходить 2ⁿ варіантів.

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int n = 3;
vector<int> chosen;

void rec(int i) {
    if (i == n) {                    // рішення про всі елементи ухвалено
        cout << "{ ";
        for (int x : chosen) cout << x << ' ';
        cout << "}\n";
        return;
    }
    rec(i + 1);                      // не беремо елемент i
    chosen.push_back(i);             // беремо елемент i
    rec(i + 1);
    chosen.pop_back();               // повертаємо стан як було!
}

int main() { rec(0); }
```

Python:

```python
n = 3
chosen = []

def rec(i):
    if i == n:                       # рішення про всі елементи ухвалено
        print(chosen)
        return
    rec(i + 1)                       # не беремо елемент i
    chosen.append(i)                 # беремо елемент i
    rec(i + 1)
    chosen.pop()                     # повертаємо стан як було!

rec(0)
```

Програма виведе 8 підмножин множини {0, 1, 2}: від порожньої до `{0, 1, 2}`. Рядок `pop_back()` / `pop()` — найважливіший: після повернення з рекурсії стан має бути таким самим, як до виклику.

### Бітові маски

Підмножину n елементів можна записати числом від 0 до 2ⁿ − 1: i-й біт дорівнює 1, якщо елемент i взято. Біти нумеруємо з нуля справа наліво. Наприклад, при n = 3 маска 5 = 101₂ означає {0, 2}.

| Дія | C++ і Python |
|---|---|
| чи взято елемент i | `(mask >> i) & 1` |
| додати елемент i | `mask \| (1 << i)` |
| прибрати елемент i | `mask & ~(1 << i)` |
| кількість масок | `1 << n` (у C++ при n ≥ 31 — `1LL << n`) |

Тут `1 << i` — число 2ⁱ (одиниця лише в i-му біті), `mask >> i` зсуває біти маски праворуч на i позицій, а `&`, `|`, `~` — побітові «і», «або», «не».

Скільки підмножин мають суму рівно S?

C++:

```cpp
vector<int> w = {3, 5, 6, 8};
int n = w.size(), S = 11, cnt = 0;
for (int mask = 0; mask < (1 << n); mask++) {
    int sum = 0;
    for (int i = 0; i < n; i++)
        if ((mask >> i) & 1) sum += w[i];    // елемент i входить у підмножину
    if (sum == S) cnt++;
}
cout << cnt << '\n';                         // 2: {3, 8} і {5, 6}
```

Python:

```python
w = [3, 5, 6, 8]
n, S, cnt = len(w), 11, 0
for mask in range(1 << n):
    s = sum(w[i] for i in range(n) if (mask >> i) & 1)   # елемент i входить у підмножину
    if s == S:
        cnt += 1
print(cnt)                                   # 2
```

Складність O(2ⁿ · n): для n = 20 це близько 2·10⁷ операцій. На нашому комп'ютері такий перебір для n = 20 зайняв на C++ 0,06 с, а на Python — 1,8 с.

### Перестановки

`next_permutation` перетворює масив на наступну за абеткою перестановку і повертає `false`, коли перестановки скінчилися. **Почати треба з відсортованого масиву**, інакше частину перестановок буде пропущено.

C++:

```cpp
vector<int> p = {1, 2, 3};               // відсортовано!
do {
    for (int x : p) cout << x << ' ';
    cout << '\n';
} while (next_permutation(p.begin(), p.end()));   // 6 перестановок
```

Python:

```python
from itertools import permutations

for p in permutations([1, 2, 3]):        # 6 перестановок у тому самому порядку
    print(*p)
```

Кількість перестановок росте дуже швидко: 8! = 40 320, 10! = 3 628 800, 12! = 479 001 600. Тому перебір перестановок можливий приблизно до n = 10.

### Відсікання

Якщо вже зрозуміло, що гілка не дасть відповіді, її не треба продовжувати. Наприклад, шукаючи підмножину додатних чисел із сумою S, припиняйте гілку, щойно поточна сума перевищила S. Відсікання не змінює складності в найгіршому випадку, але часто прискорює перебір у рази.

### Глибина рекурсії

**Python.** За замовчуванням глибина обмежена: `sys.getrecursionlimit()` повертає 1000, і глибша рекурсія дає `RecursionError: maximum recursion depth exceeded`. Ліміт можна підняти:

```python
import sys
sys.setrecursionlimit(10**6)
```

У Python 3.12 після цього рекурсія глибиною 10⁶ відпрацювала, але зайняла близько 160 МБ пам'яті. У старіших версіях Python і в PyPy глибока рекурсія може аварійно завершити програму навіть з піднятим лімітом. Надійніше переписати рекурсію циклом з явним стеком.

**C++.** Окремого ліміту немає, але стек обмежений за розміром. На нашому комп'ютері (стек 8 МБ) рекурсивний обхід ланцюжка зі 100 000 вершин (компіляція з `-O2`) спрацював, а з 200 000 — аварійно завершився. На олімпіадному сервері розмір стеку може бути іншим. Якщо глибина може сягати 10⁵ і більше, використовуйте цикл з явним стеком або обхід у ширину ([тема 15](15-графи.md)).

Для перебору підмножин і перестановок глибина дорівнює n ≤ 20 — тут проблем немає.

## Типові задачі

- n ≤ 20 і треба вибрати частину елементів: «розбийте на дві групи», «чи можна набрати суму рівно S» — перебір підмножин.
- n ≤ 10 і важливий порядок: «у якому порядку обійти», «розставте» — перебір перестановок.
- «Виведіть усі варіанти (комбінації, рядки, розстановки)».
- Підзадача з дуже малими обмеженнями в складній задачі — повний перебір дає часткові бали й допомагає перевірити швидкий розв'язок (стрес-тест).
- Задачі, які природно описуються «зведи до меншої»: Ханойські вежі, розбиття числа на доданки, обхід дерева.

## Типові помилки

1. **Немає бази або вона недосяжна** — нескінченна рекурсія й аварійне завершення.
2. **Стан не відновлено** після рекурсивного виклику (забули `pop_back()` / `pop()`).
3. **`1 << n` при n ≥ 31** в `int` у C++. Пишіть `1LL << n`.
4. **Пріоритет операцій з бітами в C++:** `==` виконується раніше за `&`. Умова `mask & (1 << i) == 0` означає `mask & ((1 << i) == 0)`, тобто завжди 0. Ставте дужки: `(mask & (1 << i)) == 0`.
5. **`next_permutation` з невідсортованого масиву:** з `{2, 1, 3}` вийде лише 4 перестановки з 6.
6. **`RecursionError` у Python** через ліміт 1000.
7. **Перебір, який не встигне:** 2ⁿ при n = 40 — це 10¹². Спершу оцініть кількість варіантів.
