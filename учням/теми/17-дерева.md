## Що треба зрозуміти

Після цієї теми ви зможете:

1. Розпізнавати дерево у вхідних даних і пояснювати його властивості: n вершин, n − 1 ребер, між будь-якими двома вершинами рівно один шлях.
2. Підвішувати дерево за корінь і обчислювати батька, глибину й розмір піддерева кожної вершини.
3. Обходити дерево з n = 2·10⁵ вершин **без рекурсії**, власним стеком.
4. Знаходити діаметр дерева двома обходами і пояснювати, чому це правильно.
5. Запускати BFS одразу з кількох джерел.

## Теорія

### Дерево і корінь

**Дерево** — зв'язний граф без циклів. У дереві з n вершинами рівно n − 1 ребер, і між будь-якими двома вершинами є рівно один шлях. Типовий вхід: `n`, далі `n − 1` рядків з ребрами.

Якщо оголосити одну вершину **коренем** (зазвичай 1), дерево «підвішується»: у кожної іншої вершини є **батько** — сусід на шляху до кореня, решта сусідів — **діти**. **Глибина** вершини — відстань від кореня, **піддерево** вершини v — сама v і всі вершини під нею.

Корисне спостереження: обходячи дерево, вершину не треба позначати масивом `used`. Єдиний уже відвіданий сусід вершини — її батько, тож досить пропускати сусіда `parent[v]`.

### Обхід без рекурсії: батьки, глибини, розміри піддерев

Рекурсивний DFS на дереві-ланцюжку з 2·10⁵ вершин у нашому запуску впав через переповнення стека ([репертуар, пастка 9](../РЕПЕРТУАР-CPP.md#9-глибина-рекурсії)). Тому обходимо власним стеком і запам'ятовуємо **порядок обходу** `order`: кожна вершина потрапляє в нього після свого батька. Тоді, пройшовши `order` з кінця, ми обробимо всіх дітей раніше за батька — саме те, що потрібно, щоб зібрати розміри піддерев знизу вгору.

Вхід: `n` і `n − 1` ребер. Вихід: глибини вершин 1..n і розміри їхніх піддерев (корінь — 1).

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> g(n + 1);           // вершини 1..n, n - 1 ребер
    for (int i = 0; i < n - 1; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }

    // Обхід від кореня 1 зі своїм стеком: батько, глибина і порядок обходу.
    vector<int> parent(n + 1, 0), depth(n + 1, 0), order;
    order.reserve(n);
    vector<int> st = {1};
    while (!st.empty()) {
        int v = st.back();
        st.pop_back();
        order.push_back(v);                 // батько завжди стоїть в order раніше за сина
        for (int u : g[v])
            if (u != parent[v]) {           // у дереві єдиний відвіданий сусід — батько
                parent[u] = v;
                depth[u] = depth[v] + 1;
                st.push_back(u);
            }
    }

    // Розміри піддерев: ідемо по order з кінця — сини раніше за батьків.
    vector<int> sz(n + 1, 1);
    for (int i = n - 1; i > 0; i--) {
        int v = order[i];
        sz[parent[v]] += sz[v];
    }
    for (int v = 1; v <= n; v++) cout << depth[v] << ' ';
    cout << '\n';
    for (int v = 1; v <= n; v++) cout << sz[v] << ' ';
    cout << '\n';
}
```

import sys

Тим самим прийомом (обхід «від кінця `order`») рахують будь-яку величину, що збирається з дітей: суму значень у піддереві, найглибший лист, ДП на дереві.

### Діаметр дерева: два обходи

**Діаметр** — найдовший шлях між двома вершинами дерева (довжину рахуємо в ребрах). Алгоритм:

1. BFS із будь-якої вершини s; найдальша від неї вершина — a.
2. BFS з a; найдальша від неї вершина — b. Відстань від a до b — діаметр.

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> g;

// BFS від s: відстані в dist, повертає найвіддаленішу від s вершину.
int farthest(int s, vector<int>& dist) {
    fill(dist.begin(), dist.end(), -1);
    queue<int> q;
    dist[s] = 0;
    q.push(s);
    int last = s;
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        last = v;                    // вершини виходять із черги за зростанням відстані
        for (int u : g[v])
            if (dist[u] == -1) {
                dist[u] = dist[v] + 1;
                q.push(u);
            }
    }
    return last;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    g.assign(n + 1, {});
    for (int i = 0; i < n - 1; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    vector<int> dist(n + 1);
    int a = farthest(1, dist);       // перший обхід: з будь-якої вершини
    int b = farthest(a, dist);       // другий обхід: з a
    cout << dist[b] << ' ' << a << ' ' << b << '\n';   // довжина діаметра в ребрах і його кінці
}
```

```python
import sys
from collections import deque

def farthest(s, g, n):
    """BFS від s: повертає (найвіддаленіша вершина, список відстаней)."""
    dist = [-1] * (n + 1)
    dist[s] = 0
    q = deque([s])
    last = s
    while q:
        v = q.popleft()
        last = v
        for u in g[v]:
            if dist[u] == -1:
                dist[u] = dist[v] + 1
                q.append(u)
    return last, dist

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    g = [[] for _ in range(n + 1)]
    for i in range(n - 1):
        a, b = int(data[1 + 2 * i]), int(data[2 + 2 * i])
        g[a].append(b)
        g[b].append(a)
    a, _ = farthest(1, g, n)         # перший обхід: з будь-якої вершини
    b, dist = farthest(a, g, n)      # другий обхід: з a
    print(dist[b], a, b)

main()
```

Для того самого дерева (ребра 1–2, 1–3, 2–4, 2–5, 5–6) програма виведе `4 6 3`: діаметр 4, шлях 6–5–2–1–3.

**Чому це правильно.** Нехай u–v — якийсь діаметр завдовжки D, а x — вершина шляху u–v, найближча до s (шляхи від s до u і до v обидва проходять через x). Покажемо, що від a є вершина на відстані не менше D, тоді другий обхід знайде саме D.

- Нехай шлях від s до a теж проходить через x і від x іде вздовж u–v до вершини z, а потім звертає вбік (можливо, z = x), причому z лежить між x і u. Оскільки a — найдальша від s, `d(x, a) ≥ d(x, u)`, тобто `d(z, a) ≥ d(z, u)`. Тоді `d(a, v) = d(a, z) + d(z, v) ≥ d(u, z) + d(z, v) = D`.
- Нехай шлях від s до a звертає раніше, у вершині y до x. З `d(s, a) ≥ d(s, u)` маємо `d(y, a) ≥ d(y, x) + d(x, u)`, а тоді `d(a, v) = d(a, y) + d(y, x) + d(x, v) ≥ d(x, u) + d(x, v) = D`.

В обох випадках найдальша від a вершина віддалена щонайменше на D, а більше за D не буває. Отже, другий обхід дає діаметр. (Для графів із циклами цей прийом не працює.)

Наслідок, корисний у задачах: найдальша від **будь-якої** вершини v вершина — один з кінців діаметра a чи b, тож відстань до неї — `max(d(a, v), d(b, v))`. Для цього досить ще одного BFS з b.

Для дерев зі зваженими ребрами алгоритм той самий, тільки відстані рахують обходом з додаванням ваг (у дереві шлях між вершинами єдиний, тож DFS чи BFS однаково дадуть правильні відстані).

### BFS з кількох джерел

«Для кожної вершини — відстань до найближчої лікарні (виходу, кроту)»: замість окремого BFS з кожного джерела кладемо в чергу **всі джерела одразу** з відстанню 0. Хвиля розходиться від усіх них разом, і кожна вершина отримує відстань до найближчого джерела. Це O(n + m), а не O(k · (n + m)). Прийом працює для будь-якого графа, не лише для дерева.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;                     // вершини, ребра, кількість джерел
    cin >> n >> m >> k;
    vector<vector<int>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    vector<int> dist(n + 1, -1);
    queue<int> q;
    for (int i = 0; i < k; i++) {    // усі джерела — у черзі з відстанню 0
        int s;
        cin >> s;
        if (dist[s] == -1) {
            dist[s] = 0;
            q.push(s);
        }
    }
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int u : g[v])
            if (dist[u] == -1) {
                dist[u] = dist[v] + 1;
                q.push(u);
            }
    }
    for (int v = 1; v <= n; v++) cout << dist[v] << ' ';   // -1 — недосяжна
    cout << '\n';
}
```

import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    n, m, k = int(data[0]), int(data[1]), int(data[2])
    g = [[] for _ in range(n + 1)]
    pos = 3
    for _ in range(m):
        a, b = int(data[pos]), int(data[pos + 1])
        pos += 2
        g[a].append(b)
        g[b].append(a)
    dist = [-1] * (n + 1)
    q = deque()
    for s in map(int, data[pos:pos + k]):   # усі джерела — з відстанню 0
        if dist[s] == -1:
            dist[s] = 0
            q.append(s)
    while q:
        v = q.popleft()
        for u in g[v]:
            if dist[u] == -1:
                dist[u] = dist[v] + 1
                q.append(u)
    print(*dist[1:])

main()

## Типові задачі

- «Мережа з n міст і n − 1 доріг, з будь-якого міста можна дістатися до будь-якого» — це дерево.
- «Скільки підлеглих у кожного начальника», «сума значень у піддереві» — розміри піддерев / обхід від кінця `order`.
- «Найбільша відстань між двома вершинами», «найдальша вершина від кожної», «де поставити центр, щоб найдальший був якомога ближче» — діаметр.
- «Відстань від кожної клітинки (вершини) до найближчого з кількох об'єктів» — BFS з кількох джерел.
- Задачі, де на вершинах дерева треба порахувати щось «знизу вгору» — ДП на дереві в порядку, оберненому до обходу.

## Типові помилки

1. **Рекурсивний DFS на глибокому дереві.** C++: аварійне завершення на ланцюжку з 2·10⁵ вершин; Python: `RecursionError` ще раніше. Як виявити: тест-ланцюжок `1–2, 2–3, …`.
2. **Розміри піддерев рахують у порядку обходу, а не з кінця:** батько обробляється раніше за дітей. Як виявити: ланцюжок і «зірка».
3. **Масив `used` забули, а на батька не перевіряють:** обхід ходить туди-сюди по ребру й зациклюється.
4. **Діаметр одним обходом з вершини 1** (відповідь — найбільша глибина, а не діаметр). Як виявити: дерево, у якого 1 — лист посередині довгої гілки.
5. **Два обходи для графа з циклами** — для нього алгоритм неправильний.
6. **BFS з кількох джерел як k окремих BFS:** O(k · n), на великих тестах не встигає.
