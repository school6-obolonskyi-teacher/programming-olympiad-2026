## Що треба зрозуміти

Після цієї теми ви зможете:

1. Створити масив потрібного розміру (`vector` у C++, список у Python), прочитати в нього n чисел і звертатися до елементів за індексом, що починається з 0.
2. Робити лінійний прохід: сума, мінімум чи максимум і його позиція, кількість елементів із заданою властивістю, перший потрібний елемент.
3. Порівнювати сусідні елементи `a[i-1]` і `a[i]` і не виходити за межі масиву.
4. Будувати масив частот, коли значення невеликі.
5. Працювати з таблицями (двовимірними масивами) n × m.

## Теорія

### Створення, читання, лінійний прохід

Знайдемо найбільше число й кількість його входжень.

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);              // n елементів з індексами 0..n-1
    for (int i = 0; i < n; i++) cin >> a[i];

    long long mx = a[0];                 // починаємо з першого елемента, а не з 0
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] > mx) { mx = a[i]; cnt = 1; }
        else if (a[i] == mx) cnt++;
    }
    cout << mx << ' ' << cnt << '\n';
}
```

Python:

```python
n = int(input())
a = list(map(int, input().split()))
mx = a[0]                 # починаємо з першого елемента, а не з 0
cnt = 0
for x in a:
    if x > mx:
        mx = x
        cnt = 1
    elif x == mx:
        cnt += 1
print(mx, cnt)
```

Для входу `6` / `3 7 2 7 5 1` обидві програми виведуть `7 2`.

У Python є готові `sum(a)`, `min(a)`, `max(a)`, `a.count(x)`, `a.index(x)`. Кожна з них — окремий прохід по масиву, тобто n операцій.

Цикл по всіх елементах у C++ можна записати коротше: `for (auto x : a)`. Але `x` тут — **копія** елемента, і змінювати її марно. Щоб читати в масив чи змінювати його елементи, потрібне посилання `auto&`:

```cpp
vector<long long> a(3);
for (auto& x : a) cin >> x;          // & — x і є елементом: читаємо прямо в масив
for (auto x : a) x *= 2;             // змінюється копія — масив не змінився
for (auto& x : a) x *= 2;            // змінюються самі елементи
for (auto x : a) cout << x << ' ';   // лише читаємо — & не потрібен
cout << '\n';                        // для входу 1 2 3 виведе 2 4 6
```

У Python так само: змінна циклу `for x in a` — лише ім'я для значення, і `x *= 2` список не змінює. Змінюйте елементи за індексом:

```python
a = [1, 2, 3]
for x in a:
    x *= 2            # змінюється лише змінна x
print(a)              # [1, 2, 3]
for i in range(len(a)):
    a[i] *= 2
print(a)              # [2, 4, 6]
```

Іноді зручно нумерувати елементи з 1, як в умові: створіть масив на `n + 1` елемент і не використовуйте нульовий. Так роблять, зокрема, для префіксних сум ([тема 07](07-префіксні-суми.md)).

### Сусідні елементи

Скільки разів значення зросло порівняно з попереднім днем?

C++:

```cpp
int cnt = 0;
for (int i = 1; i < n; i++) {          // з i = 1, бо порівнюємо з a[i - 1]
    if (a[i] > a[i - 1]) cnt++;
}
```

Python:

```python
cnt = 0
for i in range(1, n):                  # з i = 1, бо порівнюємо з a[i - 1]
    if a[i] > a[i - 1]:
        cnt += 1
```

Для масиву `1 3 2 4 5 5` відповідь 3. Якщо під час такого проходу зберігати ще й «довжину поточної серії», можна знайти найдовшу серію (задача 12). Подумайте, що відбувається з довжиною, коли серія обривається.

### Масив частот

Якщо значення невеликі, заведіть масив лічильників `cnt`, де `cnt[v]` — скільки разів трапилося значення `v`. Наприклад, оцінки від 1 до 12, треба знайти найчастішу.

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> cnt(13, 0);              // індекси 0..12; індекс 0 не використовуємо
    for (int i = 0; i < n; i++) {
        int v;
        cin >> v;
        cnt[v]++;
    }
    int best = 1;
    for (int v = 2; v <= 12; v++)
        if (cnt[v] > cnt[best]) best = v;
    cout << best << ' ' << cnt[best] << '\n';
}
```

Python:

```python
n = int(input())
cnt = [0] * 13                           # індекси 0..12; індекс 0 не використовуємо
for v in map(int, input().split()):
    cnt[v] += 1
best = 1
for v in range(2, 13):
    if cnt[v] > cnt[best]:
        best = v
print(best, cnt[best])
```

Для входу `8` / `5 12 7 5 9 5 12 7` відповідь `5 3`. Якщо ж значення сягають 10⁹, масив на 10⁹ елементів не вміститься в пам'ять. Тоді масив сортують ([тема 08](08-сортування.md)) або рахують через `map`/`dict` ([тема 10](10-структури-даних.md)).

### Таблиці

C++: `vector<vector<int>> g(n, vector<int>(m, 0));` — таблиця n × m із нулів, елемент `g[i][j]`.
Поле із символів зручно читати як масив рядків: `vector<string> g(n); for (auto& row : g) cin >> row;`.

Python: `g = [[0] * m for _ in range(n)]`. **Не пишіть** `[[0] * m] * n`: так усі рядки стануть одним і тим самим списком.

```python
g = [[0] * 3] * 2
g[0][0] = 1
print(g)          # [[1, 0, 0], [1, 0, 0]] — змінилися обидва рядки!
```

### Великі масиви в C++

Не оголошуйте великий масив як локальний усередині `main` (`int a[10000000];`): локальні змінні лежать у стеку, а він невеликий. На нашому комп'ютері така програма аварійно завершилася. Використовуйте `vector` або оголошуйте масив глобально, поза функціями.

## Типові задачі

- «Дано n чисел…»: мінімум, максимум, сума, кількість елементів із властивістю.
- «Порівняйте кожен елемент із сусідом», «скільки разів змінювалось», «найдовша серія однакових (зростаючих) елементів».
- «Скільки разів трапляється кожне значення», «яке значення найчастіше» при невеликих значеннях — масив частот.
- Таблиця або поле n × m: суми в рядках і стовпцях, сусідні клітинки.
- Два проходи: спершу знайти щось про весь масив (суму, максимум), потім пройти ще раз із цим знанням.

## Типові помилки

1. **Вихід за межі масиву:** `a[n]`, `a[i + 1]` на останньому кроці, `a[i - 1]` при `i = 0`. У C++ програма не обов'язково впаде, а просто прочитає «сміття». Як виявити: тест з n = 1 і компіляція з `-fsanitize=address,undefined` — тоді вихід за межі `vector` дає повідомлення `AddressSanitizer: heap-buffer-overflow`.
2. **Python: `a[-1]` — не помилка, а останній елемент.** Тому `a[i - 1]` при `i = 0` мовчки бере не той елемент.
3. **Мінімум починають з 0** або з «великого» числа, якого насправді замало (`1e9`, коли значення до 10¹⁸). Починайте з `a[0]`.
4. **`[[0] * m] * n` у Python.**
5. **Замалий масив частот:** для значень від 1 до 12 потрібен розмір 13. Або значення завеликі для масиву.
6. **Сума елементів у `int`.** 2·10⁵ чисел по 10⁹ дають 2·10¹⁴.
