## Що треба зрозуміти

Після цієї теми ви зможете:

1. Повторювати дію задану кількість разів (`for`) і доки виконується умова (`while`).
2. Накопичувати результат у циклі: суму, кількість, добуток, найбільше значення.
3. Розкладати число на цифри циклом `while`.
4. Писати вкладені цикли й рахувати, скільки разів виконається тіло.
5. Моделювати процес крок за кроком і правильно зупиняти цикл.
6. Помічати, коли накопичене значення не поміщається в `int`, і брати остачу за модулем, якщо цього вимагає умова.

## Теорія

### `for` і `while`

Сума чисел від 1 до n.

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long s = 0;             // сума до n(n+1)/2: при n = 10^6 це вже 5·10^11
    for (int i = 1; i <= n; i++) {
        s += i;
    }
    cout << s << '\n';
}
```

Python:

```python
n = int(input())
s = 0
for i in range(1, n + 1):   # числа 1, 2, ..., n — кінець range не входить!
    s += i
print(s)
```

`while` зручний, коли кількість кроків наперед невідома. Скільки разів треба поділити `n` навпіл (націло), щоб залишилась одиниця?

C++:

```cpp
long long n;
cin >> n;
int steps = 0;
while (n > 1) {
    n /= 2;
    steps++;
}
cout << steps << '\n';
```

Python:

```python
n = int(input())
steps = 0
while n > 1:
    n //= 2
    steps += 1
print(steps)
```

Для `n = 100` маємо 100 → 50 → 25 → 12 → 6 → 3 → 1, тобто 6 кроків. Кількість кроків приблизно дорівнює log₂ n, тому навіть для `n = 10¹⁸` цикл зробить лише близько 60 кроків.

### Читання n чисел

Щоб порахувати, скільки серед n чисел додатних, зберігати їх не обов'язково.

C++:

```cpp
int n;
cin >> n;
int cnt = 0;
for (int i = 0; i < n; i++) {
    long long x;
    cin >> x;
    if (x > 0) cnt++;
}
cout << cnt << '\n';
```

Python:

```python
n = int(input())
cnt = 0
for x in map(int, input().split()):   # усі n чисел записано в одному рядку
    if x > 0:
        cnt += 1
print(cnt)
```

### Цифри числа

C++:

```cpp
long long n;
cin >> n;
while (n > 0) {
    cout << n % 10 << ' ';   // остання цифра
    n /= 10;                 // відкидаємо її
}
cout << '\n';
```

Python:

```python
n = int(input())
while n > 0:
    print(n % 10, end=' ')   # остання цифра
    n //= 10                 # відкидаємо її
print()
```

Для `4729` програма виведе `9 2 7 4` — цифри з кінця. Зверніть увагу: при `n = 0` цикл не виконається жодного разу, хоча число 0 має одну цифру. Цей випадок треба продумати окремо.

### Вкладені цикли

C++:

```cpp
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 4; j++) {
        cout << i * j << ' ';
    }
    cout << '\n';
}
```

Python:

```python
for i in range(1, 4):
    for j in range(1, 5):
        print(i * j, end=' ')
    print()
```

Виведеться таблиця множення 3 × 4. Внутрішнє тіло виконається 3 · 4 = 12 разів. Якщо ж перебирати всі пари `i < j` з чисел від 1 до n, тіло виконається n(n − 1)/2 разів. Для n = 10⁵ це 5·10⁹ — забагато для 1 секунди (див. [тему 06](06-складність.md)).

### Моделювання процесу

Багато задач описують процес: «щосекунди відбувається…», «гравці по черзі…». Перш ніж писати цикл, дайте відповідь на три запитання:

1. Що змінюється на кожному кроці (які змінні)?
2. Коли процес зупиняється?
3. Скільки кроків буде в найгіршому випадку?

Якщо кроків до 10⁶–10⁷, а кожен крок — кілька операцій, пряме моделювання встигне. Якщо кроків може бути 10¹⁸, моделювати не можна, потрібна формула. Часто підзадачі з малими обмеженнями розраховані саме на пряме моделювання.

### Остача за модулем

Якщо відповідь величезна, умова часто просить вивести її остачу від ділення на 10⁹ + 7. Остачу беруть **після кожної операції**, бо (a · b) mod M = ((a mod M) · (b mod M)) mod M, і так само для суми. Наприклад, для M = 10: 17 · 23 = 391 дає остачу 1, і 7 · 3 = 21 теж дає остачу 1.

C++:

```cpp
const long long MOD = 1000000007;
long long r = 1;
for (int i = 0; i < 100; i++) {
    r = r * 3 % MOD;          // r < MOD, тому r * 3 поміщається в long long
}
cout << r << '\n';            // 3^100 mod (10^9 + 7) = 886041711
```

Python:

```python
MOD = 10**9 + 7
r = 1
for i in range(100):
    r = r * 3 % MOD
print(r)                      # 886041711, те саме дає pow(3, 100, MOD)
```

У Python цілі числа не переповнюються, але без остачі вони стали б дуже довгими й обчислення сповільнилися б.

### `break` і `continue`

`break` негайно завершує цикл (наприклад, коли потрібне число вже знайдено), `continue` переходить до наступного повторення.

## Типові задачі

- «Протягом n днів…», «для кожного з n чисел…» — `for` з лічильником або сумою.
- «Доки не…», «скільки кроків знадобиться…» — `while`.
- Цифри числа: сума, кількість, перевернуте число.
- Виведення таблиць і фігур із символів — вкладені цикли.
- Послідовності та прогресії: наступний член обчислюється через попередні.
- Моделювання процесу, особливо з підзадачами для малих обмежень.

## Типові помилки

1. **Межі циклу:** `<` чи `<=`; `range(n)` — це 0, 1, …, n − 1. Як виявити: тест з n = 1.
2. **Нескінченний `while`:** змінна з умови не змінюється або «перестрибує» умову зупинки (наприклад, `while (x != 0)` при x, що зменшується на 2 від непарного числа). Симптом — перевищення обмеження часу.
3. **Накопичувач не обнулили** або оголосили всередині циклу, тож він обнуляється на кожному кроці.
4. **Переповнення `int`** у сумі чи добутку. Як виявити: тест з найбільшими значеннями.
5. **n = 0 при розкладі на цифри.**
6. **Python: зміна змінної `for` усередині тіла нічого не дає.**

   ```python
   for i in range(3):
       print(i)
       i += 10      # не вплине: наступне i все одно візьметься з range
   ```

   Програма виведе 0, 1, 2. Якщо крок має бути змінним, пишіть `while`.

7. **Моделювання, коли кроків забагато.** Оцініть кількість кроків до написання коду.
