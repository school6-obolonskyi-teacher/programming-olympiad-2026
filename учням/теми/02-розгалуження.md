## Що треба зрозуміти

Після цієї теми ви зможете:

1. Записувати вибір між варіантами через `if` / `else if` / `else` (у Python — `if` / `elif` / `else`).
2. Порівнювати числа (`==`, `!=`, `<`, `<=`, `>`, `>=`) і поєднувати умови логічними операціями `&&`, `||`, `!` (`and`, `or`, `not`).
3. Розбивати задачу на випадки так, щоб кожен можливий вхід потрапив рівно в одну гілку, і окремо думати про рівність.
4. Виводити відповідь точно так, як вимагає умова (`YES`/`NO`, `Yes`/`No`, `ALICE`/`BOB`).
5. Самостійно складати тести на «пастки»: рівні числа, нулі, найбільші значення.

## Теорія

### `if` і `else`

Найбільше з трьох чисел.

C++:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long a, b, c;
    cin >> a >> b >> c;
    long long mx = a;          // поки що найбільше — перше число
    if (b > mx) mx = b;
    if (c > mx) mx = c;
    cout << mx << '\n';
}
```

Python:

```python
a, b, c = map(int, input().split())
mx = a                 # поки що найбільше — перше число
if b > mx:
    mx = b
if c > mx:
    mx = c
print(mx)
```

Те саме коротше: `max({a, b, c})` у C++ і `max(a, b, c)` у Python.

### Ланцюжок умов

Оцінка за кількістю балів: 90 і більше — `A`, від 75 — `B`, від 60 — `C`, інакше `F`.

C++:

```cpp
int s;
cin >> s;
if (s >= 90) cout << "A\n";
else if (s >= 75) cout << "B\n";
else if (s >= 60) cout << "C\n";
else cout << "F\n";
```

Python:

```python
s = int(input())
if s >= 90:
    print("A")
elif s >= 75:
    print("B")
elif s >= 60:
    print("C")
else:
    print("F")
```

Кожна наступна умова перевіряється, лише якщо всі попередні хибні. Тому порядок важливий: якби першою стояла перевірка `s >= 60`, то за 95 балів учень отримав би `C`.

Те саме з подільністю: якщо треба вивести `FizzBuzz` для чисел, кратних і 3, і 5, `Fizz` для кратних 3 і `Buzz` для кратних 5, то **найвужчий випадок перевіряйте першим**:

```python
n = int(input())
if n % 3 == 0 and n % 5 == 0:   # спершу «і 3, і 5»
    print("FizzBuzz")
elif n % 3 == 0:
    print("Fizz")
elif n % 5 == 0:
    print("Buzz")
else:
    print(n)
```

### Логічні операції

| C++ | Python | Значення |
|---|---|---|
| `&&` | `and` | і: обидві умови істинні |
| `\|\|` | `or` | або: хоча б одна умова істинна |
| `!` | `not` | не |

`&&` виконується раніше за `||` (так само `and` раніше за `or`). Щоб не помилитися, ставте дужки.

Чи лежить точка `(x, y)` у прямокутнику з кутами `(x1, y1)` і `(x2, y2)`, включно з межею:

```cpp
if (x1 <= x && x <= x2 && y1 <= y && y <= y2) cout << "YES\n";
else cout << "NO\n";
```

```python
if x1 <= x <= x2 and y1 <= y <= y2:   # у Python так писати можна
    print("YES")
else:
    print("NO")
```

**Увага:** у C++ запис `1 <= x <= 3` компілюється, але означає зовсім інше:

```cpp
int x = 5;
if (1 <= x <= 3) cout << "YES\n";   // виведе YES! Спершу (1 <= x) дає 1, а 1 <= 3 — істина
else cout << "NO\n";
```

Друга частина умови з `&&` обчислюється лише тоді, коли перша істинна. Тому запис `b != 0 && a % b == 0` безпечний: при `b = 0` ділення не відбудеться.

### Як не пропустити випадок

- Намалюйте числову пряму або таблицю всіх випадків.
- Окремо подумайте про рівність: `<` чи `<=`? Що, якщо числа однакові?
- Окремо подумайте про нуль і найбільші значення.
- Якщо варіантів мало (наприклад, чотири цифри), їх можна перебрати циклом ([тема 03](03-цикли.md)): програма сама нічого не пропустить.
- Шукайте умову, без якої відповідь точно неможлива (необхідну), а потім перевірте, чи її вистачає (чи вона достатня). Саме так розв'язуються задачі «Конструктор» і «Таємниця» з розборів I етапу.

### Переповнення в умовах

Якщо числа сягають 10⁹, сума двох ще поміщається в `int` (2·10⁹ < 2 147 483 647), а сума трьох — уже ні:

```cpp
int a = 1000000000, b = 1000000000, c = 1000000000;
cout << a + b + c << '\n';   // -1294967296 замість 3000000000
```

Тоді і порівняння `a + b + c > d` дасть неправильний результат. Беріть `long long`.

## Типові задачі

- Відповідь — одне з двох слів: `YES`/`NO`, `ALICE`/`BOB`; формулювання «чи можна…», «чи існує…».
- «Хто переможе», «хто отримає більше».
- Кілька діапазонів значень: тарифи, оцінки, категорії.
- Слова «хоча б один», «принаймні» підказують `||`; «обидва», «одночасно» — `&&`.
- «Чи можна скласти (розмістити, зафарбувати)…» — знайдіть необхідну умову й перевірте її достатність.
- Точка в прямокутнику, перетин відрізків на прямій, правило для дат (високосний рік).

## Типові помилки

1. **`=` замість `==` у C++.** `if (a = 5)` присвоює 5 і завжди істинне. Як виявити: компілюйте з `-Wall`, g++ попередить: `suggest parentheses around assignment used as truth value`.
2. **`1 <= x <= 3` у C++.** З `-Wall` g++ попереджає: `comparisons like 'X<=Y<=Z' do not have their mathematical meaning`.
3. **Неправильний порядок у ланцюжку `else if`.** Як виявити: тест, що підходить під дві гілки одночасно (у FizzBuzz — число 15).
4. **Пропущена рівність** (`<` замість `<=`). Як виявити: тест, де дві величини рівні.
5. **Інше написання відповіді.** У 2025–2026 задача «Матричка» вимагала `YES`/`NO`, а «Таємниця» — `Yes`/`No`. Копіюйте слова з умови, а не пишіть з пам'яті.
6. **Переповнення під час додавання чи множення в умові.** Як виявити: тест з найбільшими значеннями.
7. **Порівняння дробів через `double`.** Для додатних `b` і `d` умова `a/b < c/d` рівносильна `a·d < c·b` — порівнюйте цілі добутки (і стежте за переповненням).
