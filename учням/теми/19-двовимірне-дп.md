## Що треба зрозуміти

Після цієї теми ви зможете:

1. Розв'язувати рюкзак 0/1 таблицею `dp[i][j]` і пояснювати, що означає кожна клітинка.
2. Зводити таблицю рюкзака до одного рядка й пояснювати, чому вагу треба перебирати **справа наліво**.
3. Писати ДП на клітчастому полі: кількість шляхів і найбільший квадрат.
4. Розпізнавати задачі, де n ≤ 20 і стан — підмножина, та писати ДП за масками за O(2ⁿ · n).

## Теорія

### Рюкзак 0/1: таблиця

Є n предметів, у предмета i вага `w[i]` і цінність `v[i]`, місткість рюкзака W. Кожен предмет можна взяти не більше одного разу. Яка найбільша сумарна цінність?

Перебір усіх 2ⁿ наборів годиться лише для n ≤ 20 ([тема 13](13-рекурсія-та-перебір.md)). ДП:

- **стан:** `dp[i][j]` — найбільша цінність, яку можна набрати з перших i предметів, щоб вага не перевищила j;
- **перехід:** предмет i або не беремо (`dp[i−1][j]`), або беремо, якщо він вміщується (`dp[i−1][j − w[i]] + v[i]`);
- **база:** `dp[0][j] = 0` — без предметів цінність 0;
- **відповідь:** `dp[n][W]`.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, W;                        // предмети і місткість рюкзака
    cin >> n >> W;
    vector<int> w(n + 1);
    vector<long long> v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    // dp[i][j] — найбільша цінність з перших i предметів при вазі не більше j
    vector<vector<long long>> dp(n + 1, vector<long long>(W + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 0; j <= W; j++) {
            dp[i][j] = dp[i - 1][j];                             // предмет i не беремо
            if (j >= w[i])
                dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i]] + v[i]);   // беремо
        }
    cout << dp[n][W] << '\n';
}
```

Для `n = 4`, `W = 7` і предметів (вага, цінність) `(3, 4)`, `(4, 5)`, `(2, 3)`, `(5, 7)` програма виведе 10: предмети 3 і 4 разом важать 7.

Час і пам'ять — O(n · W). Таблиця для n = 1000 і W = 10⁵ — це 10⁸ чисел `long long`, 800 МБ: не вміститься.

### Рюкзак в одному рядку: чому справа наліво

Рядок `i` таблиці залежить лише від рядка `i − 1`. Тож можна тримати один масив `dp[j]` і оновлювати його на місці. Пастка: `dp[j]` бере значення `dp[j − w]`, і воно має бути ще **старим**, з попереднього рядка. Якщо йти по j справа наліво, `dp[j − w]` (ліва клітинка) ще не оновлена в цьому раунді — усе правильно. Якщо зліва направо, `dp[j − w]` уже може містити поточний предмет, і він «візьметься» вдруге.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, W;
    cin >> n >> W;
    vector<long long> dp(W + 1, 0);  // dp[j] — найбільша цінність при вазі не більше j
    for (int i = 0; i < n; i++) {
        int w;
        long long v;
        cin >> w >> v;
        for (int j = W; j >= w; j--)          // справа наліво!
            dp[j] = max(dp[j], dp[j - w] + v);
    }
    cout << dp[W] << '\n';
}
```

### ДП на полі: шляхи і найбільший квадрат

Поле n × m з вільних клітинок `.` і перешкод `#`.

**Кількість шляхів** з лівого верхнього кута в правий нижній, якщо ходити лише вправо і вниз. У клітинку (i, j) можна прийти лише згори або зліва, тож `ways[i][j] = ways[i−1][j] + ways[i][j−1]`, а для перешкоди — 0. Шляхів буває дуже багато, тому відповідь зазвичай просять за модулем 10⁹ + 7.

**Найбільший квадрат з вільних клітинок.** `side[i][j]` — сторона найбільшого вільного квадрата, у якого (i, j) — правий нижній кут. Квадрат зі стороною s з кутом у (i, j) існує тоді й лише тоді, коли квадрати зі стороною s − 1 є з кутами в трьох сусідах: згори, зліва і по діагоналі. Тому `side[i][j] = 1 + min(side[i−1][j], side[i][j−1], side[i−1][j−1])`, а для перешкоди — 0.

Обидві таблиці заповнюються в одному проході рядок за рядком: на момент обчислення (i, j) клітинки згори і зліва вже готові.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> g(n);             // '.' — вільно, '#' — перешкода
    for (auto& row : g) cin >> row;

    const long long MOD = 1000000007;
    // ways[i][j] — кількість шляхів з (0, 0) у (i, j) кроками вправо і вниз
    vector<vector<long long>> ways(n, vector<long long>(m, 0));
    // side[i][j] — сторона найбільшого квадрата з '.', правий нижній кут якого (i, j)
    vector<vector<int>> side(n, vector<int>(m, 0));
    int best = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            if (g[i][j] == '#') continue;            // тут обидві таблиці лишаються 0
            if (i == 0 && j == 0) ways[i][j] = 1;
            else {
                if (i > 0) ways[i][j] += ways[i - 1][j];   // прийшли згори
                if (j > 0) ways[i][j] += ways[i][j - 1];   // прийшли зліва
                ways[i][j] %= MOD;
            }
            if (i == 0 || j == 0) side[i][j] = 1;
            else side[i][j] = 1 + min({side[i - 1][j], side[i][j - 1], side[i - 1][j - 1]});
            best = max(best, side[i][j]);
        }
    cout << ways[n - 1][m - 1] << ' ' << best << '\n';
}
```

### ДП за масками (n ≤ 20)

Коли n ≤ 20, підмножину з n елементів зручно записувати числом-маскою від 0 до 2ⁿ − 1: біт j дорівнює 1, якщо елемент j у підмножині ([тема 13](13-рекурсія-та-перебір.md)). Тоді «множину вже використаних елементів» можна зробити станом ДП.

Задача: n учнів і n завдань, `cost[i][j]` — скільки хвилин учень i витратить на завдання j. Кожен учень отримує рівно одне завдання. Найменша сумарна кількість хвилин? Перебір усіх перестановок — n!, для n = 20 це 2,4·10¹⁸. ДП:

- **стан:** `dp[mask]` — найменша сума, якщо перші k учнів (k — кількість одиниць у mask) отримали саме завдання з маски;
- **перехід:** учень k бере вільне завдання j: `dp[mask | 1 << j] = min(…, dp[mask] + cost[k][j])`;
- **база:** `dp[0] = 0`; **відповідь:** `dp[2ⁿ − 1]`.

Маски перебираємо за зростанням: `mask | 1 << j` завжди більша за `mask`, тож до неї ми дійдемо пізніше.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;                           // n <= 20 учнів і n завдань
    cin >> n;
    vector<vector<long long>> cost(n, vector<long long>(n));
    for (auto& row : cost)
        for (auto& x : row) cin >> x;

    // dp[mask] — найменша сума, якщо перші popcount(mask) учнів
    // уже отримали саме завдання з множини mask (біт j — завдання j)
    const long long INF = LLONG_MAX / 2;
    vector<long long> dp(1 << n, INF);
    dp[0] = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        if (dp[mask] == INF) continue;
        int i = __builtin_popcount(mask);        // наступний учень
        if (i == n) continue;
        for (int j = 0; j < n; j++)
            if (!(mask >> j & 1))                // завдання j ще вільне
                dp[mask | 1 << j] = min(dp[mask | 1 << j], dp[mask] + cost[i][j]);
    }
    cout << dp[(1 << n) - 1] << '\n';
}
```

<summary>Python</summary>

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    cost = [list(map(int, data[1 + i * n:1 + (i + 1) * n])) for i in range(n)]
    INF = float("inf")
    full = (1 << n) - 1
    dp = [INF] * (1 << n)
    dp[0] = 0
    for mask in range(full):
        if dp[mask] == INF:
            continue
        i = bin(mask).count("1")         # наступний учень
        row = cost[i]
        for j in range(n):
            if not mask >> j & 1:        # завдання j ще вільне
                nm = mask | 1 << j
                if dp[mask] + row[j] < dp[nm]:
                    dp[nm] = dp[mask] + row[j]
    print(dp[full])

main()
```

## Типові задачі

- «Вибрати предмети з обмеженням на сумарну вагу (час, гроші) і найбільшою цінністю» — рюкзак 0/1.
- «Чи можна набрати суму рівно S», «скільки різних сум можна набрати» — рюкзак з `bool` замість цінностей.
- «Кількість шляхів у полі з перешкодами», «шлях з найбільшою сумою, рухаючись вправо і вниз» — ДП на полі.
- «Найбільший квадрат (прямокутник) з однакових клітинок» — ДП на полі або стек ([тема 16](16-стек-і-дек.md)).
- «n ≤ 20; розподілити, впорядкувати, обійти всі» — ДП за масками.
- Два рядки чи масиви: найбільша спільна підпослідовність, редакційна відстань — `dp[i][j]` за префіксами обох.

## Типові помилки

1. **Одновимірний рюкзак зліва направо:** предмет береться кілька разів. Як виявити: один предмет, у який рюкзак вміщується двічі.
2. **Таблиця n × W не вміщується в пам'ять:** порахуйте `n · W · 8` байтів до написання коду.
3. **На полі не обробили перешкоду або першу клітинку:** шляхи «проходять крізь стіни», або старт сам є перешкодою.
4. **`int` для кількості шляхів без модуля:** на полі 30 × 30 шляхів уже понад 10¹⁶.
5. **Пріоритет операцій з масками:** `mask & 1 << j == 0` у C++ означає `mask & ((1 << j) == 0)`. Пишіть `!(mask >> j & 1)` або ставте дужки.
6. **ДП за масками при n = 25–30:** 2³⁰ станів — понад мільярд, не вміститься ні в час, ні в пам'ять.
