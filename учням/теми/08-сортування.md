## Що треба зрозуміти

Після цієї теми ви зможете:

1. Сортувати масив за зростанням і спаданням стандартними засобами (`sort` у C++, `sort`/`sorted` у Python), які працюють за O(n log n).
2. Сортувати пари й записи за кількома ознаками: власним компаратором у C++ і параметром `key` у Python.
3. Сортувати підрахунком за O(n + K), коли значення лежать у невеликому діапазоні від 0 до K.
4. Пояснювати й писати сортування бульбашкою (воно O(n²)) і рахувати кількість обмінів.
5. Пояснювати, що дає відсортований масив: однакові елементи поруч, медіана в середині, можливість двійкового пошуку й жадібних рішень.

## Теорія

Фрагменти C++ у цій темі — це частини програми: вставляйте їх у `main` шаблону з [теми 01](01-перші-програми.md#каркас-програми).

### Стандартне сортування

C++:

```cpp
vector<int> a = {5, 2, 9, 1, 5};
sort(a.begin(), a.end());                    // 1 2 5 5 9
sort(a.begin(), a.end(), greater<int>());    // 9 5 5 2 1
```

Python:

```python
a = [5, 2, 9, 1, 5]
a.sort()                     # змінює сам список: [1, 2, 5, 5, 9]
b = sorted(a, reverse=True)  # новий список: [9, 5, 5, 2, 1]
```

Стандартні сортування працюють за O(n log n): для n = 2·10⁵ це близько 4·10⁶ порівнянь.

### Сортування пар і за кількома ознаками

Пари (`pair` у C++, кортежі в Python) порівнюються спершу за першим елементом, а при рівності — за другим. Тому, якщо треба відсортувати числа й не загубити їхні початкові позиції, сортуйте пари `(значення, індекс)`.

Приклад: вишикуйте учнів за зростом і виведіть їхні номери. Якщо відсортувати сам масив зростів, номери загубляться: буде відомо, що найнижчий учень має 152 см, але не відомо, хто це.

C++:

```cpp
vector<int> h = {160, 152, 171, 152};             // зріст учнів 1, 2, 3, 4
int n = h.size();
vector<pair<int, int>> p(n);
for (int i = 0; i < n; i++) p[i] = {h[i], i + 1}; // пара (зріст, номер)
sort(p.begin(), p.end());
for (auto& [height, id] : p) cout << id << ' ';   // 2 4 1 3
cout << '\n';
```

Python:

```python
h = [160, 152, 171, 152]                          # зріст учнів 1, 2, 3, 4
p = sorted((h[i], i + 1) for i in range(len(h)))  # пари (зріст, номер)
print(*[i for _, i in p])                         # 2 4 1 3
```

Учні 2 і 4 однакового зросту стоять у порядку номерів: при рівних перших елементах пари порівнюються за другим.

Щоб сортувати за власним правилом, у C++ передають **компаратор** — функцію, яка відповідає на запитання «чи має `x` стояти раніше за `y`?». Відсортуємо слова за довжиною, а слова однакової довжини — за абеткою.

C++:

```cpp
vector<string> w = {"pear", "fig", "apple", "kiwi", "banana"};
sort(w.begin(), w.end(), [](const string& x, const string& y) {
    if (x.size() != y.size()) return x.size() < y.size();
    return x < y;
});
for (auto& s : w) cout << s << ' ';          // fig kiwi pear apple banana
cout << '\n';
```

Python:

```python
w = ["pear", "fig", "apple", "kiwi", "banana"]
w.sort(key=lambda s: (len(s), s))            # спершу довжина, потім абетка
print(*w)                                    # fig kiwi pear apple banana
```

У Python замість компаратора задають **ключ** — значення, за яким порівнювати. Щоб за однією ознакою сортувати за спаданням, а за іншою — за зростанням, змініть знак числа:

```python
res = [(90, "Ira"), (85, "Bob"), (90, "Ann")]
res.sort(key=lambda p: (-p[0], p[1]))        # бали за спаданням, імена за абеткою
print(res)                                   # [(90, 'Ann'), (90, 'Ira'), (85, 'Bob')]
```

**Компаратор має бути строгим:** `<`, а не `<=`. Для однакових елементів він мусить повертати `false`. Інакше `sort` у C++ може працювати неправильно або навіть вийти за межі масиву. У режимі налагодження (`-D_GLIBCXX_DEBUG`) g++ ловить таку помилку: `comparison doesn't meet irreflexive requirements`.

Сортування в Python **стабільне**: елементи з однаковим ключем зберігають початковий порядок. У C++ `sort` цього не гарантує; якщо порядок рівних важливий, використовуйте `stable_sort`.

### Сортування підрахунком

Якщо значення — цілі від 0 до K і K невелике (до 10⁶–10⁷), порахуйте, скільки разів трапляється кожне значення, і виведіть значення в порядку зростання стільки разів, скільки вони трапилися. Складність O(n + K), порівнянь немає зовсім.

C++:

```cpp
vector<int> a = {3, 0, 2, 3, 1, 0, 3};
int K = 3;
vector<int> cnt(K + 1, 0);
for (int x : a) cnt[x]++;
vector<int> sorted_a;
for (int v = 0; v <= K; v++)
    for (int k = 0; k < cnt[v]; k++) sorted_a.push_back(v);
for (int x : sorted_a) cout << x << ' ';     // 0 0 1 2 3 3 3
cout << '\n';
```

Python:

```python
a = [3, 0, 2, 3, 1, 0, 3]
K = 3
cnt = [0] * (K + 1)
for x in a:
    cnt[x] += 1
sorted_a = []
for v in range(K + 1):
    sorted_a.extend([v] * cnt[v])
print(*sorted_a)                             # 0 0 1 2 3 3 3
```

Якщо значення бувають від'ємними, зсуньте їх: зберігайте `x + зсув`.

### Сортування бульбашкою (навчальне)

На кожному проході порівнюємо сусідні елементи й міняємо їх місцями, якщо вони стоять неправильно. Після k-го проходу k найбільших елементів уже на своїх місцях. Складність O(n²), тому для n = 2·10⁵ воно непридатне. Але в задачах II етапу трапляються запитання на кшталт «скільки обмінів сусідніх елементів зробить бульбашка». Кожен обмін виправляє рівно одну **інверсію** — пару `i < j`, у якій `a[i] > a[j]`.

C++:

```cpp
vector<int> a = {5, 1, 4, 2, 3};
int n = a.size(), swaps = 0;
for (int i = 0; i < n; i++)
    for (int j = 0; j + 1 < n - i; j++)
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);
            swaps++;
        }
cout << swaps << '\n';                       // 6 — стільки інверсій у масиві
```

Python:

```python
a = [5, 1, 4, 2, 3]
n, swaps = len(a), 0
for i in range(n):
    for j in range(n - 1 - i):
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
            swaps += 1
print(swaps)                                 # 6
```

Схоже працює сортування вставками: кожен новий елемент «просувається» ліворуч, доки не стане на своє місце.

### Що дає відсортований масив

- Однакові значення стоять поруч — легко порахувати, скільки різних значень і скільки разів трапляється кожне.
- Мінімальна різниця між двома елементами — серед сусідніх пар.
- Медіана — елемент посередині.
- k-те найменше значення — `a[k − 1]` (індексація з 0).
- Можна шукати двійковим пошуком ([тема 09](09-двійковий-пошук.md)) і застосовувати два вказівники та жадібні алгоритми ([тема 12](12-два-вказівники-та-жадібні.md)).

## Типові задачі

- «Виведіть у порядку зростання», «k-те за величиною», «медіана».
- «Скільки різних значень», «яке значення трапляється найчастіше» при значеннях до 10⁹.
- «Найменша різниця між двома…», «чи є однакові».
- Розклад, рейтинг, таблиця результатів: сортування за кількома ознаками.
- «Скільки обмінів сусідніх елементів потрібно» — інверсії; при n до кількох тисяч досить O(n²).
- Значення в невеликому діапазоні (оцінки, вік, цифри) — сортування підрахунком.

## Типові помилки

1. **Компаратор з `<=`.** Як виявити: компіляція з `-D_GLIBCXX_DEBUG`.
2. **`a = a.sort()` у Python.** Метод `sort()` змінює список і повертає `None`, тож після цього `a` дорівнює `None`. Пишіть `a.sort()` або `a = sorted(a)`.
3. **Числа, прочитані як рядки,** сортуються лексикографічно: `"10"` стане перед `"9"`. Перетворюйте на `int`.
4. **Загублені початкові індекси.** Якщо відповідь — номери елементів, сортуйте пари `(значення, індекс)`.
5. **Бульбашка на великих даних.** n = 2·10⁵ дає близько 2·10¹⁰ порівнянь.
6. **Сортування всередині циклу**, коли достатньо відсортувати один раз до циклу.
7. **Сортування підрахунком з від'ємними значеннями або завеликим K** — вихід за межі масиву чи брак пам'яті.
