# Картка туру

Одна сторінка, яку ви заповнюєте на кожному турі: пробному, віртуальному і на справжній олімпіаді (на папері, якщо дозволено). Вона змушує зробити те, на чому найчастіше втрачають бали сильні учні: **спершу план, потім код**, і чесно порівняти план з тим, що вийшло.

Роздрукуйте (по одній на тур) або скопіюйте в текстовий файл.

## 1. Перші 15 хвилин: план

Прочитайте всі задачі. Для кожної заповніть рядок, ще не пишучи коду.

```
Тур: _____________________   Дата: ________   Початок: ____   Кінець: ____

Задача │ Найбільше n │ Яка складність │ План               │ Прогноз  │ Прогноз
       │ (і що ще)   │ встигне        │ повний / перебір / │ балів    │ хвилин
       │             │                │ підзадачі 1–2 / —  │          │
───────┼─────────────┼────────────────┼────────────────────┼──────────┼────────
   A   │             │                │                    │          │
   B   │             │                │                    │          │
   C   │             │                │                    │          │
   D   │             │                │                    │          │
   E   │             │                │                    │          │
   F   │             │                │                    │          │
   G   │             │                │                    │          │
   H   │             │                │                    │          │
───────┴─────────────┴────────────────┴────────────────────┼──────────┼────────
                                               Разом:      │          │
Порядок розв'язування: ____________________________________
```

Підказки до стовпців:

- **Найбільше n** — головне обмеження і як рахують бали: за кожен тест чи за підзадачі.
- **Яка складність встигне** — за таблицею з [теми 06](теми/06-складність.md): `n ≤ 20` — 2ⁿ; `n ≤ 5000` — n²; `n ≤ 2·10⁵` — n log n; `n ≤ 10¹⁸` — щось на кшталт log n чи формули.
- **План** — чесно: якщо повного розв'язку не видно, пишіть «перебір» і, за потестового оцінювання, «перебір + ідея» ([чому це вигідно](ПОРАДИ.md#потестове-оцінювання-не-залишайте-тестів-порожніми)).
- **Прогноз хвилин** — сума має бути меншою за тривалість туру щонайменше на 30 хвилин: запас на помилки.

## 2. Під час туру: хроніка

Коли закінчуєте працювати над задачею (повністю чи «поки що»), запишіть час і бали.

```
Задача │ Почав │ Перше відправлення │ Закінчив │ Бали │ Що завадило
───────┼───────┼────────────────────┼──────────┼──────┼─────────────────────
       │       │                    │          │      │
       │       │                    │          │      │
       │       │                    │          │      │
       │       │                    │          │      │
       │       │                    │          │      │
       │       │                    │          │      │
       │       │                    │          │      │
       │       │                    │          │      │
```

Правило 25 хвилин: якщо від останнього успіху (новий тест чи нова підзадача) минуло 25 хвилин, а ідеї немає, — запишіть, на чому зупинилися, і переходьте до іншої задачі.

## 3. Після туру: розбір за 10 хвилин

```
Прогноз: ____ балів     Факт: ____ балів     Різниця: ____

Де прогноз розійшовся з фактом найбільше і чому:
  1. ______________________________________________________________
  2. ______________________________________________________________

На що пішло більше часу, ніж планував:  __________________________
Що зроблю інакше на наступному турі (одна річ): ___________________
```

Різниця між прогнозом і фактом — найкорисніша цифра картки. Якщо ви систематично переоцінюєте себе на задачах F–H, виділяйте на A–E менше часу і раніше відправляйте перебір. Якщо недооцінюєте — сміливіше беріться за повні розв'язки.

## Тренувальний тур зі скриптом

На [тренувальному турі репозиторію](ПРОБНИЙ-ТУР.md) картку можна вести й у файлах. Тоді скрипт сам покаже, коли ви востаннє змінювали кожен розв'язок, і порівняє прогноз з результатом:

1. На початку туру:
   ```
   python інструменти/перевірити.py --тур мій-тур --старт
   ```
2. Після 15 хвилин планування створіть файл `мій-тур/прогноз.txt` — рядок на задачу: літера, прогноз балів і (за бажанням) хвилин:
   ```
   A: 100 10
   B: 100 10
   F: 60 40
   G: 30 30
   ```
3. Після туру `python інструменти/перевірити.py --тур мій-тур` виведе таблицю з колонками «прогноз», «різниця» і «остання зміна».
