## 🎯 Welcome!

This guide will help you prepare for the **2026 Programming Olympiad**. We have selected **7 interesting problems** that cover the main topics you'll encounter in the competition.

### 📋 How to Use This Guide

1. **Start with Beginner problems** (Problems 1, 2, 5)
2. **Read the theory section** before solving
3. **Solve independently** — don't look at solutions immediately!
4. **Check your answer** against test cases
5. **Study the solution** if you got stuck
6. **Move to next level** when ready

### ⏰ Time Investment
- **Beginner Level:** ~1.5 hours per problem
- **Intermediate Level:** ~2-2.5 hours per problem
- **Advanced Level:** ~3 hours per problem

## 💡 Tips for Success

### Before Contest:
1. ✅ Practice each problem type **at least twice**
2. ✅ Learn the template for your language
3. ✅ Know how to read input/output
4. ✅ Time yourself during practice

### During Contest:
1. 📖 **Read all problems** first (10 minutes)
2. 🎯 **Pick an easy one** to start
3. ⏱️ **Don't spend too long** on hard problems
4. ✅ **Test with examples** before submitting
5. 🔄 **Revisit easy ones** for points (80% time)

### Common Mistakes:
- ❌ Forgetting to read input completely
- ❌ Using `int` for large numbers (use `long long`)
- ❌ Off-by-one errors in loops
- ❌ Wrong output format (extra spaces, newlines)
- ❌ Not testing edge cases
