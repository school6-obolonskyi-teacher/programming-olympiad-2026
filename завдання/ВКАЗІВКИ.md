## 💡 Поради для успіху

### Перед змаганням:
1. ✅ Практикуйте **кожний тип завдання мінімум два рази**
2. ✅ Вивчіть шаблон для вашої мови програмування
3. ✅ Знайте, як читати введення та виводити результат
4. ✅ Хронометруйте себе під час тренування

### Під час змагання:
1. 📖 **Прочитайте всі завдання** спочатку (10 хвилин)
2. 🎯 **Виберіть легке завдання** для початку
3. ⏱️ **Не витрачайте багато часу** на складні завдання
4. ✅ **Протестуйте на прикладах** перед відправкою
5. 🔄 **Повернеться до легких завдань** для набрання балів (80% часу)

### Поширені помилки:
- ❌ Забування прочитати всі вхідні дані
- ❌ Використання `int` для великих чисел (використовуйте `long long`)
- ❌ Помилки на одиницю в циклах
- ❌ Неправильний формат виводу (зайві пробіли, переноси)
- ❌ Неперевірені граничні випадки
