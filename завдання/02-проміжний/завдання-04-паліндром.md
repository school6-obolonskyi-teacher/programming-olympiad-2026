# Завдання 4: Паліндром

## 📋 Опис задачі

Дано рядок. Необхідно перевірити, чи є цей рядок паліндромом (читається однаково спереду та ззаду, без врахування регістру літер).

**Мета:** Практика роботи з рядками та порівняннями символів.

## 📊 Вхідні та вихідні дані

**Вхід:** Один рядок, що містить латинські літери

**Вихід:** "ТАК" (YES) якщо паліндром, "НІ" (NO) якщо не паліндром

## 📈 Обмеження

- Час виконання: до 1 секунди
- Пам'ять: до 256 МБ
- Довжина рядка не перевищує 10000 символів

## 📌 Приклади

### Приклад 1

**Вхід:**
```
racecar
```

**Вихід:**
```
ТАК
```

**Пояснення:** "racecar" читається однаково в обох напрямках

### Приклад 2

**Вхід:**
```
hello
```

**Вихід:**
```
НІ
```

**Пояснення:** "hello" не є паліндромом

### Приклад 3

**Вхід:**
```
Aba
```

**Вихід:**
```
ТАК
```

**Пояснення:** Після зведення до малих літер: "aba" — паліндром

### Приклад 4

**Вхід:**
```
a
```

**Вихід:**
```
ТАК
```

**Пояснення:** Одна літера завжди паліндром

## 💡 Теорія та пояснення

### Що таке паліндром?

**Паліндром** — це слово, фраза, число або інша послідовність символів, яка читається однаково спереду та ззаду.

Приклади:
- "racecar" — паліндром
- "radar" — паліндром
- "hello" — не паліндром

### Алгоритм розв'язання

**Способ 1: Техніка двох вказівників**
1. Перетворюємо рядок на малі літери
2. Ініціалізуємо два вказівники: `left` на початку, `right` на кінці
3. Поки `left < right`:
   - Якщо символи не збігаються, повертаємо "НІ"
   - Переміщуємо вказівники один до одного
4. Якщо вказівники зійшлись, повертаємо "ТАК"

**Способ 2: Реверс рядка**
1. Перетворюємо рядок на малі літери
2. Порівнюємо рядок з його розворотом
3. Якщо вони рівні, це паліндром

### Приклад виконання (s = "Aba")

```
Крок 1: Зведемо до малих літер: "aba"
Крок 2: Порівняємо з розворотом: "aba" vs "aba"
Крок 3: Вони рівні → ТАК
```

### Складність розв'язання

- **Часова складність:** O(N) — один або два проходи по рядку
- **Просторова складність:** O(N) — зберігання рядка
