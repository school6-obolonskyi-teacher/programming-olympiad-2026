# Завдання 6: Анаграми

## 📋 Опис задачі

Дано два рядки. Необхідно перевірити, чи є вони анаграмами (містять одні й ті ж символи, але у різному порядку, без врахування регістру).

**Мета:** Практика роботи з рядками, сортуванням та порівняннями.

## 📊 Вхідні та вихідні дані

**Вхід:** 
- Перший рядок: перше слово
- Другий рядок: друге слово

**Вихід:** "ТАК" (YES) якщо анаграми, "НІ" (NO) якщо ні

## 📈 Обмеження

- Час виконання: до 1 секунди
- Пам'ять: до 256 МБ
- Довжина кожного рядка не перевищує 10000 символів

## 📌 Приклади

### Приклад 1

**Вхід:**
```
listen
silent
```

**Вихід:**
```
ТАК
```

**Пояснення:** "listen" та "silent" містять одні й ті ж літери

### Приклад 2

**Вхід:**
```
hello
world
```

**Вихід:**
```
НІ
```

**Пояснення:** "hello" та "world" не містять одні й ті ж літери

### Приклад 3

**Вхід:**
```
abc
cab
```

**Вихід:**
```
ТАК
```

**Пояснення:** Перестановка літер дає першу послідовність

### Приклад 4

**Вхід:**
```
ABA
Baa
```

**Вихід:**
```
ТАК
```

**Пояснення:** Після зведення до малих літер: "aba" та "baa" містять одні й ті ж літери

## 💡 Теорія та пояснення

### Що таке анаграма?

**Анаграма** — це перестановка букв слова або фрази, що утворює нове слово або фразу, використовуючи кожну букву оригіналу рівно один раз.

Приклади:
- "listen" та "silent" — анаграми
- "earth" та "heart" — анаграми
- "hello" та "world" — не анаграми

### Алгоритм розв'язання

**Способ 1: Сортування**
1. Перетворюємо обидва рядки на малі літери
2. Сортуємо символи в обох рядках
3. Порівнюємо відсортовані рядки
4. Якщо вони рівні, це анаграми

**Способ 2: Підрахунок частоти**
1. Перетворюємо на малі літери
2. Підраховуємо частоту кожного символу в обох рядках
3. Порівнюємо таблиці частот
4. Якщо вони рівні, це анаграми

### Приклад виконання (s1 = "listen", s2 = "silent")

```
Крок 1: Зведемо до малих: "listen", "silent"
Крок 2: Відсортуємо: "eilnst", "eilnst"
Крок 3: Порівняємо: "eilnst" == "eilnst"
Крок 4: Це анаграми → ТАК
```

### Складність розв'язання

**Способ 1 (Сортування):**
- **Часова:** O(N log N) — сортування домінує
- **Просторова:** O(N) — для зберігання відсортованих рядків

**Способ 2 (Підрахунок частоти):**
- **Часова:** O(N) — два проходи
- **Просторова:** O(1) — 26 букв максимум
