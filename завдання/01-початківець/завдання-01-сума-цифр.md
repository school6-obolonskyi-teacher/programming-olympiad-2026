# Завдання 1: Сума цифр

## 📋 Опис задачі

Дано натуральне число N. Необхідно знайти суму всіх цифр цього числа.

**Мета:** Навчитися розкладати число на цифри та виконувати операції з кожною цифрою.

## 📊 Вхідні та вихідні дані

**Вхід:** Одне натуральне число N (1 ≤ N ≤ 10⁹)

**Вихід:** Одне натуральне число — сума цифр числа N

## 📈 Обмеження

- Час виконання: до 1 секунди
- Пам'ять: до 256 МБ
- Число N не може бути більше 10⁹

## 📌 Приклади

### Приклад 1

**Вхід:**
```
123
```

**Вихід:**
```
6
```

**Пояснення:** 1 + 2 + 3 = 6

### Приклад 2

**Вхід:**
```
999
```

**Вихід:**
```
27
```

**Пояснення:** 9 + 9 + 9 = 27

### Приклад 3

**Вхід:**
```
1000
```

**Вихід:**
```
1
```

**Пояснення:** 1 + 0 + 0 + 0 = 1

## 💡 Теорія та пояснення

### Алгоритм розв'язання

Основна ідея — послідовно видаляти останню цифру числа і додавати її до суми.

**Шаги алгоритму:**
1. Ініціалізуємо змінну для суми як 0
2. Поки число більше 0:
   - Додаємо останню цифру (N % 10) до суми
   - Видаляємо останню цифру (N = N / 10)
3. Виводимо суму

### Приклад виконання (N = 123)

```
Ітерація 1: N = 123, остання цифра = 123 % 10 = 3, сума = 3
            N = 123 / 10 = 12
            
Ітерація 2: N = 12, остання цифра = 12 % 10 = 2, сума = 3 + 2 = 5
            N = 12 / 10 = 1
            
Ітерація 3: N = 1, остання цифра = 1 % 10 = 1, сума = 5 + 1 = 6
            N = 1 / 10 = 0
            
N = 0, цикл завершає. Результат: 6
```

### Складність розв'язання

- **Часова складність:** O(log N) — кількість ітерацій дорівнює кількості цифр у числі
- **Просторова складність:** O(1) — використовуємо тільки змінні
