# Завдання 2: Парні та непарні числа

## 📋 Опис задачі

Дано список з N чисел. Необхідно підрахувати, скільки серед них парних та скільки непарних.

**Мета:** Практика роботи з умовами (if-else) та циклами.

## 📊 Вхідні та вихідні дані

**Вхід:** 
- Перший рядок: натуральне число N (1 ≤ N ≤ 1000)
- Другий рядок: N цілих чисел, розділених пробілами

**Вихід:** Два числа через пробіл: кількість парних, кількість непарних

## 📈 Обмеження

- Час виконання: до 1 секунди
- Пам'ять: до 256 МБ
- Числа можуть бути від -10⁹ до 10⁹

## 📌 Приклади

### Приклад 1

**Вхід:**
```
5
1 2 3 4 5
```

**Вихід:**
```
2 3
```

**Пояснення:** Парні: 2, 4 (2 числа). Непарні: 1, 3, 5 (3 числа)

### Приклад 2

**Вхід:**
```
4
10 20 30 40
```

**Вихід:**
```
4 0
```

**Пояснення:** Всі числа парні (4 числа). Непарних немає.

### Приклад 3

**Вхід:**
```
3
-1 -2 -3
```

**Вихід:**
```
1 2
```

**Пояснення:** Парні: -2 (1 число). Непарні: -1, -3 (2 числа)

## 💡 Теорія та пояснення

### Як визначити парність числа?

Число вважається **парним**, якщо воно ділиться на 2 без залишку, тобто `число % 2 == 0`.

Число вважається **непарним**, якщо `число % 2 != 0` (або `число % 2 == 1` для позитивних чисел).

### Алгоритм розв'язання

1. Читаємо кількість чисел N
2. Ініціалізуємо лічильники: `even = 0`, `odd = 0`
3. Для кожного числа:
   - Якщо число % 2 == 0, то ++even
   - Інакше ++odd
4. Виводимо `even` та `odd`

### Приклад виконання (N = 5, [1, 2, 3, 4, 5])

```
Число 1: 1 % 2 = 1 ≠ 0 → непарне, odd = 1
Число 2: 2 % 2 = 0 → парне, even = 1
Число 3: 3 % 2 = 1 ≠ 0 → непарне, odd = 2
Число 4: 4 % 2 = 0 → парне, even = 2
Число 5: 5 % 2 = 1 ≠ 0 → непарне, odd = 3

Результат: 2 3
```

### Складність розв'язання

- **Часова складність:** O(N) — один проход по всіх числах
- **Просторова складність:** O(1) — тільки лічильники
