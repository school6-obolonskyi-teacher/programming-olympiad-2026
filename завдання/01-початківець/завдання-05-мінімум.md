# Завдання 5: Пошук мінімуму

## 📋 Опис задачі

Дано масив з N чисел. Необхідно знайти мінімальне значення в цьому масиві.

**Мета:** Практика роботи з масивами та порівняннями.

## 📊 Вхідні та вихідні дані

**Вхід:** 
- Перший рядок: натуральне число N (1 ≤ N ≤ 10000)
- Другий рядок: N цілих чисел, розділених пробілами

**Вихід:** Одне число — мінімальне значення в масиві

## 📈 Обмеження

- Час виконання: до 1 секунди
- Пам'ять: до 256 МБ
- Числа можуть бути від -10⁹ до 10⁹

## 📌 Приклади

### Приклад 1

**Вхід:**
```
5
3 7 2 9 1
```

**Вихід:**
```
1
```

**Пояснення:** Мінімальне число в масиві [3, 7, 2, 9, 1] це 1

### Приклад 2

**Вхід:**
```
3
-5 -10 -2
```

**Вихід:**
```
-10
```

**Пояснення:** Мінімальне число це -10

### Приклад 3

**Вхід:**
```
1
42
```

**Вихід:**
```
42
```

**Пояснення:** У масиві одне число, воно й є мінімумом

## 💡 Теорія та пояснення

### Алгоритм розв'язання

Найпростіший спосіб — зберегти перше число як "мінімум" і потім порівняти його з кожним наступним числом.

**Шаги алгоритму:**
1. Читаємо кількість чисел N
2. Читаємо всі числа в масив
3. Ініціалізуємо `min_val` першим елементом масиву
4. Для кожного наступного числа:
   - Якщо число менше за `min_val`, оновлюємо `min_val`
5. Виводимо `min_val`

### Приклад виконання (N = 5, [3, 7, 2, 9, 1])

```
min_val = 3 (перший елемент)

Число 7: 7 < 3? Ні, min_val = 3
Число 2: 2 < 3? Так, min_val = 2
Число 9: 9 < 2? Ні, min_val = 2
Число 1: 1 < 2? Так, min_val = 1

Результат: 1
```

### Альтернативний спосіб (Python)

У Python існує вбудована функція `min()`:
```python
min_val = min(numbers)
```

### Складність розв'язання

- **Часова складність:** O(N) — один проход по всіх числах
- **Просторова складність:** O(N) — зберігання масиву
