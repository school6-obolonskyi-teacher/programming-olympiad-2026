## Навчальна мета

Навчитися «розбирати» число на цифри за допомогою остачі від ділення на 10 і цілочисельного ділення, а також обирати тип змінної за найбільшим можливим значенням.

## Що треба знати перед початком

- цикл `while` ([тема 03](../../учням/теми/03-цикли.md));
- операції з цілими числами: остача від ділення `%` і цілочисельне ділення (`/` у C++, `//` у Python) ([тема 01](../../учням/теми/01-перші-програми.md));
- типи `int` і `long long` у C++ та межі їхніх значень ([тема 06](../../учням/теми/06-складність.md)).

## Умова

Ярина збирає старі проїзні квитки. На кожному квитку надруковано номер — натуральне число `N`. Щоб розкласти квитки по коробках, Ярина для кожного номера рахує суму його цифр.

Номери бувають дуже довгими, тож рахувати вручну Ярині набридло. Напишіть програму, яка за номером `N` знаходить суму його цифр.

## Вхідні дані

Один рядок містить натуральне число `N` (без провідних нулів).

## Вихідні дані

Виведіть одне ціле число — суму цифр числа `N`.

## Обмеження

- `1 ≤ N ≤ 10¹⁸`

## Підзадачі

| № | Бали | Додаткові обмеження |
|---|---|---|
| 1 | 50 | `N ≤ 10⁹` |
| 2 | 50 | без додаткових обмежень |

Як і на олімпіаді, бали за підзадачу нараховуються, лише якщо пройдено **всі** її тести.

**Вхід**
```
123
```

**Вихід**
```
6
```

**Вхід**

**Вихід**
```
1
```

**Вхід**
```
1000000000000000000
```

**Вихід**
```
1
```

## Пояснення прикладів

1. `1 + 2 + 3 = 6`.
2. `9 + 9 + 9 = 27`.
3. `1 + 0 + 0 + 0 = 1`: нулі теж є цифрами числа, але до суми нічого не додають.
4. Число `10¹⁸` — це одиниця і вісімнадцять нулів, тому сума цифр дорівнює `1`. Це найбільше можливе `N`.

<summary>Підказка 1 — з чого почати</summary>

Як дістати **останню** цифру числа однією арифметичною операцією? А яка операція «відкидає» останню цифру, тобто з `123` робить `12`?

</details>

<details>
<summary>Підказка 2 — ідея</summary>

Повторюйте ці дві дії в циклі, доки від числа ще щось залишається. Коли цикл має зупинитися? Скільки разів він виконається для числа з 18 цифр?

</details>

<details>
<summary>Підказка 3 — про тип даних</summary>

У C++ змінна типу `int` вміщує числа лише до `2 147 483 647 ≈ 2,1·10⁹`. Чи вміститься в неї `N = 10¹⁸`? Саме цим відрізняються підзадачі 1 і 2. А чи потрібен великий тип для самої суми цифр — яка найбільша сума можлива?

</details>

## Самоперевірка

Перш ніж надсилати розв'язок, перевірте себе:

- `N = 1` (одна цифра);
- число з нулями всередині й наприкінці, наприклад `505` або `1000`;
- число з вісімнадцяти дев'яток;
- `N = 10¹⁸`;
- число трохи більше за `2 147 483 647`, наприклад `2147483648`, — чи не змінюється воно під час читання?
