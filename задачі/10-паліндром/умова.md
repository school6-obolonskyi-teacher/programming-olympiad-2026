## Навчальна мета

Навчитися звертатися до символів рядка за індексами з обох кінців, порівнювати символи без урахування регістру і виводити відповідь у форматі `YES`/`NO`.

## Що треба знати перед початком

- рядки: довжина, доступ до символу за індексом, перетворення літери на малу ([тема 05](../../учням/теми/05-рядки.md));
- цикли ([тема 03](../../учням/теми/03-цикли.md)).

## Умова

Мирослава знайшла на горищі скриньку зі старими записками. Деякі записки «дзеркальні»: вони однаково читаються зліва направо і справа наліво. Автор записок не розрізняв великих і малих літер, тому, наприклад, `Aba` теж дзеркальна. Такі рядки називають **паліндромами**.

Допоможіть Мирославі: за текстом записки визначте, чи є він паліндромом без урахування регістру літер.

## Вхідні дані

Один рядок `s`, що складається з латинських літер (`a`–`z`, `A`–`Z`) і цифр (`0`–`9`). Пробілів та інших символів у рядку немає.

## Вихідні дані

Виведіть `YES`, якщо рядок є паліндромом без урахування регістру літер, і `NO` в іншому випадку.

## Обмеження

- `1 ≤ n ≤ 2·10⁵`, де `n` — довжина рядка `s`.

## Підзадачі

| № | Бали | Додаткові обмеження |
|---|---|---|
| 1 | 30 | `n ≤ 1000`, у рядку немає великих літер |
| 2 | 30 | `n ≤ 1000` |
| 3 | 40 | без додаткових обмежень |

Бали за підзадачу нараховуються, лише якщо пройдено **всі** її тести: так оцінюють на III етапі й на олімпіадах формату IOI. На I і II етапах 2025/2026 бали давали за кожен пройдений тест окремо, тож там і неповний розв'язок підзадачі приносить частину балів.

## Приклади

**Вхід**
```
racecar
```

**Вихід**
```
YES
```

**Вхід**
```
hello
```

**Вихід**
```
NO
```

**Вхід**
```
Aba
```

**Вихід**
```
YES
```

**Вхід**
```
a
```

**Вихід**
```
YES
```

## Пояснення прикладів

1. `racecar` справа наліво — теж `racecar`.
2. `hello` справа наліво — `olleh`, це інший рядок.
3. Якщо не зважати на регістр, `Aba` — це `aba`, а справа наліво — знову `aba`.
4. Рядок з одного символу завжди паліндром.

## Самоперевірка

Перш ніж надсилати розв'язок, перевірте себе:

- рядок з одного символу; з двох однакових і з двох різних символів;
- паліндроми парної (`abba`) і непарної (`aba`) довжини;
- рядок, у якого збігаються крайні символи, але не збігаються внутрішні (`abca`);
- рядок, що відрізняється лише регістром (`zZ`), і рядок з цифрами (`121`);
- рядок довжиною `2·10⁵`: чи встигає програма?
- чи виводите ви саме `YES`/`NO` латиницею?

Автоматична перевірка на тестах репозиторію (див. [довідка/СЕРЕДОВИЩЕ.md](../../довідка/СЕРЕДОВИЩЕ.md)):

```
python інструменти/перевірити.py 10 мій_розвязок.cpp
```
