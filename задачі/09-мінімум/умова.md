## Навчальна мета

Навчитися знаходити найменше значення одним проходом і правильно вибирати початкове значення мінімуму.

## Що треба знати перед початком

- цикли й масиви ([тема 04](../../учням/теми/04-масиви.md));
- оцінка кількості операцій: чому `n²` при `n = 2·10⁵` — забагато ([тема 06](../../учням/теми/06-складність.md)).

## Умова

Марсохід проїхав маршрутом і в `n` точках виміряв висоту поверхні відносно нульового рівня Марса в міліметрах. Від'ємна висота означає, що точка лежить нижче нульового рівня, додатна — вище.

Учені хочуть знати висоту найнижчої точки маршруту. Знайдіть найменше з чисел `a₁, a₂, …, aₙ`.

## Вхідні дані

Перший рядок містить ціле число `n` — кількість вимірювань.

Другий рядок містить `n` цілих чисел `a₁, a₂, …, aₙ` — виміряні висоти.

## Вихідні дані

Виведіть одне ціле число — найменше серед `aᵢ`.

## Обмеження

- `1 ≤ n ≤ 2·10⁵`
- `−10⁹ ≤ aᵢ ≤ 10⁹`

## Підзадачі

| № | Бали | Додаткові обмеження |
|---|---|---|
| 1 | 30 | `n ≤ 1000`, усі `aᵢ ≤ 0` (увесь маршрут не вище нульового рівня) |
| 2 | 30 | `n ≤ 1000` |
| 3 | 40 | без додаткових обмежень |

Як і на олімпіаді, бали за підзадачу нараховуються, лише якщо пройдено **всі** її тести.

## Приклади

**Вхід**
```
5
3 7 2 9 1
```

**Вихід**
```
1
```

**Вхід**
```
3
-5 -10 -2
```

**Вихід**
```
-10
```

**Вхід**
```
1
42
```

**Вихід**
```
42
```

## Пояснення прикладів

1. Найнижча точка маршруту має висоту `1` мм над нульовим рівнем.
2. Усі точки нижче нульового рівня, найнижча з них — `−10`.
3. Вимірювання одне, тож воно й найменше.

## Підказки

<details>
<summary>Підказка 1 — з чого почати</summary>

Уявіть, що числа вам диктують по одному і записати їх не можна. Яке одне число треба тримати в пам'яті, щоб наприкінці назвати відповідь?

</details>

<details>
<summary>Підказка 2 — ідея</summary>

Тримайте «найменше з уже прочитаних» і порівнюйте з ним кожне нове число. Головне питання — яким має бути це значення **до** того, як прочитано хоч щось?

</details>

<details>
<summary>Підказка 3 — пастка</summary>

Якщо початкове значення мінімуму — якась стала, перевірте, чи не може вона виявитися меншою за **всі** числа. Подивіться на перший і третій приклади. Чи є початкове значення, яке точно не підведе, хоч би якими були межі?

</details>

## Самоперевірка

Перш ніж надсилати розв'язок, перевірте себе:

- `n = 1`;
- усі числа додатні; усі числа від'ємні;
- усі числа однакові й дорівнюють `10⁹`;
- найменше число стоїть першим; останнім;
- `n = 2·10⁵`: чи встигає програма і чи не замалий у ній масив?

Автоматична перевірка на тестах репозиторію (див. [довідка/СЕРЕДОВИЩЕ.md](../../довідка/СЕРЕДОВИЩЕ.md)):

```

```
