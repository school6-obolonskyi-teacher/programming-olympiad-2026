## Як працювати із задачею

1. Прочитайте умову, розв'яжіть приклади вручну.
2. Напишіть розв'язок, хоча б на першу підзадачу.
3. Перевірте його скриптом із кореня репозиторію:
   ```
   python інструменти/перевірити.py 05 мій.cpp
   ```
   Скрипт покаже, скільки тестів пройдено і скільки балів набрано за підзадачами.
4. Застрягли? Відкривайте підказки по одній.
5. Після розв'язання (або після 2–3 невдалих спроб) прочитайте розбір: посилання є в кінці кожної умови.

Тести лежать у теці `тести/` кожної задачі. Великі тести не зберігаються у файлах: скрипт генерує їх під час перевірки (список — у `тести/генерувати.txt`).
