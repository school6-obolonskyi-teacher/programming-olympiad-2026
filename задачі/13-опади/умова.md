## Навчальна мета

Навчитися відповідати на багато запитів «сума на відрізку» за O(1) кожен за допомогою префіксних сум, а також помічати, коли сума не вміщується в 32-бітний `int`.

## Що треба знати перед початком

- цикли та масиви ([тема 04](../../учням/теми/04-масиви.md));
- оцінка складності: чому 2·10⁵ × 2·10⁵ операцій — забагато ([тема 06](../../учням/теми/06-складність.md));
- типи `int` і `long long` у C++ і межі їхніх значень ([тема 06](../../учням/теми/06-складність.md)).

## Умова

Шкільна метеостанція протягом `n` днів записувала кількість опадів: у день `i` випало `aᵢ` міліметрів.

Учні ставлять `q` запитань. Кожне запитання — два числа `l` і `r`: скільки міліметрів опадів випало сумарно з дня `l` по день `r` включно?

Дайте відповідь на всі запитання.

## Вхідні дані

Перший рядок містить два цілі числа `n` і `q` — кількість днів і кількість запитань.

Другий рядок містить `n` цілих чисел `a₁, a₂, …, aₙ` — опади за кожен день.

Кожен із наступних `q` рядків містить два цілі числа `l` і `r` — межі чергового запитання.

## Вихідні дані

Виведіть `q` рядків: у `j`-му рядку — суму `a_l + a_(l+1) + … + a_r` для `j`-го запитання.

## Обмеження

- `1 ≤ n, q ≤ 2·10⁵`
- `0 ≤ aᵢ ≤ 10⁹`
- `1 ≤ l ≤ r ≤ n`

## Підзадачі

| № | Бали | Додаткові обмеження |
|---|---|---|
| 1 | 30 | `n, q ≤ 1000` |
| 2 | 30 | `aᵢ ≤ 10⁴` |
| 3 | 40 | без додаткових обмежень |

Як і на олімпіаді, бали за підзадачу нараховуються, лише якщо пройдено **всі** її тести.

## Приклади

**Вхід**
```
5 3
4 0 7 1 3
1 5
2 3
4 4
```

**Вихід**
```
15
7
1
```

**Вхід**
```
1 1
1000000000
1 1
```

**Вихід**
```
1000000000
```

## Пояснення прикладів

У першому прикладі: дні 1–5 дають `4 + 0 + 7 + 1 + 3 = 15`; дні 2–3 — `0 + 7 = 7`; день 4 — `1`.

У другому прикладі один день і одне запитання про цей день.

## Підказки

<details>
<summary>Підказка 1 — з чого почати</summary>

Напишіть спершу простий розв'язок: для кожного запитання пройдіть циклом від `l` до `r`. Скільки операцій він виконає в найгіршому випадку при `n = q = 2·10⁵`? Яку підзадачу він пройде?

</details>

<details>
<summary>Підказка 2 — ідея</summary>

Порахуйте заздалегідь, скільки опадів випало «з першого дня по день `i`» для кожного `i`. Як за двома такими числами отримати суму з дня `l` по день `r`?

</details>

<details>
<summary>Підказка 3 — про тип даних</summary>

Яке найбільше значення може мати сума всіх `aᵢ`? Порівняйте його з `2³¹ − 1 ≈ 2,1·10⁹`. Саме цим відрізняються підзадачі 2 і 3.

</details>

## Самоперевірка

Перш ніж надсилати розв'язок, перевірте себе:

- запитання, де `l = r`;
- запитання про весь масив (`l = 1`, `r = n`);
- усі `aᵢ = 0`;
- усі `aᵢ = 10⁹` і `n = 2·10⁵` — чи не переповнюється сума?
- чи встигає програма при найбільших `n` і `q` (у Python — чи читаєте ви вхід швидко).

Автоматична перевірка на тестах репозиторію (див. [довідка/СЕРЕДОВИЩЕ.md](../../довідка/СЕРЕДОВИЩЕ.md)):
