# Як долучитися

Дякуємо за бажання покращити репозиторій. Найцінніші внески — виправлення помилок (у задачах, тестах, розв'язках, фактах про олімпіади), нові якісні задачі за стандартом і перевірені посилання на олімпіадні задачі за темами.

## Повідомити про помилку

Відкрийте Issue і вкажіть:

- файл і місце (номер задачі, розділ);
- що не так і як це перевірити (тест, посилання на першоджерело);
- для фактів про олімпіади — посилання на офіційний документ і дату.

## Запропонувати зміни

1. Зробіть форк і гілку: `git checkout -b fix/коротко-про-зміну`.
2. Внесіть зміни.
3. Перевірте:
   ```
   python інструменти/перевірити.py           # еталони на всіх тестах
   python інструменти/перевірити.py --stress NN
   python інструменти/перевірити-посилання.py
   ```
4. Відкрийте Pull Request з описом: що змінено, чому, як перевірено.

## Вимоги до вмісту

- **Нова задача** — лише за [стандартом](вчителю/СТАНДАРТ-ЗАДАЧІ.md): умова з підказками, тести з підзадачами, розбір, еталони C++17 і Python 3, бажано генератор і повільний розв'язок для стрес-тесту.
- **Задачі з олімпіад не копіюємо.** Умови не мають відкритої ліцензії, тому даємо посилання на оригінал. Див. [стандарт, розділ 6](вчителю/СТАНДАРТ-ЗАДАЧІ.md#6-джерела-та-авторство).
- **Факти про олімпіади** — лише з першоджерел (накази МОН, документи НЦ «МАНУ», офіційні сайти організаторів) з датою перевірки. Новий документ додайте до [довідка/ДЖЕРЕЛА.md](довідка/ДЖЕРЕЛА.md).
- **Мова** — літературна українська, без русизмів. Терміни — як у [глосарії](довідка/ГЛОСАРІЙ.md).
- **Не пишіть «перевірено», якщо не запускали.**

## Конфіденційність

У репозиторії не повинно бути імен, результатів чи робіт учнів, контактів, паролів і ключів доступу. Він публічний.
