## Як добирати задачі

1. **За рівнем, а не за класом.** Семикласник на рівні 4 отримує задачі рівня 4, а не «задачі для 7 класу». Рівень визначає [діагностика](ДІАГНОСТИКА.md).
2. **Одна нова ідея на задачу.** Якщо задача потребує двох незнайомих учневі ідей, вона відкладається.
3. **Співвідношення 70/30.** 70 % задач свого рівня (закріплення, швидкість, точність) і 30 % «на виріст».
4. **Реальні олімпіадні задачі — з першого місяця.** Задачі I етапу 2025–2026 молодшої ліги доступні учням 6–7 класів уже з рівнів 1–3. Перелік за темами — у [довідка/АРХІВ-ЗАДАЧ.md](../довідка/АРХІВ-ЗАДАЧ.md).
5. **Підзадачі як інструмент диференціації.** Сильний учень розв'язує задачу на 100 балів, слабший — на перші підзадачі. Обидва працюють над однією задачею, кожен на своєму рівні.

## Відкритість розв'язків

Репозиторій публічний, тому розбори й еталони доступні й учням. Це свідомий вибір: самостійна робота з розбором після спроби корисна. Щоб розбір не замінював думання:

- вимагайте усного пояснення розв'язку (див. [ОЦІНЮВАННЯ.md](ОЦІНЮВАННЯ.md#2-критерії-для-задач-на-занятті));
- для контрольних і пробних турів беріть задачі, яких немає в репозиторії: архіви олімпіад або власні варіації;
- привчайте учнів до порядку «спроба 30+ хвилин → підказка 1 → підказка 2 → розбір».

## Друк

Markdown з GitHub друкується погано: згорнуті підказки, широкі таблиці, кожен приклад двічі (C++ і Python). Скрипт збирає один HTML для друку (відкрийте в браузері → Ctrl+P → A4; працює без інтернету):

```
python інструменти/друк.py --тур                  # 8 задач тренувального туру як олімпіадні умови + картка туру
python інструменти/друк.py --задачі 13 28 31      # умови без підказок; підказки — окремим аркушем у кінці
python інструменти/друк.py --тема 16              # конспект лише з C++ (--python лишить і Python)
python інструменти/друк.py --розбір 13            # розбір для вчителя
python інструменти/друк.py учням/РЕПЕРТУАР-CPP.md # будь-який файл
```

Готові файли з'являються в теці `друк/` (її не видно в git). Режими можна поєднувати в одному файлі.

## Режим «Злам»: учень шукає помилку в чужому коді

Найчастіше бали втрачають не через незнання алгоритму, а на граничних випадках: на I етапі 2025/26 задачу «Матричка» повністю розв'язали 40 % восьмикласників, хоча бали за неї отримали 80 % ([аналіз](../довідка/АНАЛІЗ-ОЛІМПІАД.md)). Тренуйте вміння придумувати «злі» тести:

```
python інструменти/перевірити.py --зламати 13 тест.in
```

Учень складає коректний тест, скрипт перевіряє його валідатором, рахує правильну відповідь еталоном і показує, які хибні розв'язки з `розбори/13-опади/хибні/` на ньому помиляються. Опис кожної помилки, найменший ламаючий тест і бали — у `хибні/README.md`. Як вбудувати це в заняття й дуель — у [ЗАНЯТТЯ-1-НА-1.md](ЗАНЯТТЯ-1-НА-1.md#злам-і-дуель).
