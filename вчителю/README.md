## Як добирати задачі

1. **За рівнем, а не за класом.** Семикласник на рівні 4 отримує задачі рівня 4, а не «задачі для 7 класу». Рівень визначає [діагностика](ДІАГНОСТИКА.md).
2. **Одна нова ідея на задачу.** Якщо задача потребує двох незнайомих учневі ідей, вона відкладається.
3. **Співвідношення 70/30.** 70 % задач свого рівня (закріплення, швидкість, точність) і 30 % «на виріст».
4. **Реальні олімпіадні задачі — з першого місяця.** Задачі I етапу 2025–2026 молодшої ліги доступні учням 6–7 класів уже з рівнів 1–3. Перелік за темами — у [довідка/АРХІВ-ЗАДАЧ.md](../довідка/АРХІВ-ЗАДАЧ.md).
5. **Підзадачі як інструмент диференціації.** Сильний учень розв'язує задачу на 100 балів, слабший — на перші підзадачі. Обидва працюють над однією задачею, кожен на своєму рівні.

## Відкритість розв'язків

Репозиторій публічний, тому розбори й еталони доступні й учням. Це свідомий вибір: самостійна робота з розбором після спроби корисна. Щоб розбір не замінював думання:

- вимагайте усного пояснення розв'язку (див. [ОЦІНЮВАННЯ.md](ОЦІНЮВАННЯ.md#2-критерії-для-задач-на-занятті));
- для контрольних і пробних турів беріть задачі, яких немає в репозиторії: архіви олімпіад або власні варіації;
- привчайте учнів до порядку «спроба 30+ хвилин → підказка 1 → підказка 2 → розбір».

## Перевірка всього репозиторію

Перед заняттям або після змін:

```
python інструменти/перевірити.py              # усі еталони на всіх тестах
python інструменти/перевірити-посилання.py    # усі внутрішні посилання
```

Як налаштувати компілятор і Python — [довідка/СЕРЕДОВИЩЕ.md](../довідка/СЕРЕДОВИЩЕ.md).
