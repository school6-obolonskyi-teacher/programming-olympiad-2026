# 14. Скільки не більше — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 14 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 14 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Для кожного запиту перебираються всі точки: O(n·q). | 3 — оцінка складності | **великий тест:** n = q = 2·10⁵ (команда нижче) → перевищено час (понад 3 с) | час: `b-rand`, `b-dup`, `b-equal`, `b-sorted`, `b-desc` | **30** (підзадачі: 1 — так, 2 — ні) |
| [х2.cpp](х2.cpp) | `sort(a, a + n - 1)`: останній елемент не сортується, і двійковий пошук іде невпорядкованим масивом. Приклади проходять, бо в них останнє число найбільше. | 5 — реалізація | `2 1`<br>`2 1`<br>`1` → `1` / `2` | неправильна відповідь: `05`, `s-rand`, `s-dup`, `b-rand`, `b-dup`, `b-desc` | **0** (підзадачі: 1 — ні, 2 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 14 вчителю/розбори/14-скільки-не-більше/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.

## Як створити довгі тести

Довгий тест зручно створити однорядковою командою Python, що сама записує файл `t.in` (перенаправлення `>` у Windows PowerShell 5.1 записує файл у кодуванні UTF-16, і валідатор його не прийме).

- [х1.cpp](х1.cpp) — n = q = 2·10⁵:

  ```
  python -c "n=200000; open('t.in','w').write(f'{n} {n}\n' + ' '.join(['1'] * n) + '\n' + ' '.join(['1'] * n) + '\n')"
  ```
