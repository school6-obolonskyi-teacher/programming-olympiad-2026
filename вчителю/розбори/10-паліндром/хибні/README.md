# 10. Паліндром — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 10 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 10 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Зведення до малих літер умовою `s[i] >= 'A' && s[i] < 'Z'`: літера `Z` не перетворюється. | 5 — реалізація | `Zz` → `YES` / `NO` | неправильна відповідь: `11`, `r1000-pal-mixed`, `big-pal-mixed` | **30** (підзадачі: 1 — так, 2 — ні, 3 — ні) |
| [х2.py](х2.py) | Рекурсія зі зрізами: глибина `n / 2` перевищує межу рекурсії Python (1000), до того ж кожен зріз копіює рядок. | 3 — оцінка складності | **тест:** паліндром із 1998 літер `a` (з 1997 — ще проходить) (команда нижче) → помилка виконання (`RecursionError`) | помилка виконання: `big-pal-lower`, `big-pal-mixed`, `big-pal-odd-mixed`, `big-almost-center` | **60** (підзадачі: 1 — так, 2 — так, 3 — ні) |
| [х3.cpp](х3.cpp) | Символи вважаються однаковими, якщо їхні коди відрізняються на 32 (як `a` і `A`). Але так само відрізняються цифра й велика літера: `0` і `P`, `1` і `Q`, …, `9` і `Y`. | 2 — ідея | `0P` → `NO` / `YES` | неправильна відповідь: `19` | **30** (підзадачі: 1 — так, 2 — ні, 3 — ні) |
| [х4.cpp](х4.cpp) | Перед перевіркою з рядка викинуто все, крім літер (як у відомих задачах, де ігнорують розділові знаки), — а за умовою цифри теж порівнюються. | 1 — розуміння умови | `12` → `NO` / `YES` | неправильна відповідь: `19`, `20` | **0** (підзадачі: 1 — ні, 2 — ні, 3 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 10 вчителю/розбори/10-паліндром/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.

## Як створити довгі тести

Довгий тест зручно створити однорядковою командою Python, що сама записує файл `t.in` (перенаправлення `>` у Windows PowerShell 5.1 записує файл у кодуванні UTF-16, і валідатор його не прийме).

- [х2.py](х2.py) — паліндром із 1998 літер `a` (з 1997 — ще проходить):

  ```
  python -c "open('t.in','w').write('a' * 1998 + '\n')"
  ```
