# Розбір: 10. Паліндром

Умова: [задачі/10-паліндром/умова.md](../../../задачі/10-паліндром/умова.md) · Тема: [рядки](../../../учням/теми/05-рядки.md)

## Що змінено порівняно з першою версією

- **Виведення `YES`/`NO` замість «ТАК»/«НІ».** Причин дві. По-перше, у Всеукраїнській олімпіаді та на Eolymp відповіді такого типу завжди латиницею (`YES`/`NO`, `Yes`/`No`), і учні мають звикати до цього. По-друге, кирилиця у виведенні — джерело проблем з кодуванням. Вихідний файл C++ зазвичай зберігається в UTF-8, а консоль Windows за замовчуванням використовує іншу кодову сторінку, тож замість «ТАК» учень бачить незрозумілі символи. Крім того, «ТАК» у UTF-8 і в Windows-1251 — це різні байти, і порівняння з правильною відповіддю залежить від того, як збережено файл. Старий C++-розв'язок, що виводить «ТАК»/«НІ», на нових тестах набирає 0 балів (перевірено запуском).
- **Уточнено алфавіт.** Стара умова казала «лише латинські літери», але серед тестів був рядок `121`. Тепер рядок складається з латинських літер і цифр без пробілів, і тест `121` законний.
- **Довжину збільшено** з `10⁴` до `2·10⁵` і додано підзадачі.

## Ідея алгоритму

**Спосіб 1: два вказівники (еталон C++).** Індекс `i` починає з початку рядка, `j` — з кінця. Поки `i < j`, порівнюємо `tolower(s[i])` і `tolower(s[j])`. Якщо вони різні, відповідь `NO`. Інакше зсуваємо `i` вправо, а `j` вліво. Якщо вказівники зустрілися без розбіжностей, відповідь `YES`.

**Спосіб 2: розворот рядка (еталон Python).** Зводимо рядок до малих літер і порівнюємо з його розворотом: `s == s[::-1]` у Python, `s == string(s.rbegin(), s.rend())` у C++.

Трасування для `Aba` (спосіб 2):

```
Крок 1: зводимо до малих літер: "aba"
Крок 2: розворот: "aba"
Крок 3: "aba" == "aba" → YES
```

Трасування для `abca` (спосіб 1):

```
i = 0, j = 3: 'a' == 'a' → далі
i = 1, j = 2: 'b' != 'c' → NO
```

## Обґрунтування правильності

Рядок `s` довжини `n` є паліндромом тоді й лише тоді, коли `s[k] = s[n−1−k]` для всіх `k`. Достатньо перевірити `k < n/2`: решта рівностей — ті самі пари з іншого боку. Для непарного `n` середній символ збігається сам із собою. Спосіб 1 перевіряє рівно ці пари: на кожному кроці `i + j = n − 1`, і цикл іде, поки `i < j`. Спосіб 2 перевіряє всі `n` рівностей одразу. Зведення до малих літер робить порівняння нечутливим до регістру; цифри `tolower` і `lower()` не змінюють.

## Складність

- Час: O(n). У способі 1 — не більше `n/2` порівнянь, у способі 2 — побудова розвороту і порівняння, теж O(n).
- Пам'ять: O(n) на рядок.
- При `n = 2·10⁵` еталони працюють за соті частки секунди.

## Часткові розв'язки за підзадачами

| Розв'язок | Підзадачі | Бали |
|---|---|---|
| Без зведення до малих літер | 1 | 30 |
| Рекурсія зі зрізами в Python: `pal(s) = s[0] == s[-1] and pal(s[1:-1])` | 1, 2 | 60 |
| Розворот рядка дописуванням символу **на початок** (`r = c + r`), O(n²) — C++ і Python | 1, 2 або 1, 2, 3 | 60 або 100: час упритул до обмеження, результат залежить від машини |
| Старий C++-розв'язок (виводить «ТАК»/«НІ») | — | 0 |
| Індекс `s[n − i]` замість `s[n − 1 − i]` | — | 0 |
| Старий Python-розв'язок із виведенням, заміненим на `YES`/`NO` | 1, 2, 3 | 100 |
| Еталони | 1, 2, 3 | 100 |

Усі результати отримано запуском `інструменти/перевірити.py`. Подробиці:

- Рекурсивна перевірка при `n ≤ 1000` має глибину до 500 і вкладається в стандартну межу рекурсії Python (1000). На великих паліндромах вона падає з `RecursionError`. Якщо ж розбіжність є біля країв рядка, рекурсія зупиняється рано і тест проходить. До того ж кожен зріз `s[1:-1]` копіює рядок, тож навіть із більшою межею рекурсії це O(n²).
- Дописування символу на початок рядка щоразу копіює весь рядок, разом це близько `n²/2 = 2·10¹⁰` операцій копіювання байтів. Копіювання пам'яті дуже швидке, тому на нашій машині найдовший тест зайняв 0,87 с (Python) і 0,97 с (C++) при обмеженні 1 с, і розв'язок пройшов. Під час повторного запуску на завантаженій машині ті самі розв'язки працювали 1,1–1,5 с на великих тестах і набрали 60 балів. Запасу немає, тож результат залежить від системи. Корисно показати учням, що «пройшло» ще не означає «правильна складність».
- З індексом `s[n − i]` при `i = 0` у C++ порівнюється `s[0]` з нульовим символом за кінцем рядка, тож усі паліндроми довжини від 2 отримують `NO`.

## Методичні примітки

1. Попросіть учнів записати рядок `racecar` на картках і «складати» його навпіл. Індекс пари для позиції `i` (`n − 1 − i`) учні мають вивести самі, це головне місце для помилки на одиницю.
2. Порівняйте два способи. Розворот коротший у Python, два вказівники економніші й готують до методу двох вказівників (тема 12) і до задач, де рядок не можна розвернути цілком.
3. Покажіть, що старий розв'язок із «ТАК»/«НІ» набирає 0 балів. Нагадайте правило: виводимо рівно те, що написано в умові, латиницею й з урахуванням регістру (`YES` і `Yes` — різні відповіді, якщо умова не каже інакше).
4. Варіації: паліндром, якщо ігнорувати всі символи, крім літер (фраза «Козак з казок»); найдовший підрядок-паліндром (O(n²) — тема для старшої ліги); AtCoder ABC 147 B і ABC 159 B з умови.
