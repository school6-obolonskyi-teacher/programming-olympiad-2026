# Розбір: 09. Мінімум

Умова: [задачі/09-мінімум/умова.md](../../../задачі/09-мінімум/умова.md) · Тема: [масиви](../../../учням/теми/04-масиви.md)

## Ідея алгоритму

Тримаємо змінну `mn` — найменше серед уже прочитаних чисел. Ініціалізуємо її **першим елементом**, потім порівнюємо з нею кожне наступне число і, якщо воно менше, оновлюємо `mn`. Зберігати числа в масиві не обов'язково.

Трасування для прикладу 1 (`3 7 2 9 1`):

```
mn = 3 (перший елемент)
Число 7: 7 < 3? Ні,  mn = 3
Число 2: 2 < 3? Так, mn = 2
Число 9: 9 < 2? Ні,  mn = 2
Число 1: 1 < 2? Так, mn = 1
Результат: 1
```

У Python є вбудована функція `min()`, у C++ — `*min_element(a.begin(), a.end())`. Ними можна користуватися на олімпіаді, але на занятті варто спершу написати цикл самостійно: та сама схема знадобиться для максимуму, для «мінімуму з умовою», для пошуку позиції мінімуму тощо.

## Обґрунтування правильності

Інваріант: після обробки перших `k` чисел `mn = min(a₁, …, a_k)`. Для `k = 1` це так за ініціалізацією. Якщо інваріант виконується для `k`, то для `k + 1` маємо `min(a₁, …, a_{k+1}) = min(mn, a_{k+1})`, і саме це значення отримує `mn` після порівняння. При `k = n` маємо відповідь.

Чому саме перший елемент: так `mn` з самого початку дорівнює одному з чисел масиву. Будь-яка стала `C` правильна лише тоді, коли `C ≥` найбільшого можливого `aᵢ`, бо якщо всі числа більші за `C`, мінімум так і залишиться `C`.

## Складність

- Час: O(n). При `n = 2·10⁵` еталон на C++ працює за соті частки секунди, на Python — близько 0,1 с.
- Пам'ять: O(1) у C++ (числа не зберігаються); Python-еталон читає весь вхід одразу.

Тип: `|aᵢ| ≤ 10⁹` вміщується в `int`.

## Про пастку з початковим значенням

| Початкове значення | Коли ламається | Результат запуску |
|---|---|---|
| `0` | усі числа додатні: приклад 1 дає `0` замість `1`, приклад 3 — `0` замість `42` | 30 балів |
| `1000000` (`10⁶`) | усі числа більші за `10⁶`, наприклад тест 07 (`10⁹`) | 30 балів |
| `1e9` (`10⁹`) | за цих обмежень **ніколи**: `aᵢ ≤ 10⁹`, тож `mn` або залишиться `10⁹` (якщо всі числа рівні `10⁹`), або зменшиться | 100 балів |
| `INT_MAX`, `LLONG_MAX`, `float('inf')` | ніколи | — |
| перший елемент | ніколи | 100 балів (еталон) |

Ініціалізація сталою `10⁹` у цій задачі випадково правильна: межу `aᵢ ≤ 10⁹` включено. Вона одразу ламається, щойно в іншій задачі числа можуть бути більшими (наприклад, до `10¹⁸`) або коли учень помилиться з кількістю нулів. Тому на занятті варто наголошувати: перший елемент правильний за будь-яких меж, і про них навіть не треба думати. Якщо учень хоче сталу, вона має бути не меншою за найбільше можливе значення (`INT_MAX` для `int`).

Підзадача 1 (усі `aᵢ ≤ 0`) спеціально зроблена такою, щоб розв'язок з ініціалізацією нулем набирав рівно її бали: якщо серед чисел є недодатне, мінімум `≤ 0`, і нуль не заважає.

Квадратичний розв'язок з виходом із внутрішнього циклу при першому меншому числі на випадкових даних працює швидко. Його ламають два тести: `big-desc` (числа спадають, і для кожного `aᵢ` менше число трапляється лише після всіх попередніх) і `big-lastmin` (усі числа однакові, крім останнього). На обох він не вклався в 5 с. Масив на 10001 елемент при `n = 2·10⁵` дає вихід за межі масиву: програма аварійно завершилася на всіх великих тестах.

## Методичні примітки

1. Почніть із гри: учитель диктує числа, учні записують лише одне число — «найменше на цей момент». Потім запитайте, що було записано **до** першого числа. Звідси природно виникає ініціалізація першим елементом.
2. Дайте здати розв'язок з `mn = 0` і показати, що він набирає 30 балів. Після цього обговоріть таблицю «початкове значення → коли ламається». Зверніть увагу, що `10⁹` працює лише завдяки знаку `≤` в обмеженні.
3. Варіації на тому самому коді: максимум; номер першого (або останнього) мінімуму; кількість елементів, що дорівнюють мінімуму; мінімум серед парних чисел (тут ініціалізація першим елементом уже не працює, і потрібен прапорець «ще нічого не знайдено»).
4. Продовження: AtCoder ABC 102 B (максимум мінус мінімум), а для старшої ліги — префіксні мінімуми й задача H «Виставка» I етапу 2025–2026.
