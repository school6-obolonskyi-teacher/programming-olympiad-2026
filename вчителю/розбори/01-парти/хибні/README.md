# 01. Парти — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 01 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 01 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Формула `(n + k − 1) / k` правильна, але обчислюється в `int`: коли `n + k − 1 > 2³¹ − 1`, сума переповнюється. | 4 — типи даних | `2000000000 2000000000` → `1` / `0` | неправильна відповідь: `11`, `12`, `13`, `16`, `big2`, `big4` | **50** (підзадачі: 1 — так, 2 — ні) |
| [х2.cpp](х2.cpp) | `ceil((double)n / k)` виводиться як дійсне число: `cout` друкує великі значення в експоненційному записі (`1e+06`). | 6 — введення-виведення | `1000000 1` → `1000000` / `1e+06` | неправильна відповідь: `06`, `10`, `14`, `big3` | **0** (підзадачі: 1 — ні, 2 — ні) |
| [х3.cpp](х3.cpp) | Ділення у `float`: 24 біти мантиси не розрізняють близьких великих чисел (`16777217` стає `16777216`). | 4 — типи даних | `16777217 16777216` → `2` / `1` | неправильна відповідь: `09`, `r2`, `big3` | **0** (підзадачі: 1 — ні, 2 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 01 вчителю/розбори/01-парти/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.
