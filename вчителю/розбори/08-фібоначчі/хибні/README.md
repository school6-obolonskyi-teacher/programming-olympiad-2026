# 08. Фібоначчі — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 08 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 08 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Числа в `int`: `F(47) = 2 971 215 073 > 2³¹ − 1`. | 4 — типи даних | `48` → 48-е число відповіді: `2971215073` / `-1323752223` | неправильна відповідь: `12`, `13`, `14`, `15` | **40** (підзадачі: 1 — так, 2 — ні) |
| [х2.cpp](х2.cpp) | Наївна рекурсія для кожного числа: експоненційний час. | 3 — оцінка складності | `50` → перевищено час (понад 3 с) | час: `08`, `09`, `10`, `11`, `12`, `13`, `14`, `15` | **0** (підзадачі: 1 — ні, 2 — ні) |
| [х3.cpp](х3.cpp) | Формула Біне в `double` з `llround`: від `F(71)` похибка округлення перевищує 0,5. | 4 — типи даних | `72` → 72-е число відповіді: `308061521170129` / `308061521170130` | неправильна відповідь: `14`, `15` | **40** (підзадачі: 1 — так, 2 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 08 вчителю/розбори/08-фібоначчі/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.
