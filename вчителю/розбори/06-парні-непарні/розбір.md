# Розбір: 06. Парні та непарні

Умова: [задачі/06-парні-непарні/умова.md](../../../задачі/06-парні-непарні/умова.md) · Тема: [цикли](../../../учням/теми/03-цикли.md)

## Ідея алгоритму

Читаємо числа по одному і для кожного збільшуємо один із двох лічильників: `even`, якщо `x % 2 == 0`, інакше `odd`. Зберігати числа в масиві не потрібно. Можна рахувати лише парні, а кількість непарних отримати як `N − even`.

Трасування для прикладу 1 (`1 2 3 4 5`):

```
Число 1: 1 % 2 = 1 ≠ 0 → непарне, odd = 1
Число 2: 2 % 2 = 0     → парне,   even = 1
Число 3: 3 % 2 = 1 ≠ 0 → непарне, odd = 2
Число 4: 4 % 2 = 0     → парне,   even = 2
Число 5: 5 % 2 = 1 ≠ 0 → непарне, odd = 3
Результат: 2 3
```

## Головна пастка: остача від'ємного числа в C++

У C++ ділення цілих чисел округлює частку **до нуля**, тому остача має знак діленого:

```
(-3) / 2 == -1,   (-3) % 2 == -1,   (-4) % 2 == 0
```

Отже, для від'ємного непарного числа `x % 2` дорівнює `−1`, а не `1`. Перевірка `x % 2 == 1` помилково записує всі від'ємні непарні числа до парних. Правильні варіанти в C++:

- `x % 2 == 0` — парне, інакше непарне (так в еталоні);
- `x % 2 != 0` — непарне;
- `abs(x) % 2 == 1` — непарне.

У Python ділення `//` округлює **вниз**, тому `(-3) // 2 == -2`, а `(-3) % 2 == 1`. Остача від ділення на 2 там завжди 0 або 1, і перевірка `x % 2 == 1` у Python правильна. Ці значення перевірено запуском (g++ 13 і Python 3.12).

Через цю різницю задача добре показує, що «та сама» формула в різних мовах поводиться по-різному на від'ємних числах.

## Обґрунтування правильності

Кожне ціле число або парне, або непарне, третього не дано. Тому кожне прочитане число збільшує рівно один лічильник, і `even + odd = N`. Число `x` парне тоді й лише тоді, коли воно ділиться на 2 без остачі, тобто `x % 2 == 0` в обох мовах: для парних від'ємних чисел остача теж нульова, наприклад `(-4) % 2 == 0`. Нуль парний: `0 % 2 == 0`.

## Складність

- Час: O(N), по одній перевірці на число. При `N = 2·10⁵` еталон на C++ працює за соті частки секунди, на Python — близько 0,1 с.
- Пам'ять: O(1) у C++ (числа не зберігаються). Python-еталон читає весь вхід одразу, це O(N), але кілька мегабайтів.

Типи: `|aᵢ| ≤ 10⁹` вміщується в `int`, лічильники не перевищують `2·10⁵`.

## Часткові розв'язки за підзадачами

| Розв'язок | Підзадачі | Бали |
|---|---|---|
| C++, `if (x % 2 == 1) odd++; else even++;` | 1 | 30 |
| C++, два окремі `if`: `x % 2 == 0` → `even`, `x % 2 == 1` → `odd` | 1 | 30 |
| C++, правильна перевірка, але числа зберігаються в масиві `int a[1001]` (за старим обмеженням `N ≤ 1000`) | 1, 2 | 60 |
| Python, `x % 2 == 1` | 1, 2, 3 | 100 |
| Еталон; старі розв'язки з першої версії репозиторію (C++ і Python) | 1, 2, 3 | 100 |

Усі результати отримано запуском `інструменти/перевірити.py`.

Деталі:

- `x % 2 == 1` з `else` віддає всі від'ємні непарні «парному» ліфту: на прикладі 3 виходить `3 0` замість `1 2`.
- З двома окремими `if` від'ємне непарне число не потрапляє в жоден лічильник: на прикладі 3 виходить `1 0`, тобто `even + odd ≠ N`. Цю ознаку зручно показати учням як самоперевірку.
- Масив на 1001 елемент при `N = 2·10⁵` дає вихід за межі масиву. На тестовій системі програма аварійно завершилася (помилка виконання) на всіх великих тестах.

| Помилка | Симптом | Як виявити |

| `x % 2 == 1` для непарних (C++) | від'ємні непарні рахуються як парні | приклад 3, тести 08, 10, 11 |
| Два `if` без `else` | `even + odd < N` | приклад 3 |

| Порядок виведення навпаки (спершу непарні) | неправильна відповідь | приклад 1 |

## Методичні примітки

1. Перед заняттям попросіть учнів передбачити, що виведе `cout << -3 % 2;` у C++ і `print(-3 % 2)` у Python, а потім перевірити. Розбіжність відповідей зазвичай дивує навіть сильних учнів.
2. Дайте здати розв'язок з `x % 2 == 1`: він набирає 30 балів, хоча «на прикладах із додатними числами все працює». Це наочно показує, навіщо в умовах бувають від'ємні числа і чому варто тестувати граничні випадки.
3. Обговоріть, чи потрібен масив. Підзадача 3 карає за масив, розмір якого підібрано під старі обмеження. Звичка «читати й одразу обробляти» знадобиться в багатьох задачах.
4. Корисна самоперевірка для учнів: сума двох відповідей має дорівнювати `N`.
5. Продовження: задача CSES 1068 «Weird Algorithm» (там значення перевищують `int`) і AtCoder ABC 081 B «Shift only».
