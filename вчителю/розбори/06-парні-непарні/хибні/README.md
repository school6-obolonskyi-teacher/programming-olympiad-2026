# 06. Парні та непарні — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 06 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 06 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Нуль не зараховано ні до парних, ні до непарних (хибне уявлення, що 0 «не має парності»). | 1 — розуміння умови | `1`<br>`0` → `1 0` / `0 0` | неправильна відповідь: `06`, `09`, `10`, `r1000-small`, `big-small` | **0** (підзадачі: 1 — ні, 2 — ні, 3 — ні) |
| [х2.cpp](х2.cpp) | Парність перевіряється через `float half = x / 2.0`: `float` не вміщує дробової половини великих непарних чисел, і половина «стає» цілою. | 4 — типи даних | `1`<br>`16777217` → `0 1` / `1 0` | неправильна відповідь: `08`, `09`, `r1000-pos`, `r1000-mixed`, `r1000-neg`, `r1000-negodd`, `big-pos`, `big-mixed`, `big-negodd` | **0** (підзадачі: 1 — ні, 2 — ні, 3 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 06 вчителю/розбори/06-парні-непарні/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.
