# 23. Вище середнього — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 23 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 23 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Сума в `int`: понад `2³¹ − 1` вона стає від'ємною, і «вище середнього» опиняються всі. | 4 — типи даних | `3`<br>`1000000000 1000000000 1000000000` → `0` / `3` | неправильна відповідь: `11`, `12`, `m-random`, `b-random`, `b-exact`, `b-below`, `b-above`, `b-onebig`, `b-max`, `b-max-below` | **60** (підзадачі: 1 — так, 2 — так, 3 — ні) |
| [х2.cpp](х2.cpp) | Середнє у `float`: похибка, коли середнє дуже близьке до балу учня. | 4 — типи даних | `2`<br>`16777217 16777216` → `1` / `0` | неправильна відповідь: `12`, `s2-below`, `s2-int-below`, `b-exact`, `b-below`, `b-above`, `b-max-below` | **30** (підзадачі: 1 — так, 2 — ні, 3 — ні) |
| [х3.cpp](х3.cpp) | Середнє округлено до цілого (`llround`), хоча порівнювати треба з точним дробовим середнім. | 1 — розуміння умови | `2`<br>`1 2` → `1` / `0` | неправильна відповідь: `07`, `08`, `09`, `12`, `s1-below`, `s1-max`, `s2-below`, `s2-onebig`, `s2-int-below`, `b-below`, `b-onebig`, `b-max-below` | **0** (підзадачі: 1 — ні, 2 — ні, 3 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 23 вчителю/розбори/23-вище-середнього/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.
