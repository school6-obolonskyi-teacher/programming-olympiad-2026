# Розбір: 04. Високосний рік

Умова: [задачі/04-високосний-рік/умова.md](../../../задачі/04-високосний-рік/умова.md) · Тема: [розгалуження](../../../учням/теми/02-розгалуження.md)

## Ідея алгоритму

Правило з умови переноситься в програму одним із двох способів.

**Ланцюжок перевірок** у тому самому порядку, що й в умові:

```
якщо y % 400 == 0  → 366
інакше якщо y % 100 == 0 → 365
інакше якщо y % 4 == 0   → 366
інакше                   → 365
```

**Одна складна умова:** рік високосний, якщо

```
y % 400 == 0  ||  (y % 4 == 0 && y % 100 != 0)
```

## Обґрунтування правильності

Ланцюжок дослівно повторює правило з умови, тому правильний за означенням. Важливий лише порядок: кожна наступна перевірка виконується тільки тоді, коли попередні не спрацювали. Якщо почати з `y % 4 == 0`, то 1900 «застрягне» на першій же гілці й отримає 366.

Складна умова рівносильна ланцюжку. Розглянемо всі можливі випадки:

| `y` | Ланцюжок | `y % 400 == 0` | `y % 4 == 0 && y % 100 != 0` | Умова |
|---|---|---|---|---|
| ділиться на 400 (2000) | 366 | так | ні | 366 |
| ділиться на 100, не на 400 (1900) | 365 | ні | ні | 365 |
| ділиться на 4, не на 100 (2024) | 366 | ні | так | 366 |
| не ділиться на 4 (2026) | 365 | ні | ні | 365 |

Будь-яке ціле число потрапляє рівно в один рядок таблиці, бо кожне число, кратне 400, кратне і 100, а кожне кратне 100 — кратне і 4.

У C++ `&&` має вищий пріоритет, ніж `||`, тому умова без дужок `y % 4 == 0 && y % 100 != 0 || y % 400 == 0` теж правильна. Дужки все одно варто ставити: так умову легше читати.

## Складність

- Час: O(1).
- Пам'ять: O(1).
- `y ≤ 10⁹` уміщується в `int`, переповнення немає.

## Часткові розв'язки за підзадачами

Підзадачі побудовано так, щоб кожне наступне уточнення правила давало нові бали.

| Розв'язок | Підзадачі | Бали |
|---|---|---|
| Лише `y % 4 == 0` | 1 | 30 |
| `y % 400 == 0 \|\| y % 4 == 0` (зайве «або») | 1 | 30 |
| Ланцюжок, але в порядку 4 → 100 → 400 | 1 | 30 |
| `y % 4 == 0 && y % 100 != 0` (забули правило 400) | 1, 2 | 60 |
| `y % 4 == 0 && y % 100 != 0 && y % 400 == 0` (усе через «і») | — | 0 |
| Еталон; також умова без дужок `y % 4 == 0 && y % 100 != 0 \|\| y % 400 == 0` | 1, 2, 3 | 100 |

Ці результати перевірено запуском `інструменти/перевірити.py` на навмисно недосконалих розв'язках, а не виведено теоретично.

## Типові помилки учнів

| Помилка | Симптом | Як виявити |
|---|---|---|
| Лише подільність на 4 | 1900, 2100 вважаються високосними | Приклад 3: 1900 |
| Неправильний порядок у ланцюжку (спершу 4) | Те саме | Приклад 3: 1900 |
| Забули правило 400 | 2000 вважається звичайним | Тест 04: 2000 |
| Усі умови через `&&` | Жоден рік не високосний | Приклад 2: 2024 |
| `y / 4 == 0` замість `y % 4 == 0` | Ділення замість остачі | Приклад 2: 2024 |
| `=` замість `==` в умові (C++) | `y % 4 = 0` не компілюється: «lvalue required as left operand of assignment» | Компілятор |
| Виведення `YES` / `NO` замість кількості днів | Неправильна відповідь на всіх тестах | Будь-який тест |

## Методичні примітки

1. Розкажіть, звідки взялося правило: сонячний (тропічний) рік триває приблизно 365,2422 доби. Якщо додавати день кожні 4 роки, середній рік триватиме 365,25 доби — забагато. Тому тричі на 400 років додатковий день не додають (роки, кратні 100, але не 400), і середня тривалість стає `365 + 1/4 − 1/100 + 1/400 = 365,2425` доби.
2. Попросіть учнів спершу написати ланцюжок `if / else if`, а потім переписати його однією умовою. Таблиця з чотирма випадками з розбору — зручний спосіб перевірити, що дві форми рівносильні.
3. Задача добре ілюструє підзадачі: розв'язок «ділиться на 4» отримує 30 балів, «забули про 400» — 60. Дайте учням здати обидва й обговорити, які тести їх «ловлять».
4. Продовження: кількість днів у місяці `m` року `y`; номер дня в році за датою; день тижня за датою.
