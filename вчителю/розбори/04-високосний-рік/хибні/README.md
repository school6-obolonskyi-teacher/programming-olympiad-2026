# 04. Високосний рік — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 04 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 04 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Забуто правило 400: роки, кратні 400, вважаються звичайними. | 1 — розуміння умови | `400` → `366` / `365` | неправильна відповідь: `04`, `09`, `10`, `14`, `q1`, `q2` | **60** (підзадачі: 1 — так, 2 — так, 3 — ні) |
| [х2.cpp](х2.cpp) | `y / 400 == 0` замість `y % 400 == 0`: ділення замість остачі. Усі роки до 399 «високосні», а 2000 — ні. | 5 — реалізація | `1` → `365` / `366` | неправильна відповідь: `04`, `06`, `08`, `09`, `10`, `14`, `q1`, `q2` | **0** (підзадачі: 1 — ні, 2 — ні, 3 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 04 вчителю/розбори/04-високосний-рік/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.
