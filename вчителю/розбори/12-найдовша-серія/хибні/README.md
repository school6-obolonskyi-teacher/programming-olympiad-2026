# 12. Найдовша серія — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 12 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 12 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Відповідь оновлюється лише тоді, коли серія обривається: остання серія не враховується. | 5 — реалізація | `2`<br>`7 7` → `2` / `1` | неправильна відповідь: `04`, `05`, `08`, `11`, `12`, `s-equal`, `s-last`, `big-equal`, `big-last`, `big-last-long` | **0** (підзадачі: 1 — ні, 2 — ні) |
| [х2.cpp](х2.cpp) | Наївний O(n²): від кожного елемента серія рахується заново. | 3 — оцінка складності | **великий тест:** n = 2·10⁵ однакових чисел (команда нижче) → перевищено час (понад 3 с) | час: `big-equal`, `big-blocks`, `big-last-long` | **40** (підзадачі: 1 — так, 2 — ні) |
| [х3.cpp](х3.cpp) | «Попереднє» значення `prev = 0` до початку масиву: нуль на початку вважається продовженням неіснуючої серії. | 5 — реалізація | `1`<br>`0` → `1` / `2` | неправильна відповідь: `06`, `12` | **0** (підзадачі: 1 — ні, 2 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 12 вчителю/розбори/12-найдовша-серія/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.

## Як створити довгі тести

Довгий тест зручно створити однорядковою командою Python, що сама записує файл `t.in` (перенаправлення `>` у Windows PowerShell 5.1 записує файл у кодуванні UTF-16, і валідатор його не прийме).

- [х2.cpp](х2.cpp) — n = 2·10⁵ однакових чисел:

  ```
  python -c "n=200000; open('t.in','w').write(f'{n}\n' + ' '.join(['7'] * n) + '\n')"
  ```
