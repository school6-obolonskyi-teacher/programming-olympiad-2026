# Хибні розв'язки задачі 28 «Спокійний період» (для вчителя)

Ці файли — для режиму «Злам»: учень складає коректний тест, на якому хибний розв'язок помиляється, і перевіряє його командою

```
python інструменти/перевірити.py --зламати 28 мій-тест.in
```

Усі чотири розв'язки проходять обидва приклади з умови. Учням цю сторінку не показуйте: тут описано помилки й готові ламаючі тести. Бали отримано запуском `інструменти/перевірити.py` на 43 тестах репозиторію (обмеження часу 1 с). Кроки — за таблицею з [АНАЛІЗ-ПОМИЛОК.md](../../../АНАЛІЗ-ПОМИЛОК.md#класифікація).

Що варто обговорити після зламу:

- **х1** — чому при `k = 0` «почати заново» правильно, а при `k > 0` ні: при `k > 0` день, що «зламав» період, може бути сумісним із кількома днями перед ним.
- **х2 і х3** — одна й та сама думка: значення можуть повторюватися, тож треба знати, *який саме* день виходить з вікна. Звідси правило: у монотонному деку зберігаємо номери, а в `multiset` видаляємо одну копію через `erase(find(x))`.
- **х4** — на випадкових тестах він встигає (вікна короткі), тому потестово набирає 81 бал. Ламає його лише тест із довгим спокійним періодом; учень має сам здогадатися, що такий тест потрібен.
