# 21. Сходинки — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 21 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 21 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Рекурсія без запам'ятовування: експоненційний час. | 3 — оцінка складності | **тест:** n = 60, усі ціни 1 (команда нижче) → перевищено час (понад 3 с) | час: `mid-rand`, `big-rand`, `big-small`, `big-max`, `big-trap`, `big-alt`, `big-zero` | **30** (підзадачі: 1 — так, 2 — ні) |
| [х2.py](х2.py) | Запам'ятовування є, але без `sys.setrecursionlimit`: при `n > 1000` — `RecursionError`. | 3 — оцінка складності | **великий тест:** n = 1001, усі ціни 1 (з n = 1000 — ще проходить) (команда нижче) → помилка виконання (`RecursionError`) | помилка виконання: `mid-rand`, `big-rand`, `big-small`, `big-max`, `big-trap`, `big-alt`, `big-zero` | **30** (підзадачі: 1 — так, 2 — ні) |

## Як створити довгі тести

Довгий тест зручно створити однорядковою командою Python, що сама записує файл `t.in` (перенаправлення `>` у Windows PowerShell 5.1 записує файл у кодуванні UTF-16, і валідатор його не прийме).

- [х1.cpp](х1.cpp) — n = 60, усі ціни 1:

  ```
  python -c "open('t.in','w').write('60\n' + ' '.join(['1'] * 60) + '\n')"
  ```

- [х2.py](х2.py) — n = 1001, усі ціни 1 (з n = 1000 — ще проходить):

  ```
  python -c "open('t.in','w').write('1001\n' + ' '.join(['1'] * 1001) + '\n')"
  ```
