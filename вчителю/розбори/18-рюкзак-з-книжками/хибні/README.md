# 18. Рюкзак з книжками — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 18 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 18 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | O(n²): для кожного початку відрізок розширюється вправо, доки вага не перевищить `S`. | 3 — оцінка складності | **великий тест:** n = 2·10⁵, `S = 10¹⁸`, усі ваги 1 (команда нижче) → перевищено час (понад 3 с) | час: `b-rand`, `b-half`, `b-huge`, `b-exact`, `b-ones` | **50** (підзадачі: 1 — так, 2 — так, 3 — ні) |
| [х2.cpp](х2.cpp) | Два вказівники, але сума у вікні — `int`: вона переповнюється і «не перевищує» `S`. Приклад 3 проходить випадково: там `S = 10¹⁸`. | 4 — типи даних | `3 2000000000`<br>`1000000000 1000000000 1000000000` → `2` / `3` | неправильна відповідь: `s1-rand`, `s2-rand`, `s2-half`, `b-rand`, `b-half` | **0** (підзадачі: 1 — ні, 2 — ні, 3 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 18 вчителю/розбори/18-рюкзак-з-книжками/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.

## Як створити довгі тести

Довгий тест зручно створити однорядковою командою Python, що сама записує файл `t.in` (перенаправлення `>` у Windows PowerShell 5.1 записує файл у кодуванні UTF-16, і валідатор його не прийме).

- [х1.cpp](х1.cpp) — n = 2·10⁵, `S = 10¹⁸`, усі ваги 1:

  ```
  python -c "n=200000; open('t.in','w').write(f'{n} {10**18}\n' + ' '.join(['1'] * n) + '\n')"
  ```
