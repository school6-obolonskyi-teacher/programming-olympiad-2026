# Розбір: 02. Годинник

Умова: [задачі/02-годинник/умова.md](../../../задачі/02-годинник/умова.md) · Тема: [перші програми](../../../учням/теми/01-перші-програми.md)

## Ідея алгоритму

Три формули на цілочисельне ділення й остачу:

```
секунди = t % 60
хвилини = (t / 60) % 60       — повні хвилини без повних годин
години  = (t / 3600) % 24     — повні години без повних діб
```

Далі треба вивести години як є, а хвилини й секунди — двома цифрами. Для числа `x < 60` це `x / 10` (цифра десятків) і `x % 10` (цифра одиниць), тож провідний нуль з'являється без `if`. Можна також скористатися `printf("%d:%02d:%02d")` у C++ або `f"{h}:{m:02d}:{s:02d}"` у Python.

## Обґрунтування правильності

Годинник «перекидає» секунди в хвилини кожні 60 секунд, хвилини в години — кожні 60 хвилин, години в нуль — кожні 24 години. Тому:

- від увімкнення минуло `⌊t / 60⌋` повних хвилин, і ще `t % 60` секунд, які годинник і показує;
- з `⌊t / 60⌋` повних хвилин `⌊t / 3600⌋` склалися в повні години, а решта `⌊t / 60⌋ % 60` показується як хвилини;
- з `⌊t / 3600⌋` повних годин кожні 24 становлять повну добу, після якої показ годин повторюється, тож години на екрані — `⌊t / 3600⌋ % 24`.

Це звичайний запис числа `t` у «змішаній» системі числення з основами 60, 60, 24. Повільний розв'язок прокручує годинник посекундно і підтверджує ці формули на випадкових тестах.

## Складність

- Час: O(1).
- Пам'ять: O(1).
- `t ≤ 10⁹` уміщується в `int`, переповнення немає.

## Часткові розв'язки за підзадачами

| Розв'язок | Підзадачі | Бали |
|---|---|---|
| Правильні формули, але години без `% 24` (C++ або Python) | 1 | 40 |
| Хвилини й секунди без провідного нуля (`1:2:5`) | — | 0 |
| Провідний нуль і в годинах (`01:02:05`) | — | 0 |
| Хвилини як `t / 60` без `% 60` | — | 0 |
| Python: `print(h, ":", …)` — пробіли навколо двокрапок | — | 0 |
| Провідний нуль лише в хвилинах (`1:02:5`) | — | 0 |
| Еталон | 1, 2 | 100 |

Скрипт перевірки, як і більшість олімпіадних систем, порівнює відповіді «за токенами» і не зважає на зайві пробіли між числами. Але `1 : 02 : 05` — це п'ять токенів замість одного `1:02:05`, тому такий розв'язок отримує 0 балів.

Ці результати перевірено запуском `інструменти/перевірити.py` на навмисно недосконалих розв'язках, а не виведено теоретично.

## Методичні примітки

1. Порівняйте з переведенням числа в іншу систему числення: години, хвилини й секунди — це «цифри» в системі з основами 24, 60, 60.
2. Нехай учні спершу напишуть розв'язок без провідних нулів і самі побачать, що приклад 1 не проходить. Це гарний привід поговорити про те, що на олімпіаді формат виведення перевіряється буквально.
3. Покажіть кілька способів вивести двоцифрове число: `x / 10` і `x % 10`, `printf("%02d")`, `setw(2)` з `setfill('0')` у C++, `f"{x:02d}"` і `str(x).zfill(2)` у Python.
4. Розв'язок без `% 24` набирає 40 балів — гарна ілюстрація підзадач: «майже правильний» розв'язок отримує частину балів.
5. Продовження: зворотна задача (за показом годинника і кількістю минулих діб знайти `t`) або різниця між двома показами годинника.
