# 02. Годинник — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 02 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 02 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Замість `% 24` — одноразове `if (h >= 24) h -= 24`: від двох діб годинник показує 24 години й більше. | 5 — реалізація | `172800` → `0:00:00` / `24:00:00` | неправильна відповідь: `12`, `13`, `14`, `any1`, `any2`, `any3` | **40** (підзадачі: 1 — так, 2 — ні) |
| [х2.cpp](х2.cpp) | Остачу від ділення на 24 беруть лише при `h > 24` (строга нерівність): рівно 24 години лишаються «24». | 5 — реалізація | `86400` → `0:00:00` / `24:00:00` | неправильна відповідь: `11`, `15` | **40** (підзадачі: 1 — так, 2 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 02 вчителю/розбори/02-годинник/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.
