# 16. Прості числа — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 16 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 16 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Для кожного запиту — перебір дільників кожного числа відрізка: O(q · (r − l) · √r). | 3 — оцінка складності | **тест:** q = 100 запитань `1 1000000` (команда нижче) → перевищено час (понад 3 с) | час: `s2-full`, `s2-rand`, `b-rand`, `b-full` | **30** (підзадачі: 1 — так, 2 — ні, 3 — ні) |
| [х2.cpp](х2.cpp) | Решето правильне, але для кожного запиту прості рахуються циклом по відрізку (без префіксних сум): O(q · 10⁶). | 3 — оцінка складності | **великий тест:** q = 10⁵ запитань `1 1000000` (команда нижче) → перевищено час (понад 3 с) | час: `b-rand`, `b-full` | **60** (підзадачі: 1 — так, 2 — так, 3 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 16 вчителю/розбори/16-прості-числа/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.

## Як створити довгі тести

Довгий тест зручно створити однорядковою командою Python, що сама записує файл `t.in` (перенаправлення `>` у Windows PowerShell 5.1 записує файл у кодуванні UTF-16, і валідатор його не прийме).

- [х1.cpp](х1.cpp) — q = 100 запитань `1 1000000`:

  ```
  python -c "open('t.in','w').write('100\n' + '1 1000000\n' * 100)"
  ```

- [х2.cpp](х2.cpp) — q = 10⁵ запитань `1 1000000`:

  ```
  python -c "open('t.in','w').write('100000\n' + '1 1000000\n' * 100000)"
  ```
