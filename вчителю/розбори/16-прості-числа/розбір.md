# Розбір: 16. Прості числа

Умова: [задачі/16-прості-числа/умова.md](../../../задачі/16-прості-числа/умова.md) · Теми: [теорія чисел](../../../учням/теми/11-теорія-чисел.md), [префіксні суми](../../../учням/теми/07-префіксні-суми.md)

## Ідея алгоритму

Розв'язок має дві частини.

**1. Решето Ератосфена до `N = 10⁶`.** Заводимо масив позначок «просте / складене» для всіх чисел `0…N`. Спочатку всі числа від 2 вважаємо простими. Перебираємо `i = 2, 3, …`, поки `i · i ≤ N`; якщо `i` ще не викреслене, то воно просте, і ми викреслюємо його кратні `i², i² + i, i² + 2i, …` до `N`.

**2. Префіксні суми.** `cnt[x]` — кількість простих серед `1…x`; `cnt[0] = cnt[1] = 0`, `cnt[x] = cnt[x − 1] + (1, якщо x просте)`. Відповідь на запит — `cnt[r] − cnt[l − 1]`, як у задачі [13. Опади](../13-опади/розбір.md).

У Python решето будуємо на `bytearray`, а кратні викреслюємо одним присвоюванням зрізу:

```python
sieve[i * i::i] = bytes(len(range(i * i, N + 1, i)))
```

Таке присвоювання виконується всередині інтерпретатора на швидкості C. Префіксні суми — `itertools.accumulate(sieve)`.

## Обґрунтування правильності

**Решето не викреслює простих чисел.** Викреслюються лише числа вигляду `i · k`, де `k ≥ i ≥ 2`, — усі вони складені.

**Решето викреслює всі складені числа.** Нехай `x ≤ N` складене і `p` — його найменший простий дільник. Тоді `x = p · k`, де `k ≥ p` (усі прості дільники `k` не менші за `p`). Отже, `p² ≤ x ≤ N`, тобто зовнішній цикл дійде до `p`; `p` на той момент не викреслене (воно просте); і `x` — одне з кратних `p`, починаючи з `p²`. Значить, `x` буде викреслене.

Звідси ж видно, чому викреслювати можна починати з `i²`, а не з `2i`: менші кратні `i · k` з `k < i` мають простий дільник, менший за `i`, і їх уже викреслено раніше. І чому зовнішній цикл досить вести до `√N = 1000`.

**Префіксні суми.** `cnt[r]` рахує прості серед `1…r`, `cnt[l − 1]` — серед `1…l − 1`; різниця — рівно прості серед `l…r`. При `l = 1` віднімаємо `cnt[0] = 0`.

## Складність

- Решето: O(N log log N). Для `N = 10⁶` наш еталон виконує 2 122 048 викреслень (порахували окремим запуском).
- Префіксні суми: O(N). Кожен запит: O(1). Пам'ять: O(N).
- На найбільших тестах (`q = 10⁵`) еталон на C++ працює кілька сотих секунди, на Python — 0,2–0,35 с (у різних запусках).

Для порівняння: перебір дільників для всіх чисел до `10⁶` — це десятки мільйонів ділень на кожен довгий запит.

## Типові помилки учнів

| Помилка | Симптом | Як виявити |
|---|---|---|
| Переповнення `i * i` в `int`: зовнішній цикл решета йде до `N`, а внутрішній починається з `j = i * i` | При `i ≥ 46 341` добуток перевищує `2³¹ − 1`, `j` стає від'ємним — запис за межі масиву. | 1 вважається простим (`sieve[1]` не обнулили) | Приклад 1 дає `5 4 1 1` замість `4 4 0 1` | Тести з `l = 1` |

| Перебір дільників для кожного запиту | Перевищення часу | `s2-full`, `s2-rand`, `b-rand`, `b-full` |
| Python: решето на вкладених циклах | Повільно: найдовший тест 0,73–0,83 с при обмеженні 1 с | Великі тести; використовуйте `bytearray` і зрізи |

## Методичні примітки

1. Почніть із перебору дільників до `√x` і доведіть, чому `√x` досить: якщо `x = a · b` і `a ≤ b`, то `a ≤ √x`.
2. Решето добре «програти» на дошці для чисел до 50: учні по черзі викреслюють кратні 2, 3, 5, 7 і помічають, що на 7 (`7² = 49`) робота закінчується.
3. Друга половина задачі — повторення префіксних сум. Якщо клас уже розв'язав задачу 13, учні впізнають `cnt[r] − cnt[l − 1]` самі.
4. Дайте здати версію з `for (int i = 2; i <= N; i++)` і `j = i * i` — вона «падає» на всіх тестах. Це наочний урок про переповнення, коли межі вже не `10⁹`, а `i²`.
5. Про підзадачу 2. Спершу планувалося обмеження `q ≤ 10`, але тоді перебір дільників на C++ працював 1,1–1,3 с, тобто на межі обмеження часу, а перебір лише непарних дільників — 0,6 с і проходив. Результат залежав би від швидкості сервера, тож ми взяли `q ≤ 100`: перебір гарантовано не встигає, а решето з циклом по відрізку встигає. Підзадача 2 нагороджує саме ідею решета, а підзадача 3 — решето разом із префіксними сумами.
6. Продовження: решето для найменшого простого дільника (розклад на множники за O(log x)), кількість дільників для всіх чисел до `10⁶` (CSES 1713), сегментоване решето для відрізків поблизу `10¹²`.
