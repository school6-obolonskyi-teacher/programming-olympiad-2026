# 03. Трикутник — хибні розв'язки для режиму «Злам»

Кожен файл тут проходить усі приклади з умови, але містить типову помилку учнів. Завдання учня — скласти **коректний** тест, на якому розв'язок помиляється або не встигає. Перевірка тесту:

```
python інструменти/перевірити.py --зламати 03 мій-тест.in          # проти всіх хибних розв'язків
python інструменти/перевірити.py --зламати 03 мій-тест.in х1.cpp   # лише проти одного
```

Скрипт спершу перевіряє тест [валідатором](../валідатор.py): тест, що порушує обмеження умови, нічого не доводить. Правильну відповідь дає еталон. Крок помилки — за таблицею з [АНАЛІЗ-ПОМИЛОК](../../../АНАЛІЗ-ПОМИЛОК.md).

| Файл | Що не так | Крок за АНАЛІЗ-ПОМИЛОК | Найменший ламаючий тест (вхід → правильна відповідь / що виводить хибний) | Які тести репозиторію його ловлять | Бали на тестах репозиторію (за підзадачами) |
|---|---|---|---|---|---|
| [х1.cpp](х1.cpp) | Три нерівності в `int`: сума двох сторін (до `4·10⁹`) переповнюється. | 4 — типи даних | `1 2000000000 2000000000` → `YES` / `NO` | неправильна відповідь: `15`, `17`, `18`, `22`, `big3`, `big4` | **50** (підзадачі: 1 — так, 2 — ні) |
| [х2.cpp](х2.cpp) | Сортування і одна нерівність, але в `int`. Тонше за х1: переповнюється, лише коли навіть дві менші сторони разом більші за `2³¹ − 1`. | 4 — типи даних | `1500000000 1500000000 1500000000` → `YES` / `NO` | неправильна відповідь: `15`, `22`, `big4` | **50** (підзадачі: 1 — так, 2 — ні) |
| [х3.cpp](х3.cpp) | Перевірено лише дві нерівності з трьох (бракує `b + c > a`). | 5 — реалізація | `2 1 1` → `NO` / `YES` | неправильна відповідь: `05`, `07`, `09`, `19`, `21`, `big2` | **0** (підзадачі: 1 — ні, 2 — ні) |

Бали й списки тестів отримано запуском `python інструменти/перевірити.py 03 вчителю/розбори/03-трикутник/хибні/<файл>` (g++ 13, Python 3.12, WSL); ламаючі тести перевірено режимом `--зламати`.
