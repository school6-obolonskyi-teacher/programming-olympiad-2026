# Розбір: 07. Піраміда

Умова: [задачі/07-піраміда/умова.md](../../../задачі/07-піраміда/умова.md) · Тема: [цикли](../../../учням/теми/03-цикли.md)

## Ідея алгоритму

Два вкладені цикли:

- **зовнішній** перебирає номер рядка `i` від `1` до `N`;
- **внутрішній** виводить числа `j` від `1` до `i`, а після нього виводиться перехід на новий рядок.

Пробіл ставимо лише між числами: після `j`, якщо `j < i`. У Python зручно зібрати числа рядка в список і вивести `" ".join(...)`.

Трасування для `N = 3`:

```
i = 1:
  j = 1: вивести "1"
  новий рядок
i = 2:
  j = 1: вивести "1 "
  j = 2: вивести "2"
  новий рядок
i = 3:
  j = 1: вивести "1 "
  j = 2: вивести "2 "
  j = 3: вивести "3"
  новий рядок
```

## Обґрунтування правильності

Зовнішній цикл виконується рівно `N` разів, і кожна його ітерація закінчується одним переходом на новий рядок, тому рядків рівно `N`. На ітерації з номером `i` внутрішній цикл перебирає `j = 1, 2, …, i` по порядку, тож у рядку `i` стоять саме числа від `1` до `i`. Пробіл виводиться після кожного числа, крім останнього, тому між сусідніми числами рівно один пробіл.

## Складність

- Час: O(N²). Усього виводиться `1 + 2 + … + N = N(N+1)/2` чисел, при `N = 100` це 5050 чисел. Обидва еталони працюють менш ніж за 0,1 с.
- Пам'ять: O(1) у C++, O(N) у Python на список одного рядка.

## Як перевіряється відповідь

Скрипт `інструменти/перевірити.py` без чекера порівнює відповіді **за токенами**: пробіли й переходи на новий рядок не важать. Для цієї задачі це погано: розв'язок, що виводить усі числа в одному рядку, пройшов би всі тести, бо послідовність чисел та сама. Тому в задачі є [чекер.py](чекер.py), який діє як стандартний чекер `lcmp` із бібліотеки testlib:

- рядки (крім порожніх у самому кінці) і числа в кожному рядку мають збігатися з правильною відповіддю;
- кількість пробілів між числами, пробіли в кінці рядка й порожні рядки в самому кінці виведення не важать.

Це відступ від стандарту репозиторію (там чекер передбачено лише для задач із кількома правильними відповідями). Він потрібен, бо формат виведення тут і є предметом навчання.

Коли чекер відхиляє відповідь, скрипт друкує «очікувалося» і «отримано» в один рядок, позначаючи межі рядків знаком `⏎`, тож видно, де відповідь розбита на рядки не так. Як читати цей знак, пояснено в умові.

## Методичні примітки

1. Перед кодом попросіть учнів заповнити на дошці таблицю «рядок `i` → які числа в ньому», а потім трасування для `N = 3` (див. вище). Так видно, що межа внутрішнього циклу — `i`, а не `N`.
2. Обговоріть, де стоїть перехід на новий рядок, і покажіть три типові неправильні варіанти: всередині внутрішнього циклу, забутий, подвійний.
3. Поясніть, що на олімпіадах відповідь зазвичай порівнюють за токенами, тож пробіл у кінці рядка не шкодить. Але в задачах, де важить форма (таблиці, малюнки з символів), перевіряють рядки, а іноді й кожен символ. Звичка виводити рівно те, що просять, береже бали.
4. Варіації для закріплення: перевернута піраміда (від `N` до `1` рядків), піраміда з вирівнюванням по центру, таблиця множення `N × N`, «сходинки» із зірочок. Повільний розв'язок — гарний привід обговорити, що ту саму задачу можна розв'язати одним циклом, якщо пам'ятати попередній рядок.
