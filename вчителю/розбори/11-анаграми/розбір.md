# Розбір: 11. Анаграми

Умова: [задачі/11-анаграми/умова.md](../../../задачі/11-анаграми/умова.md) · Тема: [рядки](../../../учням/теми/05-рядки.md), [масиви](../../../учням/теми/04-масиви.md)

## Що змінено порівняно з першою версією

- Виведення `YES`/`NO` замість «ТАК»/«НІ» (причини — у [розборі задачі 10](../10-паліндром/розбір.md#що-змінено-порівняно-з-першою-версією)). Старий C++-розв'язок, що виводить «ТАК»/«НІ», на нових тестах набирає 0 балів (перевірено запуском).
- Уточнено формат: два слова з латинських літер, кожне в окремому рядку, без пробілів. У старій умові було «два рядки», і незрозуміло, чи можуть у них бути пробіли.
- Основним розв'язком тепер є підрахунок частот за O(n). Сортування лишається альтернативою за O(n log n).
- Довжину слів збільшено з `10⁴` до `10⁶`, щоб квадратичні розв'язки («знайти й викреслити літеру») не проходили підзадачу 3 ні на Python, ні на C++. При довжині `2·10⁵` C++-версія з `string::erase` вкладалася в 0,32 с, бо копіювання пам'яті дуже швидке, і підзадача 3 нічого б не перевіряла.

## Ідея алгоритму

**Основний спосіб: підрахунок частот.** Слова є анаграмами тоді й лише тоді, коли кожна з 26 літер трапляється в них однакову кількість разів. Заводимо масив `cnt[26]`, проходимо першим словом і для кожної літери збільшуємо `cnt[літера − 'a']`, потім проходимо другим і зменшуємо. Відповідь `YES`, якщо всі 26 лічильників дорівнюють нулю. Регістр прибираємо функцією `tolower` (`lower()` у Python) перед обчисленням номера літери.

Трасування для `ABA` / `Baa`:

```
Перше слово:  a → cnt[a] = 1;  b → cnt[b] = 1;  a → cnt[a] = 2
Друге слово:  b → cnt[b] = 0;  a → cnt[a] = 1;  a → cnt[a] = 0
Усі лічильники нульові → YES
```

**Альтернатива: сортування.** Зводимо обидва слова до малих літер, сортуємо літери кожного й порівнюємо результати. Трасування з першої версії репозиторію:

```
Крок 1: зводимо до малих: "listen", "silent"
Крок 2: сортуємо:        "eilnst", "eilnst"
Крок 3: порівнюємо:      "eilnst" == "eilnst"
Крок 4: це анаграми → YES
```

## Обґрунтування правильності

Перестановка не змінює, скільки разів трапляється кожна літера. Отже, в анаграм однакові частоти. Навпаки, якщо частоти однакові, то літери другого слова можна по одній взяти з «купки» літер першого. Кожну літеру потрібно рівно стільки разів, скільки її є, тож друге слово — перестановка першого. Різна довжина автоматично дає різні частоти, принаймні для однієї літери, тому окремо перевіряти довжину не потрібно (хоча це корисна швидка перевірка).

Порівнювати треба саме **кількості**, а не лише набори літер (`aab` і `abb`) і не суми кодів (`ad` і `bc`: `97 + 100 = 98 + 99`).

## Складність

| Спосіб | Час | Додаткова пам'ять |
|---|---|---|
| Підрахунок частот | O(\|s\| + \|t\| + 26) | O(26) |
| Сортування | O(n log n) | O(n) у Python; у C++ рядок сортується на місці |
| Знайти й викреслити кожну літеру | O(n²) | O(n) |

При довжині `10⁶` еталон на C++ працює 0,03 с, на Python — 0,14 с. Сортування на C++ і в Python теж укладається: 0,19 с і 0,27 с. Квадратичний спосіб виконує порядку `10¹²/2` операцій копіювання і не вкладається в 5 с.

## Методичні примітки

1. Почніть з кубиків або карток із літерами: учні складають з `listen` слово `silent`. Потім запитайте, як перевірити, не переставляючи кубиків. Так з'являється ідея «порахувати, скільки яких літер».
2. Попросіть учнів запропонувати «швидкі» перевірки (однакові множини літер, однакова сума кодів) і самим знайти до них контрприклади (`aab`/`abb`, `ad`/`bc`). Це добра вправа на пошук контрприкладів, яка знадобиться на олімпіаді.
3. Порівняйте три способи за складністю і запустіть їх на тесті довжиною `10⁶`. На C++ підрахунок частот займає соті частки секунди, сортування — десяті, а викреслювання — понад 5 секунд.
4. Масив лічильників за номером літери — це «сортування підрахунком» у мініатюрі (II етап, тип E). Той самий прийом потрібен у CSES 1755 «Palindrome Reorder» і в багатьох задачах на рядки.
5. Варіації: чи можна з літер першого слова скласти друге, якщо не обов'язково використовувати всі (досить `cnt ≥ 0`); скільки літер треба видалити з обох слів, щоб вони стали анаграмами.
