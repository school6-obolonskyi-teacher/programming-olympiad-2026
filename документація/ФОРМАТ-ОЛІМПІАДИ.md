## 📌 Загальна інформація

### Що таке програмна олімпіада?

**Олімпіада з програмування** — це інтелектуальне змагання, на якому учасники розв'язують завдання, написавши програми на мовах програмування (найчастіше C++ або Python).

### Призначення олімпіади

- 🎯 Розвиток навичок алгоритмічного мислення
- 🎯 Практика програмування
- 🎯 Здружування з іншими учнями
- 🎯 Перевірка своїх знань
- 🎯 Можливість виграти призи

## ⏱️ Формат змагання

### Час проведення
- **Загальна тривалість:** 3 години
- **Можна зупинитися раніше:** так, але не можна повертатися
- **Перервина:** немає, але можна попросити у організаторів

### Кількість завдань
- **Всього:** 3-4 завдання
- **Складність:** від легких до важких
- **Сфера:** програмування, математика, логіка

### Як оцінюється робота?

**Повний бал:** 100 точок за завдання

**Система оцінювання:**
- **100%** — правильна відповідь на всіх тестах
- **0%** — неправильна відповідь або помилка

**Сортування учасників:**
1. За кількістю розв'язаних завдань
2. За часом, витраченим на останнє розв'язане завдання
3. За кількістю спроб (менше спроб = краще)

## ✅ Дозволене на олімпіаді

✅ **Дозволено використовувати:**

- Компілятор/інтерпретатор

### Готові шаблони

Можна заздалегідь підготувати базовий шаблон:

**C++:**
```cpp

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    // Ваш код тут

}
```

**Python:**
```python
#!/usr/bin/env python3

def main():
    # Ваш код тут
    pass

if __name__ == "__main__":
    main()
```

## 📊 Критерії оцінювання

### Що перевіряється?

1. **Коректність:** Чи програма видає правильні результати?
2. **Ефективність:** Чи програма працює за обмеження часу/пам'яті?
3. **Синтаксис:** Чи програма компілюється/запускається?

### Що НЕ перевіряється?

- ❌ Красота коду
- ❌ Коментарі
- ❌ Стиль програмування
- ❌ Розумність змінних

## 📝 На чому писати розв'язання?

### Доступні мови програмування:
- ✅ **C++** (найпопулярніша на олімпіадах)
- ✅ **Python 3**
- ⚠️ Інші мови (за умовою організаторів)

### На якому сайті?

Залежить від платформи:
- **Codeforces** — якщо змагання через Codeforces
- **Local judge** — якщо локальна система
- **Polygon** — на більших олімпіадах

### Як надіслати розв'язання?

1. Напишіть програму на вибраній мові
2. Протестуйте на прикладах
3. Завантажте файл або скопіюйте код
4. Натисніть кнопку "Submit"
5. Отримаєте вердикт (Accepted, Wrong Answer, Time Limit, тощо)

---

## 🏆 Вердикти при надсиланні

| Вердикт | Значення | Що робити |
|---------|----------|----------|
| **Accepted** (AC) | ✅ Правильно! | Переходьте до наступного завдання |
| **Wrong Answer** (WA) | ❌ Неправильна відповідь | Перевірте логіку та граничні випадки |
| **Time Limit** (TL) | ⏱️ Програма занадто повільна | Оптимізуйте алгоритм |
| **Memory Limit** (ML) | 💾 Занадто багато пам'яті | Зменшіть кількість даних в пам'яті |
| **Runtime Error** (RE) | 💥 Помилка під час виконання | Перевірте вихід за межі, ділення на 0 |
| **Compilation Error** (CE) | 🔴 Синтаксична помилка | Перевірте синтаксис коду |

## 💡 Поради для успіху

### Перед олімпіадою

1. ✅ Вивчіть всі 7 завдань
2. ✅ Практикуйте на Codeforces
3. ✅ Знайте свій шаблон
4. ✅ Спіть достатньо ночей перед
5. ✅ Приходьте на 15 хвилин раніше

### Під час олімпіади

1. 📖 Прочитайте **всі завдання** спочатку (10 хвилин)
2. 🎯 Виберіть **легке завдання** для початку
3. ⏱️ Не затримуйтеся на одному завданні більше 30 хвилин
4. ✅ **Протестуйте** на прикладах перед надсиланням
5. 🔄 Повертайтесь до **легких завдань** для набрання балів

### Поширені помилки

- ❌ Читання тільки першого завдання
- ❌ Витрачання вся часу на одне важке завдання
- ❌ Без тестування на граничних випадках
- ❌ Неправильне читання вхідних даних
- ❌ Паніка при помилці
