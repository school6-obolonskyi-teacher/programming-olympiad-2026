## 🌐 Онлайн-платформи для тренування

### ⭐ Основні платформи

#### 1. **Codeforces** (НАЙКРАЩЕ!)
- **Сайт:** https://codeforces.com/
- **Мова:** Англійська та інші
- **Завдання:** Від 800 до 3000+ рейтингу
- **Переваги:** 
  - Найбільше завдань
  - Швидка перевірка розв'язань
  - Живі змагання (contests)
  - Активна спільнота
- **Де почати:** 
  1. Реєстрація
  2. Problemset → Завдання рейтингом 800-1000
  3. Розв'язувати по 1-2 дня

#### 2. **AtCoder**
- **Сайт:** https://atcoder.jp/
- **Мова:** Англійська, японська
- **Завдання:** Якісні завдання від молоді компанії Sony
- **Переваги:**
  - Якість завдань вище за середній
  - Хорошо пояснені
  - Регулярні змагання
- **Де почати:** AtCoder Beginner Contest (ABC) — найлегший рівень

#### 3. **SPOJ**
- **Сайт:** https://www.spoj.com/
- **Мова:** Англійська
- **Завдання:** Архів з 20000+ завдань
- **Переваги:**
  - Велика база
  - Класичні алгоритмічні задачи
  - Можна вибрати за темою
- **Де почати:** Вибрати категорію "Beginners"

#### 4. **LeetCode**
- **Сайт:** https://leetcode.com/
- **Мова:** Англійська
- **Завдання:** Fokus на іменах та SQL
- **Переваги:**
  - Дуже популярна для інтерв'ю
  - Хорошо пояснені
  - Система лайків та коментарів
- **Де почати:** Easy задачи (1-50 задача)

## 📚 Книги для поглибленого вивчення

### 🏆 Найкращі книги

#### 1. **"Competitive Programming" (Halim & Halim)**
- **Мова:** Англійська
- **Обсяг:** 800+ сторінок
- **Вміст:** Повний курс олімпіадного програмування
- **Рівень:** Бакалавр-магістр
- **Раджу:** Для серйозної підготовки

#### 2. **"Introduction to Algorithms" (CLRS)**
- **Мова:** Англійська
- **Обсяг:** 1300+ сторінок
- **Вміст:** Класичний курс алгоритмів
- **Рівень:** Глибоке розуміння
- **Раджу:** Для тих, хто хоче знати "чому"

#### 3. **"Алгоритмы и структуры данных" (Гудзієнко)**
- **Мова:** Російська
- **Обсяг:** 400+ сторінок
- **Вміст:** Базові алгоритми з прикладами
- **Рівень:** Середній
- **Раджу:** Якщо є проблеми з англійською

## 🎯 Рекомендована послідовність ресурсів

### Для новачків (0-2 місяці):
1. YouTube (GeeksforGeeks базове)
2. CP-Algorithms (розділи "Основи")
3. Codeforces (рейтинг 800)
4. LeetCode Easy

### Для середнього рівня (2-4 місяці):
1. YouTube (Errichto, Abdul Bari)
2. CP-Algorithms (розділи "Структури даних")
3. Codeforces (рейтинг 900-1000)
4. AtCoder (ABC завдання)

### Для продвинутого рівня (4+ місяці):
1. Книги (Halim & Halim, CLRS)
2. CP-Algorithms (позиціл розділи)
3. Codeforces (рейтинг 1100+)
4. SPOJ (класичні алгоритми)
