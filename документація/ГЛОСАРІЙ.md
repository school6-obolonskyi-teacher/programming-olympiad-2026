## 🔤 Термін і алгоритми

### **Алгоритм**
Послідовність кроків для розв'язання задачи. Наприклад, алгоритм пошуку мінімуму в масиві.

### **Анаграма**
Слово або фраза, утворена перестановкою букв іншого слова. Приклад: "слухати" та "малюситеs".

### **Масив (Array)**
Колекція елементів однакового типу, розташованих послідовно в пам'яті. 
```
Приклад: [1, 2, 3, 4, 5]
        індекс 0, 1, 2, 3, 4
```

### **Бінарний пошук**
Эффективный алгоритм пошуку в відсортованому масиві. Складність: O(log N).

### **Вхід (Input)**
Дані, що надходять у програму. Зазвичай читаються зі стандартного потока введення (cin, input()).

### **Вихід (Output)**
Результат, який повинна вивести програма. Зазвичай виводиться до стандартного потока виведення (cout, print()).

### **Гранична випадків**
Екстремальні значення (мінімум, максимум, нуль), які часто призводять до помилок.

### **Двійкова система**
Система числення з основою 2. Використовує цифри 0 та 1. Основа комп'ютерів.

### **Дерево (Tree)**
Структура даних, де кожен вузол має батька та дітей. Використовується в багатьох алгоритмах.

### **Динамічне програмування (DP)**
Метод розв'язання задач шляхом розбиття їх на підзадачі та запам'ятовування результатів.

## ℹ️ Терміни олімпіади

### **Accepted (AC)**
Вердикт при надсиланні розв'язання: програма видала правильну відповідь на всіх тестах.

### **Вердикт**
Результат перевірки розв'язання (AC, WA, TL, ML, RE, CE).

### **Видання олімпіади**
Змагання з програмування на конкретний рік. Наприклад, "Олімпіада 2026".

### **Відправлення (Submission)**
Надіслання готового розв'язання на перевірку платформою.

### **Вкладений цикл**
Цикл всередині іншого циклу.
```cpp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // Код тут виконується n² раз
    }
}
```

### **Виконання (Execution)**
Запуск програми на комп'ютері або платформі.

## 🔍 Пошук та сортування

### **Лінійний пошук**
Простий пошук елемента в масиві перейдя по всім елементам. Складність: O(N).

### **Сортування (Sorting)**
Впорядкування елементів масиву за деяким критерієм (зростання, спадання).

### **Сортування пузирцем (Bubble Sort)**
Простий алгоритм сортування, але повільний. Складність: O(N²).

### **Швидке сортування (QuickSort)**
Ефективне сортування "розділяй та панюй". Складність: O(N log N).

### **Злиття сортування (Merge Sort)**
Сортування шляхом розбиття та злиття. Складність: O(N log N).

## 🔢 Математичні терміни

### **Дільник**
Число, на яке інше число ділиться без залишку. Приклад: 2 дільник 4.

### **НОД (Найбільший Спільний Дільник)**
Найбільше число, на яке два число ділиться без залишку. 
Приклад: НОД(12, 18) = 6

### **НОК (Найменше Спільне Кратне)**
Найменше число, яке ділиться на обидва числа.
Приклад: НОК(4, 6) = 12

### **Послідовність Фібоначчі**
Послідовність, де кожне число дорівнює сумі двох попередніх: 0, 1, 1, 2, 3, 5, 8, 13...

### **Модуль (Mod, Залишок)**
Залишок від ділення одного числа на інше.
Приклад: 10 % 3 = 1 (остання цифра 10 при діленні на 3 це 1)

### **Операція ділення**
На відміну від математики, в програмуванні є розриз між `/` (дійсне ділення) та `//` (ціле ділення).

### **Парне число**
Число, яке ділиться на 2 без залишку. Приклад: 2, 4, 6, 8...

### **Паліндром**
Число або слово, яке читається однаково спереду та ззаду. 
Приклад: "racecar", 121

### **Простое число**
Число, яке ділиться тільки на 1 та на себе. Приклад: 2, 3, 5, 7, 11...

### **Степень (Вознесення до степеня)**
Множення числа самого на себе кілька разів.
Приклад: 2³ = 2 × 2 × 2 = 8

## 💾 Структури даних

### **Гешь (Hash)**
Функція, яка перетворює дані в числовий ключ. Використовується для швидкого пошуку.

### **Граф (Graph)**
Мережа вузлів (вершин), з'єднаних рубами (ребрами).

### **Де que (Двостороння черга)**
Список, до якого можна додавати та видаляти з обох кінців.

### **Картка (Map, Dictionary)**
Структура даних, яка зберігає пари ключ-значення.
```
Приклад: {"name": "Іван", "age": 15}
```

### **Куча (Heap)**
Спеціальна структура даних для швидкого отримання мінімального або максимального елемента.

### **Лист (List)**
Послідовна колекція елементів, подібна масиву, але з динамічним розміром.

### **Матриця (Matrix)**
Двовимірний масив, структурований як таблиця з рядками та стовпцями.

### **Множина (Set)**
Колекція унікальних елементів. Немає дублів.

### **Премаршалізації (Stack)**
Структура "останній увійшов — перший вийшов" (LIFO). Як стік тарілок.

### **Рядок (String)**
Послідовність символів. Приклад: "Привіт світ!"

### **Черга (Queue)**
Структура "перший увійшов — перший вийшов" (FIFO). Як черга в магазині.

## ⚙️ Операції та функції

### **abs() — Абсолютне значення**
Повертає число без знака. Приклад: abs(-5) = 5

### **ceil() — Округління вверх**
Округлює число до найменшого більшого цілого.

### **floor() — Округління вниз**
Округлює число до найбільшого меншого цілого.

### **max() — Максимум**
Повертає найбільше число з переданих.

### **min() — Мінімум**
Повертає найменше число з переданих.

### **pow() — Степень**
Піднімає число до степеня. Приклад: pow(2, 3) = 8

### **round() — Округління**
Округлює число до найближчого цілого.

### **sqrt() — Квадратний корінь**
Обчислює квадратний корінь числа. Приклад: sqrt(9) = 3

## 📊 Складність алгоритму

### **Часова складність**
Як кількість операцій залежить від розміру вхідних даних (N).

### **O(1) — Постійна часова складність**
Незалежно від розміру даних, час однаковий.

### **O(log N) — Логарифмічна**
Час зростає як логарифм від N. Приклад: бінарний пошук.

### **O(N) — Лінійна**
Час пропорційний N. Приклад: пошук мінімуму.

### **O(N log N) — Лінійно-логарифмічна**
Приклад: швидке сортування.

### **O(N²) — Квадратична**
Час залежить від N². Приклад: вкладені цикли.

### **O(N³) — Кубічна**
Дуже повільна. Приклад: трійний цикл.

### **O(2^N) — Експоненціальна**
Екстремально повільна. Приклад: наїва рекурсія.

### **Просторова складність**
Скільки пам'яти використовується алгоритмом.

## 🔧 Технічні терміни

### **Бит (Bit)**
Найменша одиниця інформації: 0 або 1.

### **Байт (Byte)**
8 бітів. Основна одиниця зберігання даних.

### **Вектор**
Динамічний масив, що може змінювати розмір.

### **Власне число**
Число, яке ділиться на 2 без залишку. Синонім парного.

### **Гексадесяткова система**
Система з основою 16, використовує цифри 0-9 та букви A-F.

### **Двовимірний масив (2D Array)**
Масив з рядками та стовпцями.
```
[[1, 2, 3],
 [4, 5, 6],
 [7, 8, 9]]
```

### **Екземпляр (Instance)**
Об'єкт, створений з класу.

### **Індекс**
Позиція елемента в масиві. Зазвичай починається з 0.

### **Компіляція**
Перетворення вихідного коду (C++) на машинний код.

### **Локальна змінна**
Змінна, доступна тільки в рамках функції.

### **Мегабайт (МБ)**
1024 кілобайти. Одиниця розміру файлів.

### **Обхід (Traversal)**
Відвідування кожного елемента структури даних.

### **Передача за посиланням**
Передача адреси змінної (вказівника) функції.

### **Передача за значенням**
Копіювання значення змінної в функцію.

### **Таблиця істинності (Truth Table)**
Таблиця для логічних операцій.

### **Точка входу**
Місце, де починається виконання програми (main()).

### **Фінальна змінна**
Змінна, що не може змінюватися після ініціалізації.

## 📝 Терміни з вводу-виводу

### **Вхідні дані (Input)**
Дані, які читає програма.

### **Вихідні дані (Output)**
Дані, які виводить програма.

### **Вхідний файл**
Файл, з якого програма читає дані.

### **Вихідний файл**
Файл, до якого програма пише дані.

### **Стандартний вхід (stdin)**
Вхід з клавіатури чи перенаправлений потік.

### **Стандартний вихід (stdout)**
Вивід на екран (консоль).

### **Стандартна помилка (stderr)**
Потік для виведення помилок.
